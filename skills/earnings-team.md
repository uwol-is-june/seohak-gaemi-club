# 실적 정밀분석 팀: 4대 거장 병렬 해석 + 아티클 발행

$ARGUMENTS 에 대해 팀 기반 실적 정밀분석을 수행한다. 4명의 투자 거장이 실적을 병렬로 해석하고, 편집자가 아티클로 다듬은 뒤, 독자 검토를 거쳐 발행 가능한 최종 아티클을 산출한다.

**지원 입력 형식**: `회사명 분기`, 예: `Apple 2025Q4`, `NVIDIA FY2025`, `Microsoft 최신`

## 설계 철학

좋은 실적 분석이 해결해야 할 두 가지 문제:
1. **스스로 미래를 읽을 수 있어야 한다** — 4가지 상이한 관점의 심층 연구가 필요하다
2. **독자가 가치를 읽을 수 있어야 한다** — 편집 다듬기와 독자 관점의 품질 검증이 필요하다

본 Skill의 프로세스는 3단계로 구성된다:
- **1단계·연구**: 4대 거장 병렬 실적 정독 (단용평: 비즈니스 본질, 버핏: 재무 품질, 멍거: 경쟁 변화, 이루: 리스크 신호)
- **2단계·합성**: Team Lead가 4개 관점을 종합해 연구 리포트 초안을 산출한다
- **3단계·발행**: 편집 Agent가 아티클로 개작 + 독자 검토 Agent가 수정 의견 제시 → Team Lead 최종 확정

## 1단계: 4대 거장 병렬 연구

### 0번째 단계: 핵심 재무 1회 수집 (fetch-once · 필수)

Agent를 띄우기 **전에** 연간 핵심 재무를 딱 한 번 수집해 박제한다. 4~6개 Agent가 같은
숫자를 각자 긁으면 토큰만 배로 나가고 Agent마다 다른 값을 들고 와 리포트가 어긋난다.

```bash
python3 tools/fetch_financials.py {티커} --years 10 --cross
```

- `reports/{티커}/_data.md` — 요약표. **Agent가 읽는 것은 이 파일이다.**
- `reports/{티커}/_data.json` — provenance(태그·accession·공시일) 포함 감사용.

SEC EDGAR XBRL 원문을 기계로 직접 읽으므로 전사 오류가 없다 → **🟢[사실]** 등급.

**정확도 가드**: ⚠️ 교차검증 미완료 / ❌ 중대 불일치(>5%) / 🔴 신선도 경고가 뜬 항목은
**반드시 원문으로 직접 확인**한 뒤 사용한다. ⬛(SEC에 태그 없음)은 추정으로 채우지 않는다.
도구가 실패하면(외국기업 XBRL 미제출 등) 기존 WebFetch 경로로 그대로 진행한다.

> ⚠️ 이 도구는 **연간(10-K/20-F)** 데이터만 제공한다. 분기 실적 수치는 여기 없으므로
> 8-K/10-Q 원문·실적발표 자료에서 별도 수집한다. `_data.md`는 **추세 비교의 기준선**으로 쓴다.

### 1번째 단계: 1차 자료 수집

Agent 도구를 사용해 백그라운드 Agent를 **병렬**로 실행하여 다음 원본 자료를 수집한다:

| 자료 유형 | 수집 출처 | 우선순위 |
|---------|---------|--------|
| 실적 보고서 원문 | SEC EDGAR (10-K, 10-Q, 8-K): sec.gov/cgi-bin/browse-edgar | 최고 |
| 실적 발표(Earnings Call) 트랜스크립트 | Seeking Alpha (seekingalpha.com), 회사 IR 페이지 | 최고 |
| 주주 서한 | 연간 보고서(10-K) 내 추출 | 높음 (연간 보고서 시에만) |
| 직전 분기 실적/콜 트랜스크립트 | 상동 | 높음 (공약 추적 목적) |
| **연간 재무 기준선** | **`reports/{티커}/_data.md` (0번째 단계에서 확보 — 재수집 금지)** | **최고** |
| 재무 데이터(분기·보조) | macrotrends.net/stocks/charts/{TICKER}, stockanalysis.com/stocks/{ticker}/financials | 높음 |
| 뉴스/애널리스트 반응 | finance.yahoo.com(`/analyst-insights/`), cnbc.com, seekingalpha.com(WebSearch 경유) | 보통 |

**자료 가용성 등급**:

| 등급 | 특징 | 영향 |
|------|------|------|
| A등급 | 완전한 원문 확보 | 모든 단계 정상 수행 |
| B등급 | 원문 일부 또는 제3자 요약만 확보 | "원본 출처 아님" 표기, 주석 분석 가중치 낮춤 |
| C등급 | 뉴스 보도 및 데이터 사이트 요약만 확보 | 핵심 수치 변화에 집중, 주석 분석 생략, "1차 자료 부족" 표기 |

자료 가용성 등급을 각 Agent에 전달해 분석 깊이에 반영한다.

| 단계 | 역할 | 거장/포지션 | 핵심 과제 |

| 연구 | 재무 품질 감사자 | 워런 버핏 (Warren Buffett) | 번 돈이 진짜 돈인가, 가짜 돈인가? |
| 연구 | 경쟁 변화 해석자 | 찰리 멍거 (Charlie Munger) | 경쟁 구도가 어떻게 바뀌고 있나? |

### 3번째 단계: 4개 병렬 연구 Agent 실행

Agent 도구를 사용해 **같은 메시지 내**에서 4개의 백그라운드 Agent를 실행한다.

> **토큰 예산 ([token-budget.md](token-budget.md))** — 각 Agent 프롬프트에 아래를
> **인라인으로** 포함시킨다(Agent는 이 문서를 읽지 않는다):
>
> - 🔴 **하위 Agent를 스폰하지 않는다** (TB-1). 팬아웃은 팀 리드만, 깊이는 1단계.
> - **조사 상한**: WebSearch 10회 · WebFetch 8회 · Bash 8회. 상한에 닿으면 가진 자료로 작성.
> - 실적 원본(10-Q·8-K·어닝스콜)은 2단계에서 **1회 수집해 공유**한다 — Agent마다 다시 긁지 않는다.
> - 결과는 **Write 1회**로 저장(Edit 반복 금지 · TB-5). 팀 리드에게는 **요약 + 파일 경로**만
>   보내고 본문을 메시지에 다시 붙여넣지 않는다.
> - 재시도는 역할당 1회까지, 2회차 실패면 그 관점을 "데이터 부족"으로 표기하고 진행(TB-2).
> - 못 구한 값은 `⬛`로 남긴다 — 상한은 정확도보다 우선하지 않는다.

#### Agent 1: 비즈니스 본질 해석 (단용평 관점)

**핵심 질문: 이번 실적이 반영하는 비즈니스 본질이 좋아졌나, 나빠졌나?**

> 단용평: "투자는 비즈니스를 사는 것이다. 실적 보고서를 볼 때 숫자를 보는 게 아니라, 이 비즈니스가 변했는지를 본다."

분석 내용:

1. **매출 구조 분해와 해석**
   - 사업 부문별·지역별 매출 — 어디가 가속, 어디가 감속인가
   - 숫자 나열에 그치지 않고 — 각 사업 부문이 반영하는 비즈니스 논리는 무엇인가
   - 매출 성장이 "물량(Volume)" 에서 왔나, "가격(Pricing)" 에서 왔나? 어느 쪽이 더 건강한가?

2. **고객/사용자 가치 변화**
   - MAU, DAU, 유료 구독자 등 운영 지표 변화 (해당 시)
   - ARPU, 재구매율, 고객 유지율(Retention) 등 품질 지표
   - 플랫폼/제품이 사용자에게 주는 가치가 강해지고 있나, 약해지고 있나?

3. **MOAT(경제적 해자) 점검**
   - 매출총이익률(Gross Margin) 변화 — Pricing Power(가격 결정력)가 유지되고 있나
   - 시장점유율 변화 — 경쟁 장벽이 유효한가
   - 전환 비용(Switching Cost) / 네트워크 효과가 약화되는 신호는 없나

4. **"좋은 비즈니스" 기준 평가**
   - 단용평의 3가지 조건: 차별화, 가격 결정력, 지속 가능한 경쟁 우위 — 이번 분기 변화
   - 비즈니스가 "자본 집약적"으로 변하고 있나, "자본 경량화"로 가고 있나?
   - 내일 이 회사가 문을 닫으면 고객이 매우 불편할까? 이번 실적으로 그 답이 달라졌나?

5. **경영진의 제품 감각**
   - 경영진이 제품/고객에 대해 이야기할 때 구체적 언어를 쓰나, 관료적 언어를 쓰나
   - 인상적인 제품 인사이트가 있나, 아니면 현장 감각 상실을 보여주는 불안한 신호가 있나

**산출 요건**: 각 세부 항목에 🟢개선 / 🟡유지 / 🔴악화 표기, 단용평 스타일 총평 제시.

#### Agent 2: 재무 품질 감사 (버핏 관점)

**핵심 질문: 이 회사가 번 돈은 진짜 돈인가? 안전 마진이 변했나?**

> 버핏: "나는 모든 실적 보고서에서 가장 먼저 현금흐름표를 펼친다."

분석 내용:

1. **핵심 재무 데이터 추출 및 검증**
   - **연간 GAAP 수치는 `reports/{티커}/_data.md` 를 먼저 읽는다** — 0번째 단계에서 SEC XBRL
     원문 기계추출 + 교차검증까지 끝난 값이다(🟢[사실]). **같은 항목을 다시 긁지 않는다.**
   - 매출(Revenue), 매출총이익(Gross Profit), 영업이익(Operating Income), 순이익(Net Income) — GAAP과 Non-GAAP 모두 확인
     (GAAP 연간 = `_data.md` / **분기치와 Non-GAAP은 8-K·10-Q·실적자료에서 별도 수집**)
   - GAAP vs Non-GAAP 차이: 얼마나 차이나는가, 어디서 차이가 나는가, 격차가 확대되는가 축소되는가
   - `_data.md` 에 없는 수치(분기·Non-GAAP·세그먼트)는 최소 2개 출처 교차 검증 (macrotrends.net + stockanalysis.com)

   ```bash
   python3 tools/financial_rigor.py cross-validate \
     --metric "revenue" --values {value1} {value2} --sources "macrotrends" "stockanalysis"
   ```

2. **현금흐름 분석 (가장 중요)**
   - 영업현금흐름(Operating Cash Flow) vs 순이익 비율 (>100% 양호, <80% 경계)
   - FCF(자유현금흐름) = 영업현금흐름 - CapEx(자본적 지출)
   - CapEx 구성: 유지보수성 vs 확장성
   - 자사주 매입(Buyback) 및 배당(Dividend) 금액

3. **이익 품질 검증**
   - 매출채권(Accounts Receivable) 증가율 vs 매출 증가율
   - 재고자산(Inventory) 증가율 vs 매출 증가율
   - 영업현금흐름과 순이익 격차 추세
   - 비용 자본화(Capitalized Expenses) 갑작스러운 증가 여부
   - 일회성 이익(Non-recurring Gains) 비중

4. **재무상태표 건전성**
   - 순현금(Net Cash) / 순부채(Net Debt) 변화
   - 매출채권/재고자산 회전일수 변화
   - 영업권(Goodwill) 및 무형자산 손상(Impairment) 리스크

5. **밸류에이션 및 안전 마진 업데이트**

   ```bash
   python3 tools/financial_rigor.py verify-market-cap \
     --price {price} --shares {shares} --reported {reported_market_cap} --currency USD
   python3 tools/financial_rigor.py verify-valuation \
     --price {price} --eps {EPS} --bvps {book_value_per_share}
   python3 tools/financial_rigor.py three-scenario \
     --price {price} --eps {EPS} --shares {shares_billions} \
     --growth {bull} {base} {bear} --pe {bull_PE} {base_PE} {bear_PE}
   ```

**산출 요건**: 모든 계산에 도구 출력 기록 첨부, 이익 품질 신호등 🟢/🟡/🔴, 버핏 스타일 총평 제시.

#### Agent 3: 경쟁 구도 해석 (멍거 관점)

**핵심 질문: 이번 실적이 경쟁 구도의 어떤 변화를 드러내고 있나?**

> 멍거: "나는 내가 어디서 죽을지 알고 싶다. 그러면 그곳에 가지 않으면 되니까."

분석 내용:

1. **실적 데이터로 경쟁 변화 추론**
   - 매출 성장률 vs 업계 성장률 — 아웃퍼폼인가, 언더퍼폼인가?
   - 매출총이익률 변화 — 경쟁 심화 또는 완화를 반영하나
   - 마케팅 비용률(S&M as % of Revenue) 변화 — 고객 획득에 더 많은 비용이 드나?
   - R&D 투자 — 주도적 투자인가, 경쟁에 떠밀린 대응인가?

2. **동기간 경쟁사 비교**
   - 주요 경쟁사의 동기간 핵심 지표 비교 (발표 완료 시)
   - 성장률, 이익률, 투자 강도 비교
   - 누가 이기고 있나? 누가 지고 있나?

3. **경영진의 경쟁에 대한 언급**
   - Earnings Call에서 경쟁 환경을 어떻게 묘사했나
   - 경쟁사를 직접 언급했나? 자신감 있는 어조인가, 불안한 어조인가?
   - 새로운 경쟁 위협이 등장했나?

4. **업계 트렌드 신호**
   - 기술 변화 (AI, 새로운 플랫폼 등)의 영향
   - 규제 변화가 경쟁 구도에 미치는 영향
   - 소비자/수요 측 트렌드 변화

5. **멍거식 역발상 사고**
   - 무엇이 이 회사를 죽일 수 있는가? 이번 실적에 그 위협을 가리키는 신호가 있나?
   - 5년 후 돌아봤을 때, 이번 실적이 "전환점"이 될 수 있나?

**산출 요건**: 경쟁 구도 판정 (강화/유지/악화), 경쟁사 비교표, 멍거식 역발상 총평.

#### Agent 4: 리스크 신호 사냥 (이루 관점)

**핵심 질문: 경영진이 이번 실적에서 무엇을 숨기고 있나? 어떤 신호가 깜빡이고 있나?**

> 이루: "투자에서 가장 중요한 것은 영구적 자본 손실을 피하는 것이다."

분석 내용:

1. **경영진 어조 분석**
   - MD&A(경영진 토의 및 분석) 및 Earnings Call 발언을 단락별로 읽으며 신호 표기:
   - 🟢솔직 신호 (문제를 자발적으로 인정) / 🟢명확 신호 (수치 목표 제시)
   - 🔴모호 신호 (빈말) / 🔴회피 신호 (엉뚱한 답변) / 🔴외부 귀인 (책임 전가)

2. **공약 추적**
   - 직전 분기 경영진의 구체적 공약 vs 이번 분기 실제 이행 — 항목별 대조
   - 단용평: "경영진이 믿을 만한지 보려면, 전에 한 말을 지켰는지 보면 된다."

3. **주석(Footnotes) 및 숨겨진 정보**
   - 관련 당사자 거래(Related Party Transactions), 스톡옵션 희석, 우발 부채(Contingent Liabilities)
   - 회계 정책 변경(Accounting Policy Changes), 사업 부문별 이익률 차이
   - 고객/공급업체 집중도 변화

4. **Earnings Call Q&A 정선**
   - 가장 날카로운 애널리스트 질문 3~5개 및 경영진 답변 품질 평가

5. **영구적 자본 손실 리스크**
   - 영구적 손실로 이어질 수 있는 신호가 나타났나
   - 규제/컴플라이언스/소송 리스크 신규 진전
   - 경영진이 돌이킬 수 없는 잘못된 의사결정을 했나

**산출 요건**: 경영진 신뢰도 평점 ★1~5, 공약 이행률, 리스크 신호 목록, 이루 스타일 총평.

## 2단계: Team Lead 연구 리포트 합성

4개의 연구 리포트가 모두 도착하면 Team Lead가 종합해 연구 리포트 초안을 산출한다.

**합성 요점** — 리포트를 이어 붙이는 게 아니라, 교차점과 모순점을 찾는다:

1. **4개 관점의 합의점**: 4명의 거장이 모두 동의하는 결론 — 신뢰도 최고
2. **4개 관점의 모순점**: 예를 들어 단용평은 비즈니스가 좋아지고 있다고 하는데 멍거는 경쟁이 심화되고 있다고 하는 경우 — 이런 모순이 가장 가치 있는 분석이다
3. **간과된 영역**: 4명 모두 중점적으로 다루지 않은 것 — 그게 오히려 가장 중요한 포인트일 수 있다

#### 연구 리포트 구조

```markdown
# {회사명} {기간} 실적 정밀분석 리포트
**4대 거장 병렬 해석 | {날짜}**

## 1. 한 줄 결론
> 50~100자: 예상 초과/부합/미달, 핵심 변화, 투자 thesis에 대한 영향.

## 2. 이번 분기 가장 중요한 3가지 변화
진짜 중요한 변화에 집중 — 데이터 나열 금지, 변화당 100자 이내.

## 3. 4대 거장 평가 테이블
| 관점 | 거장 | 핵심 질문 | 결론 | 평점 | vs 직전 분기 |
|------|------|---------|------|------|--------|

## 4. 핵심 수치 스냅샷
핵심 재무 및 운영 지표 테이블 (이번 분기 vs 직전 분기 vs 전년 동기)

## 5. 각 관점 심층 분석
각 관점별 가장 중요한 발견 3~5개

## 6. 경영진 어조 및 공약 추적
공약 이행 테이블 + 어조 변화 분석

## 7. 4대 거장이라면 어떻게 할까?
| 거장 | 보유 중이라면 | 미보유라면 | 근거 |

## 8. 결론
1. 예상 초과/부합/미달?
2. 투자 thesis 영향: 강화/무영향/약화/붕괴
3. 다음 촉매(Catalyst)
4. 매매 판단 가이드
```

## 3단계: 편집 다듬기 + 독자 검토

연구 리포트 완성 후 **병렬**로 2개의 Agent를 실행한다:

### Agent 5: 편집자 (투자 아티클 개작)

**포지션**: 하드코어 연구 리포트를 투자자들이 즐겨 읽고 이해할 수 있는 아티클로 개작한다.

**핵심 원칙**:
- 모든 핵심 데이터와 결론을 유지 — 전문적 깊이를 낮추지 않는다
- 표현 방식을 개선 — 비전문 투자자도 논리를 따라올 수 있게 한다
- "쉽게 설명하기"가 아니라 "전문 내용을 읽어도 지치지 않게 만들기"다

**구체적 작업**:

1. **제목과 도입부**
   - 제목은 정보량이 있고 클릭을 유도하되 낚시성 제목은 쓰지 않는다
   - 좋은 제목 예시: "NVIDIA가 $50B를 AI 인프라에 베팅했다 — 이겼나?"
   - 나쁜 제목 예시: "충격! NVIDIA 실적 폭발!"
   - 도입부 100자 이내에서: 이번 실적의 가장 중요한 결론이 무엇인지, 독자가 왜 읽어야 하는지 명확히 한다

2. **구조 최적화**
   - 연구 리포트는 나를 위한 것, 아티클은 독자를 위한 것 — 논리 순서를 조정한다
   - "가장 중요한 3가지 변화"를 최상단에 배치한다 (역피라미드 구조)
   - 테이블은 유지하되 간소화, 긴 분석 단락은 요점 형식으로 변환
   - 500자마다 "단계별 소결"을 삽입해 독자가 소화할 수 있게 한다

3. **표현 다듬기**
   - 딱딱한 재무 용어를 비유/시나리오로 설명한다: "영업현금흐름이 순이익보다 30% 낮다" → "$100을 벌었지만 지갑에는 $70밖에 없다"
   - 4대 거장의 어록 포인트는 아티클의 핵심 — 각 어록이 날카롭고 기억에 남도록 한다
   - 단락은 4줄을 넘기지 않는다, 문장은 30자를 넘기지 않는다
   - 대비와 반전을 적절히 활용해 읽는 리듬을 만든다

4. **독자 가치 테스트**
   - 각 섹션을 읽고 자문한다: 독자가 이 단락을 읽고 어떤 결정을 내릴 수 있나? 답이 "아무것도 없다"라면 — 다시 쓰거나 삭제한다
   - 아티클 마지막에는 명확한 "So What?" 이 있어야 한다 — 보유자와 관망자 각각에게 구체적 행동 지침을 제시한다

5. **포맷 최적화**
   - 블로그/뉴스레터 발행에 적합한 포맷: 짧은 단락, 명확한 소제목, 간결한 테이블
   - 적절한 구분선 및 인용 포맷 추가
   - 아티클 길이는 1,000~3,000자 내외 (너무 길면 독자가 이탈한다)

**산출물**: 개작된 완성 아티클.

---

### Agent 6: 독자 검토자 (일반 투자자 관점)

**포지션**: "가치투자에 관심 있고, 기초 재무 지식이 있으며, 해당 회사를 보유/관심 보유 중인" 일반 투자자 입장에서 아티클을 검토한다.

**검토 기준**:

1. **가독성 (가중치 30%)**
   - 전체를 읽는 데 몇 분이 걸리나? 건너뛰고 싶은 단락이 있나?
   - 이해하기 어렵거나 반복해서 읽어야 하는 부분이 있나?
   - 리듬감은 어떤가? "읽다가 지쳤다"는 느낌이 드나?

2. **정보 가치 (가중치 30%)**
   - 다 읽고 나서 이 회사에 대한 이해가 깊어졌나?
   - "아, 그렇구나"라는 순간이 있었나?
   - 다른 곳에서 본 분석과 비교해 이 아티클만의 독자적인 관점이 있나?
   - 없어도 이해에 지장 없는 불필요한 정보가 있나?

3. **신뢰도 (가중치 20%)**
   - 데이터에 출처가 있나? 핵심 판단에 근거가 있나?
   - 정반양면을 모두 제시하고 있나, 아니면 일방적으로 낙관/비관만 하나?
   - "이건 너무 자신만만한 것 아닌가"라는 판단이 있어서 불편한 느낌이 드나?
   - 4대 거장의 인용이 적절하고 힘 있게 사용되었나?

4. **행동 지침성 (가중치 20%)**
   - 다 읽고 나서 어떻게 해야 할지 알겠나?
   - 보유자와 관망자에 대한 가이드가 충분히 구체적인가?
   - 다음 단계에서 무엇을 봐야 하는지 알겠나? (Catalyst, 타임라인)

**산출 형식**:

```markdown
## 독자 검토 리포트

### 종합 평점: X/10

### 장점 (2~3개)
독자 관점에서 잘 된 부분

### 반드시 수정 (치명적 결함)
- 문제 1: 구체적 설명 → 수정 방향 제안
- 문제 2: ...

### 개선 권고 (있으면 더 좋을 것들)
- 제안 1: ...
- 제안 2: ...

### 독자가 가장 알고 싶지만 아티클에서 답하지 않은 질문
- 질문 1
- 질문 2

### 한 줄 총평
```

### Team Lead 최종 확정

편집 개작본과 독자 검토 리포트를 받은 후:

1. **독자 검토의 "반드시 수정" 항목 처리** — 항목별 수정 진행
2. **"개선 권고" 항목 선택적 반영** — 가치 있는지 판단 후 수용
3. **"독자가 알고 싶은데 답 없는 질문" 보완** — 데이터 근거가 있으면 추가
4. **최종 통독** — 수정 후 전체 흐름이 자연스럽고 논리적으로 일관된지 확인

## 핵심 원칙

- **원문을 읽는다, 요약본이 아니라**: SEC 원문 확보를 최우선으로 한다
- **4개 관점은 4개 부서가 아니다**: 서로 검증하고 도전해야 하며, 각자 제 얘기만 해서는 안 된다
- **Team Lead의 가치는 종합 판단에 있다**: 교차점과 모순점을 찾는 것이지, 리포트를 이어 붙이는 게 아니다
- **결론은 명확해야 한다**: "전반적으로 대체로 예상에 부합하지만 주목할 만한 포인트도 있다" 같은 표현은 금지
- **반면 검증은 전 과정에 관통한다**: 모든 긍정적 발견에는 반대 논거를 첨부한다
- **편집은 전문성을 낮추는 게 아니다**: 전문 내용을 더 읽기 쉽게 만드는 것이지, 과학 도서관으로 만드는 게 아니다
- **독자 검토는 형식이 아니다**: 진짜 독자 입장에서 문제를 찾아야 한다
- **데이터 정확성**: 핵심 수치는 교차 검증, financial_rigor.py 도구로 계산 확인

## 데이터 신뢰도 표기 (필수)

본 보고서(및 발행 아티클)는 **[data-confidence.md](data-confidence.md) 표준**을 적용한다:

- 핵심 수치·판단 옆에 **신뢰도 등급 + 유형 태그**를 단다 — 🟢높음(2+독립출처 교차검증 또는 SEC 원문 직접 확인) / 🟡보통(단일출처·경미편차·해석여지) / 🔴낮음(추정·미확정주장·구데이터) / ⬛데이터부족(공백 유지) + `[사실]`/`[추정]`/`[주장]`/`[의견]`.
- **출처 독립성 주의**: 회사 IR·보도자료와 집계 사이트는 둘 다 회사 공시 파생이라 상호 독립이 아니다 → 🟢은 SEC 원문 직접 확인 또는 계보가 다른 두 출처를 요구한다.
- 보고서 **말미에 기계 판독용 신뢰도 요약 블록**을 포함한다(대시보드가 파싱):

      <!-- confidence-summary
      high: N
      medium: N
      low: N
      gap: N
      verdict: 높음|보통|낮음
      -->

  (아래에 사람용 요약 몇 줄: 등급별 개수 + 종합 판단 근거)
- ⚠️ verdict는 **"데이터 신뢰도"이며 "투자 매력도"가 아니다.** 두 축은 독립이며 자주 어긋난다. `[의견]` 태그는 verdict 계산 분모에서 제외한다.
