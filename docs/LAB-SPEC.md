## 1. 유니버스

- **S&P 500 구성 종목 전체** — 출처: Wikipedia "List of S&P 500 companies" 표(티커·회사명·GICS 섹터).
  수집 시각과 종목 수를 산출물에 기록한다.
- 티커 표기는 SEC 기준(`BRK.B`), Yahoo 조회 시에만 `BRK-B` 로 바꾼다.
- **업종 제외**: GICS 섹터가 `Financials` 또는 `Real Estate` 인 종목.
  사유: 은행·보험·리츠는 영업현금흐름에 예금·보험료·자산 매각이 섞여 FCF가 사업 성과를 뜻하지 않는다.

## 2. 데이터

| 항목 | 출처 | 비고 |
|---|---|---|
| 연간 재무 (영업이익·OCF·CAPEX·총자산·현금·장기부채·희석주식수) | SEC XBRL companyfacts | `fetch_financials.build_annual` 재사용. 최근 **11개 회계연도** |
| 월말 종가 11년 + 주식분할 이력 | Yahoo chart API (`interval=1mo`, `events=split`) | 종가는 분할 조정값 |

**결측 보완** (2026-10-02 커버리지 진단 — 탈락 69종목 중 47종목이 이 두 가지 원인이었다)
- CAPEX 태그가 없는 연도 → `PaymentsToAcquireOtherPropertyPlantAndEquipment` 로 대체 (ADP 등)
- 희석주식수가 없는 연도 → `순이익 / 희석EPS` 로 역산. 다중 클래스 주식 회사(HSY·GOOGL)는 주식수를
  클래스별로만 공시해 companyfacts 에 합계가 없다. `|EPS| < $0.10` 이거나 순이익·EPS 부호가 다르면 역산하지 않는다.
  분할 보정의 공시일은 EPS 의 공시일을 쓴다.
- **분사 의심 표시**: 최근 3년 안에 정수비(k:1 · 1:k)가 아닌 분할 이벤트가 있으면 `spinoffSuspect` 로 표시한다.
  Yahoo 는 분사 조정을 소수 비율 분할로 기록한다(CMCSA 2026-01-05 Versant 분사 = 1.067). 분사 전 FCF 에 떨어져 나간
  사업이 섞여 목표가가 부풀려지므로, **제외하지 않되 LLM 결격 검증이 반드시 확인**한다(6절).
- 보완한 값은 산출물에 `imputed` 로 표시한다. **보완해도 못 채우면 결측 그대로 둔다(추정 금지)**.

**정의**
- `FCF_y = OCF_y − CAPEX_y`
- **분할 보정 주당 FCF**: `FCFps_y = FCF_y / (희석주식수_y × S_y)`
  - `S_y` = 그 수치의 **SEC 공시일(filed) 이후**에 일어난 분할 비율의 곱.
    SEC 주식수는 공시 시점 기준이고 Yahoo 종가는 이후 분할까지 소급 조정돼 있으므로,
    공시일 뒤의 분할만 곱해야 같은 잣대가 된다.
- `P_y` = 회계연도 종료일이 속한 달의 월말 종가(분할 조정)
- 과거 FCF 수익률 `Y_y = FCFps_y / P_y`
- **정상화 주당 FCF** `FCFps_now` = 최근 3개 회계연도 `FCFps` 의 **중앙값** (일회성 급등 1년이 목표가를 끌어올리지 못하게)
- 현재가 `P_now` = 실행일 직전 거래일 종가
- 현재 FCF 수익률 `Y_now = FCFps_now / P_now`

## 3. 제외 규칙 (깔때기 순서대로 적용, 단계마다 탈락 사유 기록)

| 단계 | 규칙 | 사유 코드 |
|---|---|---|
| E1 | GICS `Financials` · `Real Estate` | `sector` |
| E2 | SEC/Yahoo 데이터 수집 실패 · 보고통화가 USD 아님 · 13개월 월봉 부족 | `no_data` |
| E3 | 최신 회계연도 종료일이 실행일 기준 **15개월 초과** | `stale` |
| E4 | `FCFps`·`P_y` 가 모두 있는 연도가 **8개 미만** (10년 중 결측 2년 허용) | `short_history` |
| E5 | `FCFps_now ≤ 0` | `fcf_negative` |
| E6 | **12-1M 수익률**이 E1을 통과한 종목 중 **하위 20%** | `momentum` |
| E7 | 기대 상승여력 **< +15%** (4절) | `upside` |

- **12-1M 수익률** = `월말종가[t−1] / 월말종가[t−12] − 1` (t = 실행일이 속한 달. 최근 1개월은 단기 반전 소음이라 뺀다)
- E6의 하위 20% 경계는 **E1 통과 종목 전체**(데이터가 있는 것)로 계산한다 — 뒤 단계 통과 여부와 무관하게 고정된 모집단.
- 모멘텀은 **안전장치(제외)로만** 쓰고 점수에는 넣지 않는다. 많이 오른 종목을 쫓지 않기 위해서다.

## 4. 목표가 · 철회선 · 호라이즌

- **목표가** `T = FCFps_now / median(Y_y, 최근 10년)` — 밸류에이션이 자기 10년 중앙값으로 돌아올 때의 가격
- **기대 상승여력** `U = T / P_now − 1`
- `median(Y_y) ≤ 0`(과거 대부분 FCF 적자)이면 목표가를 정의할 수 없다 → E7 탈락(`upside`)
- **철회선** = 다음 중 먼저 걸리는 것: ① `P_pick × 0.85` 이하 종가 ② 다음 주 실행에서 E1~E7 통과 후보 밖으로 밀려남
- **호라이즌** = 픽 일로부터 **12개월** 고정
- 애널리스트 컨센서스는 **표시만** 한다(TASK-188). 계산·순위에 쓰지 않는다.

## 5. 순위 점수

E1~E6 통과 종목(= **랭킹 모집단**) 안에서 각 지표의 백분위 순위(0~100, 좋을수록 큼)를 매긴다.

| 축 | 지표 | 좋은 방향 |
|---|---|---|
| 퀄리티 Q1 | 영업자산이익률 10년 중앙값 = `영업이익 / (총자산 − 현금)` | 높을수록 |
| 퀄리티 Q2 | 영업이익률 10년 **표준편차** (안정성) | 낮을수록 |
| 퀄리티 Q3 | 순부채 / FCF = `(장기부채 − 현금) / FCF_최신` (순현금이면 음수. `FCF_최신 ≤ 0` 이면 최하위로 둔다) | 낮을수록 |
| 밸류 V1 | 자기 이력 대비 할인 = 기대 상승여력 `U` | 높을수록 |
| 밸류 V2 | 절대 FCF 수익률 `Y_now` (종목 간 비교) | 높을수록 |

- `퀄리티 = mean(Q1, Q2, Q3)` · `밸류 = mean(V1, V2)` · **`총점 = (퀄리티 + 밸류) / 2`** (동일 가중)
- 결측 지표는 해당 축 평균에서 빼고 남은 지표로 계산한다. 한 축의 지표가 전부 결측이면 그 종목은 순위에서 제외(`score_missing`).
- 백분위 = `(모집단 안에서 그 값보다 나쁜 종목 수 + 동값 수 × 0.5) / (모집단 크기 − 1) × 100`. 모집단이 1개면 50.
- 동점은 **티커 알파벳순**으로 정렬한다.
- E7(상승여력)은 순위를 매긴 **뒤에** 적용한다 — 백분위가 E7 통과 여부로 흔들리지 않게 하기 위해서다.
- 화면용 5단 게이지: 백분위 `0~20 → ●○○○○`, `20~40 → ●●○○○`, … `80~100 → ●●●●●`.

## 6. 산출

- **후보** = E7까지 통과한 종목을 총점 내림차순으로 정렬한 목록
- **픽** = 후보 1위부터 LLM 결격 검증(TASK-188)을 통과한 첫 종목. `spinoffSuspect` 가 있는 종목은 분사 전후 FCF 비교를 검증 항목에 반드시 포함한다. 최대 5위까지만 내려가고, 그래도 없으면 **"이번 주 없음"**
- **대조군** = 후보 전체에서 무작위 1종목. 시드 = 실행일 `YYYYMMDD` 정수 → `random.Random(seed).choice(정렬된 후보)`.
  LLM 검증을 거치지 않는다(순위와 검증이 무작위보다 나은지 재기 위한 비교군).
- 후보가 0개면 픽·대조군 모두 없음 → "이번 주 없음" 기록, 화면에는 **E7에서 가장 아깝게 떨어진 종목**(상승여력 최대)을 근접 후보로 보여준다.
- 산출 파일: `data/_lab/screen-{YYYYMMDD}.json` — 규칙 버전, 유니버스 출처·시각, 단계별 생존 수, 종목별 팩터 원값·백분위·목표가·탈락 사유, 후보 순위, 대조군.

## 7. 알려진 한계 (v1에서 의도적으로 감수)

- **평균회귀 가정**: 사업이 구조적으로 바뀐 회사(산업 쇠퇴·성장 둔화)는 자기 10년 평균으로 돌아오지 않는다 → LLM 결격 항목 "구조적 변화로 평균회귀 불성립"으로 거른다.
- **연간 데이터 지연**: 최신 회계연도 기준이라 최대 15개월 늦은 FCF를 쓸 수 있다. 분기(TTM) 반영은 v2 후보.
- **CAPEX만 차감**: 주식보상비용(SBC)을 FCF에서 빼지 않는다 — SBC가 큰 기업의 FCF가 후하게 잡힌다. v2 후보.
- **자체 태그 공시 기업 누락 (~20종목, 5%)**: CAPEX나 EPS를 회사 고유 XBRL 태그로 공시하면 SEC companyfacts API에
  값이 없어 E4(`short_history`)로 빠진다(2026-10-02 실측: NVDA·VZ·NEE·GLW·PSX·DTE·IT·ROP·HSY 등).
  대체 태그를 더 넓히면 CAPEX가 아닌 항목이 섞일 위험이 커서 v1에서는 감수한다. 10-K 원문 파싱은 v2 후보.
- **생존편향**: 현재 S&P 500 구성 종목만 본다. 픽의 전진 채점에는 영향이 없다(과거 백테스트가 아니므로).
