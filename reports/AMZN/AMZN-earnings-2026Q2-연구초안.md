## 1. 한 줄 결론

**영업은 최상급이었고, 이익은 대부분 사업이 번 것이 아니며, 가격에는 여유가 없다.**
AWS는 감가상각 +67% 역풍을 뚫고 파생 제외 마진을 +514~520bp 넓혔다(🟢). 그러나 순이익
$62.6B 중 **$53.4B(85%)가 Anthropic 지분의 비현금 Level 3 평가이익**이고(🟢), 잉여현금흐름은
**−$7.6B로 마이너스 전환**했다(🟢). 논제 영향: **강화도 붕괴도 아닌 "성격 변경"** —
아마존은 이번 분기부터 **타사 밸류에이션의 함수**가 됐다.

## 2. 이번 분기 가장 중요한 3가지 변화

**① 손익계산서가 비상장사 밸류에이션에 연동됐다.**
세전이익 $80.9B 중 기타수익 $53.4B = **66.1%**(🟢). 그 대부분이 아마존이 **직접 $10.0B를 넣은
Anthropic Series G·H 라운드 가격**을 "관측가능한 가격"으로 삼은 상향조정 $50.5B다(🟢).
Q1도 51.7%였다 — **2분기 연속**이다(🔴 역산).

**② 자본 성격이 바뀌었다.**
분기 영업이익 $27.5B를 벌면서 설비에 $63.9B를 넣었다(**2.33배**, 🟢). TTM FCF는
$25.9B → $18.2B → $14.8B → $11.2B → $1.2B → **−$7.6B**로 6분기 연속 단조 하락(🟢).
6개월 만에 순현금 +$57.4B → **리스 포함 순부채 −$100.2B**(🟢).

**③ AWS가 가속하면서 증분 점유율은 잃었다.**
AWS +36.7%(18분기 최고, 5분기 연속 가속, 🟢). 그러나 YoY 증분 달러는 AWS +$11.36B vs
**Google Cloud +$11.17B**(59% 작은 기반에서, 🔴 계산). **증분 점유율 ≈33% < 기존 점유율 ≈42%**.

## 5. 🔴 모순점 — 이 리포트에서 가장 가치 있는 부분

4개 관점이 **같은 숫자를 보고 반대로 읽은 지점**이다. 여기가 이번 분기의 진짜 쟁점이다.

### 모순 ① AWS 마진 +514bp는 실력인가, 일시적 국면인가

| | 단융핑 | 멍거 |
|---|---|---|
| 해석 | **실질적 개선.** D&A 343bp 역풍을 뚫고 514bp → D&A 이전 단위경제성 **약 850bp 개선** | **캐파 충전의 1회성 국면.** 비D&A 비용이 +10.5%만 늘어(매출 +36.7%) 이미 깔린 캐파를 채운 것 |
| 함의 | 자체 실리콘·가동률의 구조적 우위 | **레버리지는 양방향** — 캐파가 붙는 다음 국면엔 역으로 작동. 39.4%는 **천장이지 바닥이 아니다** |

**Team Lead 판정**: **둘 다 맞고, 시점이 다르다.** 두 관점의 계산은 동일하다(비D&A 비용 +10.5%).
차이는 이 레버리지가 반복되느냐다. **AWS에 6개월간 자산 $90.1B가 추가됐고 상당수가 아직
가동 전(건설중)이며, 그 규모는 ⬛ 미공시**(리루). 이 자산들이 순차 가동되면 D&A가 계단식으로
뛴다. **→ 검증 지표: 다음 2개 분기의 "파생 제외 AWS 마진"이 38% 위에서 버티는가.**

### 모순 ② 경쟁에서 이기고 있나

| | 단융핑·회사 서사 | 멍거 |
|---|---|---|
| 근거 | AWS **5분기 연속 가속**, 18분기 최고 성장 | **증분 달러 기준 점유율 33% < 기존 42%** |
| 결론 | 경쟁력 증명 | **시장 확대이지 점유율 탈취 아님.** 4사 중 성장률 최하위(AWS 36.7% vs Azure 43%, GCP 82%, OCI 93%) |

**Team Lead 판정**: **멍거가 더 엄밀하다.** 성장률은 기저효과에 오염되지만 증분 달러는 그렇지
않다. 다만 멍거 자신이 반론을 달았다 — **백로그/매출 배수가 AWS·MSFT 2.9x vs GCP 5.2x,
ORCL >15x**. AWS의 성장은 **이미 인도된 성장**이고 경쟁사는 **아직 인도되지 않은 계약**이다.
**→ 정직한 답: 인도 기준으로는 AWS·MSFT가 이기고, 계약 기준으로는 Google·Oracle이 이긴다.**

### 모순 ③ 순환 구조를 어디까지 말할 수 있나

| | 멍거 | 리루 |
|---|---|---|
| 주장 | 백로그 $496B의 **최소 48%**가 아마존이 $60B+ 투자한 2개사 | **구조는 🟢 확인, 규모는 ⬛ 측정 불가** |
| 근거 | OpenAI $138B + Anthropic $100B+ ÷ $496B | 10-Q는 RPO를 고객별로 쪼개지 않음. AWS의 Anthropic 매출액 ⬛ |

**Team Lead 판정**: **리루 기준을 채택한다.** "아마존이 자기 돈으로 자기 매출을 샀다"는 결론은
현재 공시로 **뒷받침되지 않는다**. 48%는 공표 약정 기준 **🔴[추정]**이며, 발행본에서
이 등급을 낮춰 쓰면 안 된다. **구조가 성립한다는 사실만으로도 충분히 무겁다** — 과장할 필요가 없다.

### 모순 ④ 이게 얼마나 위험한가 — 정면 충돌

| | 멍거 | 리루 |
|---|---|---|
| 판정 | **최대 위협.** 자산·매출·비용이 상관계수 1로 묶임. 하나의 사건이 세 곳을 동시에 때림 | **영구적 자본 손실 위험은 낮다.** 현금 손실 상한 $18.0B(+약정 $15.0B) |
| 논리 | Anthropic 마크 되돌림 → 장부가 $122.3B + 백로그 $238B + PP&E $446B 감가상각이 동시 | 손실은 **비현금**이고 사업 운영에 영향 없음. "위험한 것은 기업이 아니라 **가격**이다" |

**Team Lead 판정**: **리루가 옳고, 멍거의 경로도 유효하다 — 층위가 다르다.**
- **현금 손실**: 리루가 맞다. 실제 나간 돈은 $18.0B뿐이고 아마존 규모에서 미미하다. **파산 경로 아님.**
- **회계 레버리지**: 멍거가 맞다. **자기자본의 41.6%가 Level 3 사모지분**인 상태에서 부채를
  $133B로 늘렸다. 마크가 되돌려지면 **자기자본은 줄고 부채는 그대로다** → 신용등급·조달비용·
  주가 멀티플에 동시 작용. 리루도 이를 "가장 현실적인 경로(높음)"로 분류했다.
- **정량**: Anthropic 장부가 $190.4B가 50% 하락 → 세후 약 $72B → **자기자본의 13%가 한 분기에 증발**(🔴추정).

### 모순 ⑤ 조정 EPS가 갈린다

| | 버핏 | 리루 |
|---|---|---|
| 조정 EPS | **$1.94** (일회성까지 $1.86) | **$2.00~2.08** (일회성까지 ~$1.96) |
| 세율 가정 | 23% (10-Q의 Anthropic 개별 세부담 $15.9B에서 역산) | 17.5~21% |

**Team Lead 판정**: **단일값으로 쓰지 말고 범위로 쓴다 — 조정 희석 EPS $1.86~$2.08.**
차이는 정규화 세율 가정 하나뿐이며 어느 쪽도 틀리지 않았다. **중요한 것은 소수점이 아니라
"보고 $5.75가 아니라 $2 안팎"이라는 사실**이고, 그 점에서 두 관점은 완전히 일치한다.

## 6. 🟢 합의점 — 4명 전원 동의 (신뢰도 최고)

1. **영업 자체는 진짜다.** 일회성 $1,151M(관세환급 $640M + 에너지파생 $551M)을 다 걷어내도
   영업이익률 11.4% → **13.1%**(+170bp). 재고는 매출 +20%에 오히려 **−0.4%**. 콘텐츠 자본화
   잔액 **완전 동결**($21.3B)인데 비용 인식은 +35%. SBC/매출 3.90% → **3.01%**. (🟢)
2. **GAAP 순이익은 사업이 번 돈이 아니다.** $53.4B(85%)가 비현금 Level 3. 현금흐름표가
   이 전액($53,381M)을 순이익에서 차감한다 — **회사 스스로 비현금임을 인정**. (🟢)
3. **FCF가 마이너스로 전환했고 추세가 단조롭다.** 6분기 연속 하락, 예외 없음. (🟢)
4. **순환 구조의 요건이 성립한다.** 자금·매출·평가가 **동일 상대방**에 물려 있다. (🟢)
5. **경영진은 이 항목을 콜에서 설명하지 않았다** — 2분기 연속. 애널리스트 6명 중 아무도 묻지 않았다. (🟡)
6. **그럼에도 공시 성실성은 높다.** CFO가 파생이익을 **묻기도 전에 걷어내고** "520bp"를 제시했고,
   3개 관점이 독립 검산해 **514·515·520bp**로 수렴했다. 일회성 "$1.2B"도 10-Q 검증 $1.191B. (🟢)
