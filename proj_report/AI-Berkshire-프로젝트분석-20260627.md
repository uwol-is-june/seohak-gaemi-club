## 1. 서비스 개요

### 무엇인가

**AI Berkshire**는 Claude Code 기반의 투자 리서치 Skill 모음이다. 워런 버핏, 찰리 멍거, 단융핑(段永平), 리루(李录) — 4명의 가치투자 대가의 방법론을 AI Agent로 구현해 전문가 수준의 투자 분석을 자동 생성한다.

핵심 컨셉: **"혼자서도 투자팀을 가질 수 있다"**

```
설치 방법: skills/*.md 파일을 ~/.claude/commands/ 에 복사
사용 방법: Claude Code에서 /investment-research 삼성전자 입력
기술 스택: Claude Code + Python (financial_rigor.py) + 웹 검색
라이선스: MIT 오픈소스
GitHub: xbtlin/ai-berkshire
```

### 구조 3단계

| 레이어 | 내용 |
|--------|------|
| **Skill 레이어** (16개) | 사용자 진입점: 심층 리서치, 실적 분석, 섹터 스크리닝, 포트폴리오 관리 |
| **Agent 레이어** | 각 Skill 내부에서 4개 Agent 병렬 실행 (4명의 대가 시각 각각 독립 분석) |
| **도구 레이어** | financial_rigor.py (정밀 계산), report_audit.py (데이터 검증), stock_screener.py |

## 3. 핵심 차별화 — 왜 그냥 AI에게 묻는 것과 다른가

### 3.1 일반 AI vs AI Berkshire 비교

| 항목 | 일반 AI | AI Berkshire |
|------|---------|-------------|
| 결론 | "한편으로는... 반면에..." 양면 분석 | **강제 결론**: 매수/관망/회피 + 구체 가격대 |
| 분석 시각 | 단일 | **4명 대가 대립 구도**: 서로 다른 시각이 충돌하며 맹점 제거 |
| 편향 대응 | 없음 | **5중 반편향 메커니즘** (아래 상세) |
| 계산 정확도 | LLM 암산 (오류 빈번) | **Python decimal 정밀 계산**, 부동소수점 금지 |
| 재현성 | 매번 포맷 다름 | **동일 입력 → 동일 구조 출력**, 7개 종목 횡단 비교 가능 |
| 정보량 | 컨텍스트 1개 | **4개 Agent 병렬 = 4배 검색량·정보원·독립 시각** |

### 3.2 5중 반편향 메커니즘

| 메커니즘 | 해결하는 문제 |
|---------|------------|
| **정보 풍부도 등급 (A/B/C)** | "자료 많음 = 확신 높음" 착각 방지 |
| **멍거식 역방향 검증** | "이 회사가 망하는 시나리오는?" 강제 질문 |
| **즉시 거부 체크리스트** | 경영진 도덕성 문제 등 8개 레드라인 → 밸류에이션 무관 즉시 탈락 |
| **반컨센서스 확인** | "왜 스마트머니는 사지 않는가?" 강제 확인 |
| **여백 원칙** | 불확실하면 "모른다"고 명시, 추측으로 확실성 위장 금지 |

### 3.3 재무 데이터 정밀성 도구 (`tools/financial_rigor.py`)

| 기능 | 해결하는 문제 |
|------|------------|
| 시가총액 검산 | 주가 × 발행주식수, 단위 오류(원/달러/위안 혼용) 검출 |
| 밸류에이션 검산 | PER/PBR/ROE/FCF Yield 정밀 계산 |
| 다중 소스 교차 검증 | N개 출처 동일 데이터 자동 대조, 1% 초과 편차 시 경보 |
| 3시나리오 밸류에이션 | 낙관/중립/비관 정밀 목표주가 계산 |
| 벤포드 법칙 검출 | 재무 데이터 이상 분포 감지 |

## 6. 한국 주식시장(KRX) 도입 가능성

### 6.1 한국 시장 특성 vs 프레임워크 적합성

| 특성 | 내용 | 프레임워크 적합도 |
|------|------|----------------|
| 시장 규모 | KOSPI + KOSDAQ 약 1,500개 주요 상장사 | ✅ 홍콩주와 유사한 규모 |
| 주요 섹터 | 반도체(삼성/SK하이닉스), 자동차(현대/기아), 배터리, 화학 | ✅ 제조업 중심, 경제적 해자 분석에 적합 |
| 데이터 접근성 | 금융감독원 DART + FnGuide + 증권사 API | ⚠️ 한국어 데이터소스, 별도 연동 필요 |
| Korea Discount | 재벌 지배구조로 인한 시스템적 할인 | ✅ 이사회·경영진 평가 모듈이 핵심 분석 도구 |
| 투자자 구조 | 개인 투자자 비중 30~40%, 기관화 미국보다 낮음 | ✅ 개인 투자자 도구 수요 강함 |
| 언어 장벽 | 공시·사업보고서 한국어 | ❌ 현재 Skill 한국어 데이터소스 미지원 |

### 6.2 Korea Discount — 프레임워크가 가장 빛나는 영역

한국 상장사의 고질적 문제인 **재벌 지배구조 할인**은 정확히 AI Berkshire의 강점 영역이다.

- 삼성전자: 글로벌 반도체 1위지만 PBR이 대만 TSMC·미국 NVIDIA의 절반 이하
- 할인 원인: 이재용 일가 지배구조, 계열사 순환출자, 주주환원 불투명성
- 분석 도구: 리루(李录)의 "경영진 신뢰성 + 주주이익 일치성" 모듈 → 할인 구조를 정밀 해부 가능

**결론**: Korea Discount 해소 여부를 분석하는 프레임워크로서 AI Berkshire는 높은 부가가치를 제공한다.

## 7. 미국 주식시장(NYSE/NASDAQ) 도입 가능성

### 7.1 현재 미국주 커버리지

프로젝트 기존 보고서 기준, 미국주는 이미 실질적으로 커버되고 있다:

| 기존 미국주 분석 보고서 | 사용 Skill |
|----------------------|-----------|
| NVIDIA, Google, Meta, Microsoft, Adobe | 섹터 펀넬·체크리스트 |
| SpaceX | `/private-company-research` |
| RKLB (로켓랩) | `/investment-research` |
| 모닝스타 전 세계 AI 종목 공정가치 스캔 | `/industry-funnel` |
| Temu vs Amazon 재무 비교 | 커스텀 분석 |

**결론: 미국주는 이미 실질 검증 완료. 별도 적응 작업 거의 불필요.**

### 7.2 미국 시장 데이터소스 현황

| 데이터소스 | 현재 상태 |
|-----------|---------|
| macrotrends.net | ✅ 미국주 주요 소스로 이미 활용 |
| stockanalysis.com | ✅ 미국주 보조 소스로 이미 활용 |
| Yahoo Finance | ✅ 이미 인용 |
| SEC EDGAR (10-K/10-Q 원문) | ⚠️ 시스템화 미완성, 무료 API 존재 |
| 모닝스타 공정가치 | ✅ 전용 분석 스크립트 존재 (morningstar_fair_value.py) |

### 7.3 미국 시장에서 추가로 가능한 확장

**① 13F 추적 전용 Skill**
현재 `대사보유추적-13F-2026Q1` 보고서가 존재. 이를 `/13f-tracker` Skill로 공식화하면:
버핏·리루·단융핑의 실제 포지션 → 4대가 프레임워크로 역방향 투자 논리 해석 가능.

**② S&P500/나스닥100 전수 스크리닝**
`/quality-screen`, `/investment-checklist`는 배치 입력 지원.
영어 데이터 A급 풍부 → 전체 시장 열등 기업 제거 후 심층 분석 후보 선정 가능.

**③ 한국/홍콩주 vs 미국주 크로스마켓 비교**
기존 보고서 사례: 텐센트 vs Meta, 美团 vs Uber, 알리바바 vs Amazon.
이미 자연스럽게 진행 중인 분석 방향.

**④ SaaS/테크 특화 지표 추가**
미국 테크주 분석을 위한 ARR, NRR, Rule of 40, Magic Number 등 지표를 financial_rigor.py에 추가하면 완성도 향상.

### 7.4 미국 시장 도입 작업 목록

| 작업 | 우선순위 | 예상 공수 |
|------|---------|---------|
| SEC EDGAR API 연동 (10-K/10-Q 원문 정독) | P0 | 소 (공개 무료 API) |
| SaaS 특화 지표 추가 (ARR, NRR, Rule of 40) | P1 | 소 |
| US GAAP 구체 처리 로직 | P1 | 소 |
| `/13f-tracker` 전용 Skill 개발 | P2 | 중 |
| 영문 보고서 출력 모드 | P2 | 중 |

> **미국 시장 우선순위**: ★★★★★  
> 데이터 접근성 최고, 이미 실질 검증 완료, SEC EDGAR 무료. 가장 낮은 비용으로 가장 큰 커버리지 확장.
