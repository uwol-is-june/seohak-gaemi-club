### 사전 단계: AI 리서치 편향 자각 (반드시 실행)

리서치 시작 전, 해당 기업의 "AI 분석 가능성"을 평가하고 잠재적 데이터 편향을 식별한다.

**정보 풍부도 등급**:

| 등급 | 특징 | AI 리서치 함정 | 대응 전략 |
|------|------|--------------|----------|
| A등급 (정보 충분) | 상장 다년, 애널리스트 커버리지 풍부, 미디어 보도 밀집 | 컨센서스 과강, AI 출력이 시장 가격에 수렴 → alpha 제한 | 역방향 검증 집중: 똑똑한 투자자가 왜 안 사는가? 간과된 리스크는? |

**C등급 기업의 제1원칙 리서치법**:

공개 자료가 부족할 때, "완성된 것처럼 보이는" 보고서를 억지로 만들지 말고 다음 핵심 질문에 집중한다:
1. 고객은 누구인가? 왜 돈을 지불하는가? 대안이 있는가?
2. 재구매는 무엇이 이끄는가? 습관, 잠금(lock-in), 지속적 가치 창출 중 어느 것인가?
3. 경쟁자가 $10B을 들여 이 사업을 복제할 수 있는가?
4. 경영진이 어떤 핵심 결정을 내렸는가? 그 결정이 반영하는 판단력과 가치관은?

**편향 자기 점검 체크리스트** (리서치 전 과정에서 경계 유지):
- [ ] 내가 느끼는 "확실성"은 사업 본질에서 오는가, 자료의 양에서 오는가?
- [ ] 이 기업 자료를 절반으로 줄이면 내 결론이 바뀌는가?
- [ ] AI 출력 분석이 시장 컨센서스와 고도로 일치하는가? 그렇다면 내 정보 우위는 어디에 있는가?
- [ ] "공개 자료는 적지만 사업 본질이 탁월할 가능성"을 과소평가하고 있지는 않은가?

정보 풍부도 등급 결과를 보고서 서두에 기재하고, 최종 결론에서 "AI 리서치 신뢰도"와 "실제 투자 확실성"의 차이를 명시한다.

### 1단계: 데이터 수집

> **데이터 소스 기준**:
> - 1차 (주): macrotrends.net/stocks/charts/{TICKER}
> - 2차 (부): stockanalysis.com/stocks/{ticker}/financials
> - SEC 공시: sec.gov/cgi-bin/browse-edgar (10-K, 10-Q, 8-K)
> - 스크리닝: finviz.com/screener
> - 뉴스/리서치: finance.yahoo.com, seekingalpha.com, wsj.com
>
> **모든 재무 데이터는 두 개의 독립 소스에서 확인, 오차 >1% 시 반드시 표기**

다음 데이터를 수집한다:

1. 매출 구조: 최근 회계연도 및 최근 4분기 세그먼트 매출, 성장률, 매출총이익률
2. 재무 지표: 최근 5개년 매출, 순이익, 매출총이익률, 영업이익률, FCF(잉여현금흐름), 현금 보유액
3. 경쟁 구도: 시장점유율, 주요 경쟁사 비교
4. 비즈니스 모델 및 MOAT: 핵심 경쟁 우위 원천
5. 기술 역량: 핵심 기술 스택, R&D 투자 현황
6. 경영진: 창업자/CEO 이력, 지분율, 주요 결정 기록
7. 산업 전망: TAM(총 유효 시장), 성장 예측
8. 리스크 요인: 지정학적, 규제, 공급망 등
9. 현재 밸류에이션: 시가총액, PER, PSR, PEG, EV/Revenue
10. 롱/숏 양측 핵심 논거

#### 데이터 교차 검증 (반드시 실행 — 금융 엄밀성 도구 사용)

데이터 수집 완료 후, **반드시 `tools/financial_rigor.py`를 호출하여 핵심 데이터를 프로그래밍 방식으로 검증**한다. LLM 암산 오류를 원천 차단한다.

**반드시 검증해야 할 데이터 포인트**:
- 총 발행 주식수 (Yahoo Finance, StockAnalysis 등 최소 2개 소스 확인)
- 현재 주가 및 시가총액 (**주가 × 총 주식수 수동 계산 후 보고서 시가총액과 대조, 단위 오류 방지**)
- 최근 회계연도 매출 및 순이익 (회사 연간보고서 + 최소 1개 제3자 소스 확인)
- 현금 보유액 및 순현금 (현금 + 단기투자 − 총부채, 기준 차이 주의)
- 경영진 지분율 (경제적 권리와 의결권 구분, dual-class 구조 주의)

**강제 검증 단계 (Bash로 도구 호출)**:

Step 1 — 시가총액 검증 (정밀 십진수, 부동소수점 아님):
```bash
python3 ~/Desktop/reality-escape-device/tools/financial_rigor.py verify-market-cap \
  --price {주가} --shares {총주식수} --reported {보고 시가총액} --currency USD
```

Step 2 — 핵심 데이터 다중 소스 교차 검증:
```bash
python3 ~/Desktop/reality-escape-device/tools/financial_rigor.py cross-validate \
  --field {필드명} --values '{"소스1": 수치, "소스2": 수치}' --unit {단위}
```
매출, 순이익, 현금 보유액 각각 실행.

Step 3 — 밸류에이션 지표 정밀 검증 (PER/PBR/ROE/FCF Yield 등):
```bash
python3 ~/Desktop/reality-escape-device/tools/financial_rigor.py verify-valuation \
  --price {주가} --eps {EPS} --bvps {주당순자산} --fcf-per-share {주당FCF} --dividend {주당배당}
```

**검증 규칙**:
1. 각 핵심 데이터 포인트는 최소 2개의 독립 소스 필요
2. 소스 간 차이 발견 시, 회사 연간보고서(10-K)/SEC 공시 데이터를 우선하고 차이 이유를 명시
3. **계산이 포함된 모든 데이터는 반드시 도구로 검증, LLM 암산 금지**
4. 도구 출력 결과를 보고서 부록 "핵심 데이터 교차 검증 기록"에 직접 삽입
5. 도구가 ❌ 과대 편차를 보고하면 원인 파악 후에만 분석 진행

**흔한 오류 방지**:
- 시가총액 단위: $B(십억) vs $T(조), 0 하나 빠뜨리거나 추가하기 쉬움
- FCF 기준: 소스마다 자본적 지출 정의 다를 수 있음 (리스, 인수 포함 여부 등)
- 부채 기준: 운용 리스 부채 포함 여부
- 지분율: Dual-class 주식 기업의 경제적 권리 ≠ 의결권

### 2단계: 사업 본질 분석 — 단융핑의 "올바른 사업"

분석 요점:
- 한 문장으로 이 사업의 본질을 정의한다
- 매출 구조 분해 (표/차트)
- 5개년 수익성 추이 (차트)
- 비즈니스 모델 캔버스: 일회성 판매 vs 구독/반복 구매? 하드웨어 vs 소프트웨어 vs 플랫폼?
- 생태계 점착성 / 고객 잠금(lock-in) 강도
- 매출총이익률 수준과 동종업계 비교, 높거나 낮은 이유 설명
- 운영 레버리지 분석
- **단융핑식 질문**: 이 사업이 좋은 이유는 무엇인가? 한 문장으로 표현하면?

**주요 참고 기업 예시** (비교 벤치마크):
- 소프트웨어/플랫폼: MSFT, GOOGL, META, AAPL
- 소비재/리테일: COST, WMT, AMZN
- 금융: BRK.B, JPM, V
- 성장주: NVDA, NFLX, TSLA
- 헬스케어: UNH, JNJ

### 3단계: MOAT(경제적 해자) 평가 — 버핏의 "경제적 해자"

다섯 가지 MOAT 유형을 하나씩 검증한다:

| MOAT 유형 | 검증 방법 |
|-----------|---------|
| 브랜드 / 가격결정력 | 판매량 손실 없이 가격을 올릴 수 있는가? |
| 전환 비용 | 고객이 경쟁사로 이동하는 비용은 얼마나 높은가? |
| 네트워크 효과 | 사용자가 많아질수록 제품이 더 좋아지는가? |
| 규모의 경제 | 규모에서 오는 비용 우위는 얼마나 큰가? |
| 기술 / 특허 장벽 | 기술 선도가 몇 년인가? 복제 가능한가? |

MOAT 추이 분석: 지난 5년간 넓어졌는가, 좁아졌는가? 향후 5년 전망.

**버핏식 질문**: 10년 후 이 해자는 여전히 존재하는가? 무엇이 그것을 파괴할 수 있는가?

### 4단계: 역발상 사고와 리스크 목록 — 멍거의 "거꾸로 생각하기"

- "이 기업이 실패할 수 있는 모든 경로" 나열 (표: 경로/확률/영향 정도)
- 역사적 유사 사례: 역사상 유사한 위치에 있었던 기업, 그 결말은?
- 학제간 분석: 네트워크 효과 이론, 기술 채택 곡선, 경쟁 게임 이론 등 모델로 교차 검증
- 편향 자기 점검: 서사 편향, 앵커링 효과, 생존자 편향
- 숏(공매도) 측 핵심 논거 수집

**멍거식 질문**: 내가 가장 틀리기 쉬운 부분은 어디인가? 똑똑한 투자자가 왜 이 기업을 사지 않거나 공매도하는가?

### 5단계: 경영진 평가 — 단융핑의 "올바른 사람" + 버핏의 "경영진 정직성"

4. 최종 완성 보고서를 `reports/{기업명}/{기업명}-research-{YYYYMMDD}.md` 에 저장한다
5. 결론은 명확하게 — 매수/관망/회피 권고를 회피하지 않는다
6. 밸류에이션 섹션은 구체적인 가격 범위를 제시한다
7. **보고서 서두**에 "정보 풍부도 등급" (A/B/C)과 "AI 리서치 한계 선언"을 반드시 포함한다
8. **보고서 말미**에 "AI 분석 신뢰도"와 "투자 확실성"을 구분한다 — 전자는 자료량에 달려 있고, 후자는 사업 본질에 달려 있다. 보고서의 어떤 결론이 충분한 데이터에 기반하고, 어떤 결론이 제한된 정보의 추론인지 독자에게 명확히 알린다
9. 기업이 C등급(정보 희박)에 해당하면, 보고서 말미에 "현장 검증 필요 질문 목록"을 반드시 기재한다 — 현장 조사, 제품 직접 사용, 공급망 인터뷰 등으로 AI 사각지대를 보완하도록 독자에게 권고

## 데이터 표본 검사 (게시 전 필수 프로세스)

보고서를 파일에 저장한 후, **반드시** 데이터 표본 검사를 실행하고, 통과 후에만 게시한다:

**Step 1 — 표본 검사 목록 추출 (15% 랜덤 샘플링)**:
```bash
python3 ~/Desktop/reality-escape-device/tools/report_audit.py extract \
  --report <보고서 파일 경로>
```
출력: JSON 템플릿, 각 항목에 `fetched_value`(미입력) 포함.

**Step 2 — 데이터 검수**:
목록의 각 데이터 포인트에 대해, 다음 소스에서 데이터 취득:
- 1차: macrotrends.net
- 2차: stockanalysis.com
- SEC 공시: sec.gov (해당 시)

`fetched_value` / `fetched_source` / `fetched_value2` / `fetched_source2` 항목을 채운다.

**Step 3 — 판정 출력**:
```bash
python3 ~/Desktop/reality-escape-device/tools/report_audit.py verdict \
  --results '<완성된 JSON>' \
  --report <보고서 파일명>
```

- **[게시 가능]**: 모든 표본 포인트 편차 ≤ 1% → 보고서 게시 가능
- **[반려]**: 어느 포인트든 편차 > 1% → 해당 데이터 수정 후 재검사, 통과할 때까지 반복
