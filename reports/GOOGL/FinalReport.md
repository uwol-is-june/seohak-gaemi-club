## 4. 차원별 분석 요약

**단융핑 — 비즈니스 모델 (01 + Q3)**
1. Search 의 YoY 증가액이 Q2 까지 4분기 연속 커졌으나(01 §2.1), **Q3 에 꺾였다** — QoQ +0.1%, 증가액 2분기 연속 축소 🟢. 2년 누적으로 보면 30.4%→28.3% 로 −2.1pp 라 기저효과가 상당 부분이지만 전부는 아니다.
2. Cloud 에 TPU 하드웨어가 섞였는데도 마진이 올랐다(35.6→36.2%) — 01 이 "변론의 가장 약한 고리"로 꼽은 Cloud 매출의 질 우려가 이번 분기엔 마진으로 반박됐다.
3. 쿼리는 5년 최고, AI Mode 는 아직 화폐화가 덜 됐다(경영진 인정 🟡).
4. 강세 변론은 **조건부 성립** — 깨는 신호: Cloud 마진 2분기 연속 30% 미만 · 재고/Cloud 매출 50% 초과 · TPU 제외 성장률 공개 시 40% 미만.

**버핏 — 재무·밸류에이션 (02 + Q3)**
1. T1 유지(10년 실적 기반 5축 불변).
2. FCF 적자의 본체는 capex $51.4B. 재고(−$3.2B)·기타자산(−$7.8B ⬛)을 빼면 +$2.0B 🟢[계산].
3. 감가상각 +49% — 2027 세후 EPS −$1.27, 2028 최대 −$3.34 영향 가능 🔴[추정]. **Bear 에만 반영**(이중 차감 방지).
4. IV $338.92 → **$323.45**: 원인은 기준 EPS 교체($11.61→$11.08) **하나**다. 목표 PER·성장률·확률은 그대로.

**멍거 — 산업·경쟁 (03 + Q3)**
1. GCP +103% vs Azure +48% 는 하드웨어 포함 여부가 달라 직접 비교 불가 — 원가 우위의 증거는 성장률이 아니라 **마진**이다.
2. 분기 광고 매출이 Meta 와 사실상 같아졌다(Search $63.4B vs Meta $63.1B 🟡). 03 이 짚은 "예산을 가져가는 쪽은 Meta" 가 숫자로 확인.

4. 03 의 인버전 1순위 "자본 소각" 경로가 한 분기 더 진행됐다.

**리루 — 리스크·경영진 (04 + Q3)**

## 5. 투자 논지

### Bull Case (01 강세 변론 + Q3 확인분)
1. **Cloud 마진 36.2%** — 하드웨어가 섞이고도 상승, Cloud 영업이익 증가액($7.5B)이 Services 증가액($5.6B)을 넘었다 🟢
2. **백로그 $561B (+9% QoQ)**, 24개월 내 ~55% 인식 → 연 $150B+ 🟡 = TTM Cloud 매출의 약 1.7배
3. **검색 해자 손상 증거 없음** — Services 영업이익률 YoY +2.2pp, TAC율 안정 🟢
4. **현재가가 버크셔 증자 단가(~$350)보다 16% 낮다** (모방 근거 아님) · Q3 ATM 평균 발행가 ~$344 보다도 15% 낮다
5. **아직 가격에 없는 것**: TPU 외부 판매, AI 지면 광고, 에이전트 커머스, Apple–Gemini ⬛
6. **5년 경로** 🔴: 정규화 EPS 연 18% · 출구 22x → 연 ≈12.8% (01 §C · 실적 전 기준)
7. 시간외 PER 26.4x = 10년 중앙값 — "역사적으로 평범한 배수에 사상 최고 Cloud 점유율"

### Bear Case
1. **이익 미스가 진짜다** — 정규화 EPS 컨센서스 −11%, 기저 성장 ~+9% 🔴
2. **Search QoQ 정체** — 기저효과로 다 설명되지 않는다. 레드라인 #3(2분기 연속 <10%)까지 2pp
3. **FCF 2분기 연속 음수**(−$5.9B, −$9.1B) · capex 매출의 40% · 장기부채 $125B
4. **희석 가정 이탈** — 9개월 +1.70%, ATM 이 설명보다 2.3배 사용됨
5. **감가상각 해일** — 2027~28 EPS 를 $1.3~3.3 깎을 수 있다 🔴
6. **핵심 4개 지표 비공개** — 회수를 숫자로 보여주지 않는 회사에 회수를 믿고 산다
7. 광고 경쟁에서 Meta 에 밀린다

## 8. 결론

Q3 는 논제의 두 얼굴을 동시에 보여줬다. Cloud 는 하드웨어가 섞이고도 마진 36.2% 를 내며 capex 가 회수되기 시작했다는 첫 증거를 냈다. 반면 이익은 컨센서스를 11% 밑돌았고, Search 는 정체했으며, FCF 는 두 분기 연속 음수였다. 그 차이는 증자로 메웠다. 기준 EPS 를 실적으로 바꾸자 내재가치는 $323.45 로 내려갔다. 시간외 $292.50 은 그 90% 로 T1 요구 범위 안이다. 그래서 **보유 1주는 유지한다.** 증액은 정규장 $291.10 이하에서, Cloud 마진과 Search 성장이 둘 다 버틸 때만 한다. 다음 시험은 11월 초 10-Q 다.

> 버핏: "The worst sort of business is one that grows rapidly, requires significant capital to engender the growth, and then earns little or no money." — Q3 의 Cloud 마진은 Alphabet 이 아직 이 문장의 반대편에 있다는 증거이고, Q3 의 FCF 는 그 경계가 가까워졌다는 증거다.
> 리루: "진정한 위험은 주가 변동이 아니라 영구적 자본 손실이다."
