# TASK

각 태스크에 `[TASK-N]` 부여 — 지칭용이고 완료돼도 번호를 재사용하지 않는다.
모델은 `(O)` Opus · `(S)` Sonnet · `(H)` Haiku, 상태는 `[ ]` 예정 · `[~]` 진행중.
완료한 항목은 지운다 — 이력은 `git log -p docs/TASK.md` 에서 본다.

## 예정

### 실험실 — 이번 주 추천 종목 (2026-10-02 합의)

> **목적**: 기존 시스템(4대가·퀄리티 티어·래더)과 **독립된 두 번째 의견**을 매주 1종목 내고,
> 받든 안 받든 전부 박제해 **실험실 vs 무작위 대조군 vs SPY**로 채점한다.
> 효과가 없으면 접는다(TASK-191).
>
> **v1 규칙 요약** (TASK-181에서 문서로 고정)
> - 유니버스: **S&P 500만**. 관찰 종목·판단 기록부는 **보지 않는다**(기존 판단에 끌려가는 걸 막기 위해)
> - 제외: FCF 음수 · 10년 이력 없음 · **12-1M 수익률 S&P 500 하위 20%**(떨어지는 칼 = 모멘텀 안전장치)
> - 순위: **퀄리티 + 밸류 동일 가중** (모멘텀은 점수에 넣지 않는다 — 추격 방지)
> - 목표가: `FCF/주 ÷ 10년 중앙 FCF 수익률`. **기대 상승 +15% 미만 탈락**
> - LLM: **반대 측 검증만** — 증거 있는 결격 사유로 탈락만 가능, 승격 불가
> - 결과: 1종목 또는 **"이번 주 없음"**(정상 결과)
> - 픽 한 건 = 목표가 · 철회선(−15% 또는 다음 주 통과 후보 이탈) · 호라이즌 12M 고정 · 컨센서스(표시만)
>
> 구축(TASK-181~190)은 2026-10-02 완료 — 이력은 `git log -p docs/TASK.md`. 매주 월 09:05 자동 실행 중.
> 🧑 = 사용자 확인이 필요한 체크포인트.
