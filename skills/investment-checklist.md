# 버핏 가치투자 매수 전 체크리스트

$ARGUMENTS 에 대해 버핏 가치투자 매수 전 체크리스트 분석을 실행합니다.

**입력 형식**: 단일 또는 복수 종목, 쉼표/공백으로 구분. 예: `Apple, Microsoft, NVDA` 또는 `AAPL MSFT GOOGL`

## 실행 절차

### ⓪ 사전 점검: 데이터 소스 접근 확인

```bash
python3 tools/site_preflight.py quality-screen
```

차단된 소스가 있으면 스크립트가 대체 소스를 출력한다. 진행은 계속하되, **다음 규칙을 반드시 지킨다(hard rule):**

> **⛔ fetch 실패·차단으로 값을 못 구한 셀은 `⬛`(데이터부족)으로 남긴다. 절대 기억(parametric
> memory)이나 추측으로 채우지 않는다.** 6게이트 표를 "완성"하는 것보다 빈칸이 정직한 것이다. 데이터를
> 못 구한 게이트는 판정 보류(⬛)로 명시하고, 임의 수치로 통과/미통과를 매기지 않는다.
> (근거: [data-confidence.md](data-confidence.md) 핵심 원칙 4 — 공백은 채우지 말고 남긴다.)

---

### 1단계: 입력 파싱 — 분석 대상 종목 확인

$ARGUMENTS 에서 모든 종목명/티커를 파싱한다. 각 종목에 대해 확인:
- 정식 회사명, 티커 심볼, 상장 거래소 (NYSE / NASDAQ)
- 비상장 종목은 "비상장"으로 표시하고 간략한 설명(간접 투자 경로 존재 여부 포함) 후 풀 체크리스트 생략

### 1.5단계: AI 리서치 편향 경보

각 종목의 "정보 풍부도"를 A/B/C로 신속 평가하고 보고서에 명기한다:

| 등급 | 판단 기준 | 체크리스트 적용 방식 |
|------|----------|-------------------|
| A급 | 상장 다년, 데이터 충분 | 정상 실행. 단, "컨센서스 함정" 주의 — 모든 지표가 명확해 보인다고 확실한 것은 아님 |
| B급 | 데이터 제한, 추정 필요 | 추정 지표마다 신뢰도 명기. "좋은 사업" 판단 시 데이터 신뢰도를 가중 반영 |
| C급 | 정보 극히 희소 | 6개 관문 표를 억지로 채우지 않음. "데이터 부족, 판단 불가"를 솔직히 표기. 검증 가능한 핵심 문제에만 집중 |

**핵심 원칙**: 체크리스트의 목표는 **나쁜 선택을 걸러내는 것**이다. C급 종목의 경우 "데이터 부족"은 "탈락"도 "통과"도 아니다 — "회색지대, 1차 정보 보완 필요"로 솔직히 표기한다. AI가 표를 채우지 못한다는 이유만으로 부결 처리하지 않는다.

단영평(Duan Yongping) 왈: "'모른다'에는 두 종류가 있다 — 사업이 너무 복잡해서 정말 모르는 것과, 아직 충분히 공부하지 않은 것." AI 리서치의 한계는 '정보 부족'을 '이해 불가'와 혼동하기 쉽다는 점이다.

### 2단계: 병렬 데이터 수집

Task 도구를 사용해 **각 종목마다** 독립 백그라운드 에이전트를 동시에 실행한다.

> **토큰 예산 ([token-budget.md](token-budget.md))** — 종목 수만큼 팬아웃되므로 종목당 비용이
> 그대로 곱해진다. 아래는 권고가 아니라 상한이다:
>
> - **종목 1개면 에이전트를 띄우지 않고 본체에서 직접 수집**한다(에이전트 오버헤드가 더 크다).
>   2개 이상일 때만 팬아웃하고, **동시 실행은 6개까지**.
> - 🔴 **에이전트는 하위 에이전트를 스폰하지 않는다** (TB-1). 이 금지를 에이전트 프롬프트에
>   **인라인으로** 박는다 — 에이전트는 이 문서를 읽지 않는다.
> - **에이전트 1개당 조사 상한**: WebSearch 10회 · WebFetch 8회 · Bash 8회.
>   8개 항목을 각각 따로 검색하지 말고 **한 소스에서 여러 항목을 한 번에** 걷는다.
> - 결과는 **Write 1회**로 저장한다(Edit 반복 금지 · TB-5). 재시도는 종목당 1회까지(TB-2).
> - 못 구한 항목은 `⬛`로 남긴다 — 상한은 정확도보다 우선하지 않는다.
> - ⚠️ 종목 1개 기준 정상 범위는 **2~5M 토큰**이다.

각 에이전트가 수집할 항목:

1. **수익성**: ROE (5~10년 추이), 매출총이익률, 순이익률, Free Cash Flow
2. **밸류에이션**: 현재 주가, 시가총액, PER (TTM), Forward PER, PBR, 배당수익률
3. **성장 추이**: 최근 3년 매출/이익 성장률
4. **재무 건전성**: 부채 수준, CAPEX 요구 수준, 현금 보유액, 순현금/순부채
5. **경쟁 구도**: 시장점유율, 주요 경쟁사, 점유율 변화 추이
6. **해자(MOAT) 근거**: 브랜드/전환비용/네트워크 효과/규모의 경제/기술 장벽의 구체적 증거
7. **경영진 이력**: CEO 경력, 주요 의사결정, 지분 보유, 자본 배분 실적
8. **최신 동향**: 최근 6개월 중요 이벤트 (실적, M&A, 규제, 경영진 교체 등)

**데이터 소스 우선순위**:
- 1차: macrotrends.net/stocks/charts/{TICKER} (장기 재무 추이)
- 2차: stockanalysis.com/stocks/{ticker}/financials (재무제표 상세)
- SEC 공시: sec.gov/cgi-bin/browse-edgar (10-K, 10-Q, 8-K)
- 스크리닝: finviz.com/screener
- 뉴스: finance.yahoo.com, seekingalpha.com, wsj.com

### 3단계: 종목별 6개 관문 체크리스트 실행

상장된 각 종목에 대해 6개 관문을 순서대로 통과시킨다:

---

#### 관문 1: 이 사업을 이해할 수 있는가 (능력 범위, Circle of Competence)

반드시 답해야 할 질문:
- [ ] 이 회사가 어떻게 돈을 버는지 한 문장으로 설명할 수 있는가?
- [ ] 10년 후에도 높은 확률로 같은 사업을 하고 있을 것인가?
- [ ] 성패를 가르는 핵심 변수는 무엇인가?
- [ ] 이 산업에 대한 이해가 깊은 연구에서 나온 것인가, 아니면 주워들은 정보인가?

**평가 기준** (★1-5):
- ★★★★★: 비즈니스 모델이 극히 단순명료, 10년 확실성 높음 (예: Coca-Cola — 음료 제조·판매, Visa — 결제 네트워크 수수료)
- ★★★★☆: 모델은 명확하지만 일정 전문 지식이 필요
- ★★★☆☆: 이해는 가능하나 10년 확실성 낮음, 산업 변화 속도 빠름
- ★★☆☆☆: 사업 부문 복잡하거나 산업 격변 중, 미래 예측 어려움
- ★☆☆☆☆: 능력 범위 완전 밖

**하드 거부**: 수익 구조 자체를 설명할 수 없다면 즉시 "능력 범위 외, 분석 불가"로 표시한다.

---

#### 관문 2: 좋은 사업인가 (경제적 특성)

데이터로 말한다. **핵심 지표는 반드시 도구로 정확히 계산**한다:

```bash
python3 tools/financial_rigor.py verify-valuation \
  --price {주가} --eps {EPS} --bvps {주당순자산} --fcf-per-share {주당FCF} --dividend {주당배당}
```

| 지표 | 해당 종목 수치 | 기준값 | 판정 |
|------|-------------|--------|------|
| ROE (5년 평균) | | >15% 양호, >20% 탁월 | |
| 매출총이익률 (Gross Margin) | | >40%는 가격결정력 시사 | |
| Free Cash Flow | | 지속 플러스, 순이익과 근접 | |
| CAPEX 강도 | | 경자산(Asset-light) 우선 | |
| 부채 수준 | | 이자부부채 / 순이익 < 3년 | |

**평가 기준** (★1-5):
- ★★★★★: ROE>25%, 고마진, 강한 FCF, 경자산, 저부채 (전항목 충족)
- ★★★★☆: 4개 항목 충족
- ★★★☆☆: 3개 항목 충족
- ★★☆☆☆: 2개 항목 충족 또는 추이 악화 중
- ★☆☆☆☆: 대다수 미충족 또는 FCF 지속 마이너스

---

#### 관문 3: 해자(MOAT)는 충분히 깊은가 (경쟁 우위)

항목별 점검:

| MOAT 유형 | 보유 여부 | 구체적 근거 | 넓어지는 중인가 vs 좁아지는 중인가 |
|-----------|---------|-----------|--------------------------------|
| 브랜드 / 가격결정력 | | | |
| 전환비용 (Switching Cost) | | | |
| 네트워크 효과 (Network Effect) | | | |
| 비용 / 규모의 경제 | | | |
| 기술 / 특허 장벽 | | | |

추가 검증: 경쟁사에 $10B을 줬을 때 이 사업을 복제할 수 있는가?

**평가 기준** (★1-5):
- ★★★★★: 복수의 MOAT가 중첩되어 있고 넓어지는 중
- ★★★★☆: 최소 한 개의 강한 MOAT가 안정적으로 유지
- ★★★☆☆: MOAT가 있으나 충분히 깊지 않거나 추이 불분명
- ★★☆☆☆: MOAT가 침식되고 있음
- ★☆☆☆☆: 뚜렷한 MOAT 없음

---

#### 관문 4: 경영진을 신뢰할 수 있는가 (사람의 문제)

| 점검 항목 | 평가 |
|---------|------|
| 정직성 (약속 vs 실행) | |
| 자본 배분 능력 (자사주매입 / 배당 / M&A 실적) | |
| 주주 이익 우선 여부 (지분 보유, 보상 구조) | |
| 오너십 마인드셋 (창업자 vs 고용 경영인) | |
| 기업 지배구조 (내부거래, 감사, 회계 투명성) | |
| CEO 없이도 회사가 정상 운영되는가? | |

**평가 기준** (★1-5):
- ★★★★★: 창업자 경영, 탁월한 자본 배분, 이해관계 완전 일치
- ★★★★☆: 경영진 우수하나 소소한 흠결 있음
- ★★★☆☆: 경영진 합격 수준이나 지배구조 우려 있음
- ★★☆☆☆: 신뢰성 또는 지배구조 문제 존재
- ★☆☆☆☆: 심각한 신뢰성 문제 (→ 하드 거부)

---

#### 관문 5: 가격은 충분히 저렴한가 (안전마진, Margin of Safety)

| 지표 | 수치 | 역사적 분위 | 판정 |
|------|------|-----------|------|
| PER (TTM) | | | |
| Forward PER | | | |
| PBR | | | |
| 배당수익률 | | | |
| FCF Yield | | | |

추가 검증 (**반드시 도구로 정확히 계산, 암산 금지**):
```bash
python3 tools/financial_rigor.py three-scenario \
  --price {주가} --eps {EPS} --shares {발행주식수B} \
  --growth {낙관} {중립} {비관} --pe {낙관PE} {중립PE} {비관PE} --currency USD
```
- 3가지 시나리오별 밸류에이션 범위 (도구 출력 결과 인용)
- 판단이 틀렸을 경우 현재가에 매수 시 최대 손실은 얼마인가?
- 주가가 반토막 났을 때 추가 매수할 수 있는가?

**평가 기준** (★1-5):
- ★★★★★: 내재가치 대비 50% 이하, 극단적 안전마진
- ★★★★☆: 내재가치 대비 70% 수준, 양호한 안전마진
- ★★★☆☆: 적정 밸류에이션, 안전마진 보통
- ★★☆☆☆: 다소 비쌈, 안전마진 부족
- ★☆☆☆☆: 심각한 고평가

---

#### 관문 6: 포지션 규모와 의사결정 규율 (감정 통제 방지)

다음 감정 신호를 점검한다:
- [ ] FOMO 때문에 매수하려는 것은 아닌가?
- [ ] 타인의 추천 때문에 매수하려는 것은 아닌가?
- [ ] 5년간 거래 정지가 되어도 괜찮은가?
- [ ] 매수 논거를 200자(또는 영문 200단어) 이내로 명확히 쓸 수 있는가?

### 4단계: 거울 테스트 (Mirror Test)

각 종목에 대해 거울 테스트 문장을 작성한다:

> "나는 $___ 에 ___ 주식을 매수한다. 이유:
> 1. 이 사업의 본질은 ___이며, 나는 이를 이해한다;
> 2. 이 회사의 MOAT는 ___이며, 현재 넓어지는 중 / 좁아지는 중이다;
> 3. 경영진은 ___, 신뢰할 수 있다 / 없다;
> 4. 현재 주가는 내재가치 대비 약 ___%이며, 충분한 안전마진이 있다 / 없다;
> 5. 내 판단이 틀렸을 경우 하방 리스크는 통제 가능하다 / 불가능하다, 이유: ___."

**5개 문장을 완성하지 못하면 = 매수하지 않는다.** "통과" 또는 "미통과"를 명확히 표기한다.

---

### 5단계: 즉각 거부 체크리스트

각 종목에 대해 항목별 점검. 하나라도 해당하면 즉시 "거부"로 표기:

- [ ] 이 회사가 어떻게 돈을 버는지 설명할 수 없다
- [ ] 연속 3년 FCF가 마이너스이며 개선 징후가 없다
- [ ] 경영진에 신뢰성 문제가 있다
- [ ] 경쟁 우위가 되돌리기 어려운 방식으로 침식되고 있다
- [ ] "다음 매수자가 더 높은 가격에 사줄 것"에 의존해야 수익이 나는 구조 (모멘텀 베팅)
- [ ] 이 투자가 0이 됐을 때의 결과를 감당할 수 없다
- [ ] 매수 이유가 주로 "모두가 사고 있어서" 또는 "최근 잘 올랐으니까"다
- [ ] 매수 논거를 200단어 이내로 쓸 수 없다

---

### 6단계: 종합 비교표 출력 (복수 종목 시 필수)

복수 종목을 분석한 경우 반드시 비교 총람표를 생성한다:

| 종목 | 체크리스트 통과? | 능력 범위 | 좋은 사업 | MOAT | 경영진 | 안전마진 | 핵심 결론 |
|------|--------------|---------|---------|------|--------|---------|---------|
| | | ★☆☆☆☆ | ★☆☆☆☆ | ★☆☆☆☆ | ★☆☆☆☆ | ★☆☆☆☆ | |

---

### 7단계: 최종 결론 및 파일 저장

각 종목에 대해 명확한 결론을 제시한다 (회피 없이):
- ✅ **체크리스트 통과** (X/6관문) — 심층 리서치 단계로 진입 가능
- ❌ **체크리스트 미통과** — 어떤 레드라인이 발동됐는지 명시
- ❓ **회색지대** — 핵심 논쟁 포인트가 무엇인지, 투자자가 직접 판단해야 할 사항이 무엇인지 명시
- N/A — 비상장 / 매수 불가

**섹터 마커(대시보드 파싱 계약)**: 보고서 H1 제목 **바로 다음 줄**에 `<!-- meta sector: {섹터명} -->` 를 남긴다. 섹터명은 이 종목이 나온 섹터 리서치 보고서 파일명의 섹터 토큰(`reports/{섹터}-funnel-{YYYYMMDD}.md`)과 **정확히 같은 표기**를 쓴다(예: `Defense`, `GLP-1-Obesity`). 퍼널을 거치지 않고 종목부터 시작했다면 그 종목이 속한 섹터명을 같은 어휘로 적고, 판단이 어려우면 마커를 생략한다(임의 신조어 금지 — 대시보드에서 섹터가 갈린다). 이 마커로 대시보드가 종목을 분야·섹터 위계에 자동 배치한다(`tools/sync_sector_map.py`).

완성된 보고서를 `reports/{회사명}/{회사명}-checklist-{YYYYMMDD}.md` 에 저장한다. 회사 폴더가 없으면 먼저 생성한다. 복수 종목 비교 시 주요 종목 이름을 대표 폴더명으로 사용하고, 파일명에 전체 종목을 명기한다 (예: `reports/Apple/Apple-MSFT-GOOGL-checklist-20260627.md`).

## 출력 형식 요건

1. 각 종목마다 독립 챕터: 6개 관문 평가표 + 핵심 데이터 표 + 주요 리스크 (3~5개) + 거울 테스트 + 명확한 결론
2. 복수 종목의 경우 마지막에 총람 비교표 추가
3. 모든 평가는 ★ 기호 사용 (★1~5), 반별 없음
4. 데이터에는 출처와 날짜를 명기, 추정치는 반드시 "추정"으로 표시
5. 결말에 버핏의 명언 인용: "투자의 제1원칙은 돈을 잃지 않는 것이다 (Rule No. 1: Never lose money)"
6. 문체: 직접적, 날카롭게, 군더더기 없이. 버핏 / 멍거 / 단영평(Duan Yongping) / 리루(Li Lu)의 어록을 군데군데 인용

## 핵심 원칙

- **놓치더라도 틀리지 말라**: 체크리스트의 목표는 나쁜 선택을 제거하는 것이지, 최선을 찾는 것이 아니다
- **능력 범위에 솔직하라**: 모르면 모른다고 하라, 억지로 분석하지 말라
- **안전마진은 생명선이다**: 좋은 회사도 비싸게 사면 손해본다
- **거울 테스트는 생략 불가**: 이유를 명확히 말할 수 없으면 사지 않는다, 예외 없음

## 콜 원장 기록 (필수 · TASK-38)

체크리스트 최종 판정을 **콜 원장**(`data/calls.jsonl`)에 박제해 사후 채점(대시보드 트랙레코드)이
가능하게 한다. 판정을 파일에 저장한 직후, 각 **상장** 종목마다 아래를 실행한다:

```bash
python3 tools/record_call.py \
  --ticker {티커} --skill investment-checklist \
  --report reports/{회사}/{파일}.md \
  --call {buy|hold|avoid} --conviction "{안전마진 ★평점}"
```

- **판정 → call 매핑**: 체크리스트 통과 → `buy` · 회색지대 → `hold` · 미통과/거부 → `avoid`.
- 🔴 **관문5(안전마진) 미통과면 다른 관문을 다 통과해도 `buy`가 아니라 `hold`다.**
  안전마진은 매수 판단의 생명선이므로 다른 관문의 우수함으로 상계되지 않는다.
- `buy`는 "현재가에 매수 권고"라는 분석 결론일 뿐 **사용자 보유를 의미하지 않는다** —
  콜을 근거로 `reports/track-record.md`의 '보유 포지션'에 올리지 않는다.
- `priceAtCall`은 도구가 그 시점 시세를 Yahoo에서 fetch해 박제한다(**모델 기억값 금지**).
  시세를 못 구하면 `--price {주가}`로 직접 지정한다(불변 값).
- 관문5(안전마진) 3-시나리오에서 목표가 밴드가 나오면
  `--target-low {중립 하단} --target-high {낙관 상단} --horizon-months 24`를 덧붙인다(선택).
- **회피(avoid)도 반드시 기록** — "안 산 게 옳았는지"까지 채점해 생존편향을 막는다.
- 원장은 append-only·불변이다. 이미 기록한 콜을 수정하지 않는다(재평가는 새 콜로 추가).

## 데이터 신뢰도 표기 (필수)

본 보고서는 **[data-confidence.md](data-confidence.md) 표준**을 적용한다:

- 핵심 수치·판단 옆에 **신뢰도 등급 + 유형 태그**를 단다 — 🟢높음(2+독립출처 교차검증 또는 SEC 원문 직접 확인) / 🟡보통(단일출처·경미편차·해석여지) / 🔴낮음(추정·미확정주장·구데이터) / ⬛데이터부족(공백 유지) + `[사실]`/`[추정]`/`[주장]`/`[의견]`. 예: `FY2025 매출 $0.68M 🟢[사실]`, `2030 TAM 🔴[추정]`, `사기 의혹 🔴[주장](공매도, 미확정)`.
- **출처 독립성 주의**: 회사 IR·보도자료와 집계 사이트는 둘 다 회사 공시 파생이라 상호 독립이 아니다 → 🟢은 SEC 원문 직접 확인 또는 계보가 다른 두 출처를 요구한다.
- 보고서 **말미에 기계 판독용 신뢰도 요약 블록**을 포함한다(대시보드가 파싱):

      <!-- confidence-summary
      high: N
      medium: N
      low: N
      gap: N
      verdict: 높음|보통|낮음
      -->

  (아래에 사람용 요약 몇 줄: 등급별 개수 + 종합 판단 근거)
- ⚠️ verdict는 **"데이터 신뢰도"이며 "투자 매력도"가 아니다.** 두 축은 독립이며 자주 어긋난다. `[의견]` 태그는 verdict 계산 분모에서 제외한다.
