## 예정

- [ ] **[TASK-135] (O) 시안의 화면 레이아웃 반영 — 제품 단위 변경**
  리뉴얼(TASK-125~134)은 **토큰·어휘까지** 끝났다. 시안에서 보여준 아래 넷은
  스타일이 아니라 **화면이 무엇을 보여주는가**를 바꾸는 일이라 따로 둔다:
  - 홈 히어로 — 지금 홈은 포트폴리오가 주인공이다. 시안은 "오늘 볼 건 하나"
    (진입 임박 + 건강도 급락 종목 1건)를 맨 위에 세운다.
  - 1차까지 거리 **게이지** — 지금은 `진입까지 −10.6% → $204.67` 텍스트뿐.
  - AND 조건 **체크리스트** — 지금은 칩·산문. 몇 개 중 몇 개 충족인지가 안 보인다.
  - 래더를 **신뢰구간 선그래프**로 — 지금 LadderChart는 가격 축 다이어그램이라
    "과거에 이 구간에 왔었나"가 안 보인다. 체결확률의 근거가 같은 화면에 없다.

  ⚠️ 시안 아티팩트는 삭제됐다. 기준은 `docs/DESIGN-toss.md` 와 위 서술뿐이다.
  ⚠️ 트랙레코드는 **이미 카드형이다** — 진단 때 "11열 마크다운 표"라고 적은 건
  `reports/track-record.md`(사람이 읽는 문서)였지 대시보드 화면이 아니었다.
