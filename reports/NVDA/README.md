## 최종 결론

NVDA는 최상급 사업이며 시장의 모트 지도는 낡았다 — 모트는 CUDA에서 랙스케일 인터커넥트로 이전했고(네트워킹 +199% YoY), 마진 하락은 이미 끝났다(GM 74.9% 복귀). 문제는 사업이 아니라 **비대칭**이다: 중립 시나리오가 그대로 실현돼도 3년 수익 **+4.8%**로 자본비용 미만이고 빗나가면 **−63.8%**이며, 같은 5개 분기에 고객 집중 **54%**·약정 **$182B**·거래상대방 노출 **자기자본의 48%**로 리스크의 종류 자체가 바뀌었다. **훌륭한 회사와 훌륭한 가격은 다르고, 지금 가격에는 후자가 없다.**
