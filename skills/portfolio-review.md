# 포트폴리오 관리: "종목 분석"에서 "포트폴리오 운용"으로

$ARGUMENTS에 대해 투자 포트폴리오 점검 및 최적화를 수행한다.

**지원 입력 형식**:
- 보유 종목 목록 예시: `Apple 30%, Microsoft 20%, NVIDIA 20%, Berkshire 15%, 현금 15%`
- 또는: `AAPL 50주 @$195, MSFT 30주 @$415, NVDA 20주 @$890, ...`
- 또는: `내 포트폴리오` (기존 저장 파일 `reports/portfolio-latest.md`가 있을 경우)

> "분산투자는 무지에 대한 보호다. 자신이 무엇을 하는지 안다면, 분산투자는 별 의미가 없다." — 워런 버핏
>
> "내 평생 진짜 좋은 투자 기회는 열 손가락으로 셀 수 있을 정도였다." — 리루 (Li Lu)

---

## 설계 철학

종목 분석은 투자의 절반에 불과하다. 나머지 절반은 **포트폴리오 수준의 의사결정**이다:
- 얼마나 살 것인가? (포지션 크기)
- 어떤 자금으로 살 것인가? (신규 자금 vs. 기존 종목 교체)
- 기존 보유 종목과 충돌하지 않는가? (상관관계)
- 최적 포트폴리오는 어떤 모습인가? (기회비용)

버핏은 개별 종목을 단독으로 보지 않는다 — 그는 항상 "지금 내가 할 수 있는 최선의 선택인가?"를 생각한다.

---

## 실행 프로세스

### 1단계: 포지션 파악

입력값에서 현재 보유 내역을 파싱하여 다음 형식으로 표준화한다:

| 종목 | 티커 | 보유량 | 평균 매입가 | 현재가 | 시가총액(USD) | 비중 | 손익 |
|------|------|--------|-----------|--------|-------------|------|------|

입력값이 비율만 있고 금액이 없다면, 비율 기준으로 분석한다.

기존 포트폴리오 파일(`reports/portfolio-latest.md`)이 있는지 확인하고, 있다면 읽어서 업데이트한다.

---

### 2단계: 최신 데이터 수집

Task 도구로 백그라운드 Agent를 실행하고, WebSearch를 통해 각 보유 종목에 대해 병렬로 다음 정보를 수집한다:

> **토큰 예산 ([token-budget.md](token-budget.md))** — 보유 종목 수만큼 팬아웃되므로
> 종목당 비용이 그대로 곱해진다. 이 단계는 **스냅샷 수집**이지 심층 리서치가 아니다:
>
> - 🔴 **Agent는 하위 Agent를 스폰하지 않는다** (TB-1). **동시 실행은 8개까지.**
> - **종목 1개당 조사 상한**: WebSearch 4회 · WebFetch 4회. 아래 4개 항목은 대부분
>   **한 페이지에서 함께** 얻을 수 있다 — 항목마다 따로 검색하지 않는다.
> - 결과는 짧은 표 형태로 반환한다(원문 붙여넣기 금지 — 팀 리드 컨텍스트가 부푼다).
> - 재시도는 종목당 1회까지(TB-2). 못 구한 값은 `⬛`로 남긴다.

1. 현재 주가 및 밸류에이션 지표 (PER, PBR, 배당수익률, FCF Yield)
2. 최근 분기 핵심 재무 변화 (EPS, 매출, 마진 추이)
3. 최근 주요 뉴스 및 이벤트 (실적 발표, 경영진 변경, M&A 등)
4. 애널리스트 컨센서스 (Forward PER, 목표주가)

**데이터 출처 우선순위**:
- 1순위: stockanalysis.com/stocks/{ticker}/financials (재무제표 요약)
- 2순위: macrotrends.net/stocks/charts/{TICKER} (장기 재무 데이터) — ⚠️ 상시 봇 차단, 열렸을 때만
- SEC 공시: sec.gov/cgi-bin/browse-edgar (10-K, 10-Q, 8-K)
- 뉴스: finance.yahoo.com, cnbc.com, seekingalpha.com(WebSearch 경유)

`tools/financial_rigor.py verify-valuation`으로 각 종목의 밸류에이션 데이터를 검증한다.

각 보유 종목에 **정보 풍부도**를 표시한다:
- **A급**: 데이터 완전, 결론 신뢰도 높음
- **B급**: 일부 데이터 부족, 결론은 유효하나 주의 필요
- **C급**: 데이터 부족, 결론에 낮은 신뢰도 표기 필수

---

### 3단계: 개별 종목 건강 진단

각 보유 종목에 대해 빠른 건강 체크를 실시한다:

| 종목 | 현재 PER | 매수 논리 변화 여부 | 투자 thesis 건강도 | 포지션 의견 |
|------|:-------:|:----------------:|:----------------:|-----------|
| Apple (AAPL) | 28x | 변화 없음 | 8/10 | 적정 |
| NVIDIA (NVDA) | 35x | AI 수요 우려 부각 | 7/10 | 비중 다소 높음, 부분 축소 검토 |

각 종목에 대해 다음 질문에 답한다:
- [ ] **오늘 보유하지 않고 있다면, 현재 가격에 새로 매수하겠는가?**
- [ ] **내일부터 거래가 불가능해도 5년간 보유할 수 있는가?**
- [ ] **최초 매수 당시의 투자 thesis가 여전히 유효한가?**

**단융핑(Duan Yongping)**: "10년간 보유하고 싶지 않은 주식이라면, 단 하루도 보유해서는 안 된다."

### 4단계: 포트폴리오 수준 분석

#### 4.1 집중도 분석

| 지표 | 현재 값 | 권장 범위 | 판단 |
|------|--------|---------|------|
| 1위 종목 비중 | | 40% 미만 | |
| 상위 3종목 비중 합계 | | 50~80% | |
| 총 보유 종목 수 | | 5~15개 | |
| 현금 비중 | | 10~30% (시장 환경에 따라 조정) | |

**리루의 기준**: 핵심 포지션 3~5개, 상위 3개가 전체의 80% 이상.
**단, 이는 각 종목을 완전히 이해하고 있을 때만 유효하다.**

**버핏의 기준**: 핵심 포지션 10개 이하이나, 소규모 위성 포지션은 허용.

---

#### 4.2 상관관계 점검

보유 종목 간 숨겨진 연관성을 파악한다:

| 종목 A | 종목 B | 연관 유형 | 리스크 |
|--------|--------|---------|--------|
| Apple (AAPL) | Microsoft (MSFT) | 빅테크 / 클라우드 동시 노출 | 테크 섹터 규제 또는 경기 침체 시 동반 하락 |
| NVIDIA (NVDA) | Amazon (AMZN) | AI 인프라 공급·수요 체인 | AI Capex 사이클 동조화 |
| Meta (META) | Alphabet (GOOGL) | 디지털 광고 시장 경쟁 | 광고 경기 침체 시 동반 하락 |

**체크리스트**:
- [ ] 동일 테마/섹터에 50% 이상 집중되어 있는가?
- [ ] 동일 통화(USD) 외 외환 노출이 있는가?
- [ ] 연준이 금리를 급격히 올리면 포트폴리오에 어떤 영향이 오는가?
- [ ] 글로벌 경기 침체 시 포트폴리오 손실 규모는 어느 정도인가?

---

#### 4.3 기회비용 분석

버핏의 핵심 사고방식 — **모든 달러는 수익이 가장 높은 곳에 배치되어야 한다**.

모든 보유 종목을 "예상 연환산 수익률" 기준으로 정렬한다:

| 순위 | 종목 | 현재 비중 | 예상 연환산 수익률 | 확실성 | 기대수익률 × 확실성 |
|:---:|------|:-------:|:---------------:|:-----:|:-----------------:|
| 1 | | | | | |
| 2 | | | | | |
| ... | | | | | |

예상 수익률 추정 방법 (`tools/financial_rigor.py three-scenario` 계산 활용):
- **주요 방법**: 예상 연환산 ≈ FCF Yield + 예상 성장률
- **가치형 검증**: 안전마진 회귀 + 이익 성장률 + 배당수익률
- **성장형 검증**: 이익 성장률 × 합리적 PER 변화

**핵심 질문**: 순위 최하위 종목의 예상 수익률이 현금(무위험 수익률 ~4~5%)보다 높은가? 낮다면 매도하고 현금으로 전환해야 한다.

---

#### 4.4 스트레스 테스트

| 시나리오 | 가정 | 포트폴리오 예상 영향 | 최대 손실 추정 |
|---------|------|-------------------|-------------|
| 글로벌 경기 침체 | 기업 이익 20~30% 감소 | | |
| 연준 금리 급등 | 10년 국채 금리 → 6% 이상 | | |
| 빅테크 규제 강화 | 반독점 조치로 핵심 사업 분리 강제 | | |
| 테크 버블 붕괴 | 테크 PER 40% 압축 | | |
| AI 투자 실망 | AI 수익화 지연으로 관련주 재평가 | | |

각 시나리오에 대해 정성적 + 대략적 정량 평가를 수행한다:
- 어떤 보유 종목이 가장 큰 충격을 받는가? 영향의 방향과 규모 범위
- 포트폴리오 전체가 견딜 수 있는가?
- 헤지가 필요한가?

### 6단계: 포트폴리오 리포트 출력

#### 리포트 구성

```
1. 포트폴리오 개요 (보유 종목 표 + 비중 분포 설명)
2. 개별 종목 건강 진단 (각 보유 종목의 상태)
3. 포트폴리오 분석
   - 집중도: 과도하게 분산되었는가, 아니면 집중되었는가?
   - 상관관계: 숨겨진 연관성과 리스크 동조화
   - 기회비용: 순위 최하위 종목은 보유할 가치가 있는가?
   - 스트레스 테스트: 극단적 시나리오에서의 손실 추정
4. 리밸런싱 제안 (구체적인 액션 + 근거)
5. 다음 점검 시기 및 주요 모니터링 포인트
```

#### 결론에서 반드시 명확히 답해야 할 사항

1. **포트폴리오 전체 건강도**: 우수 / 양호 / 조정 필요 / 심각한 문제
2. **지금 당장 해야 할 가장 중요한 한 가지는 무엇인가?** (X 비중 확대 / Y 비중 축소 / 현상 유지)
3. **현재 가장 큰 리스크는 무엇인가?**

---

### 7단계: 포트폴리오 파일 저장

포트폴리오 정보를 `reports/portfolio-latest.md`에 저장한다. 포함 내용:
- 최신 보유 종목 표 (USD 기준)
- 이번 점검 날짜 및 결론
- 리밸런싱 기록 (추가 형식으로 축적)
- 다음 점검 권장 일정

## 핵심 원칙

- **모든 달러에는 기회비용이 있다** — 평범한 종목을 보유하는 비용은, 뛰어난 종목을 놓치는 것이다
- **집중 자체가 리스크가 아니라, 무지가 리스크다** — 깊이 이해한 3개 종목이, 어중간하게 아는 30개보다 안전하다
- **현금도 하나의 포지션이다** — 좋은 기회가 없을 때 현금을 보유하는 것은 부끄러운 일이 아니다
- **포트폴리오 수준 > 개별 종목 수준** — 좋은 종목도 잘못된 비중에서는 포트폴리오를 망친다
- **정기 점검은 하되, 과잉 매매는 금물** — 분기 1회 점검으로 충분하며, 매일 시세를 보며 조정하지 않는다
- **USD 기준 통일** — 모든 시가총액, 손익, 비중은 USD 단위로 표기하며, 단위는 B(십억)/T(조)를 사용한다

## 데이터 신뢰도 표기 (필수)

본 보고서는 **[data-confidence.md](data-confidence.md) 표준**을 적용한다:

- 핵심 수치·판단 옆에 **신뢰도 등급 + 유형 태그**를 단다 — 🟢높음(2+독립출처 교차검증 또는 SEC 원문 직접 확인) / 🟡보통(단일출처·경미편차·해석여지) / 🔴낮음(추정·미확정주장·구데이터) / ⬛데이터부족(공백 유지) + `[사실]`/`[추정]`/`[주장]`/`[의견]`.
- **출처 독립성 주의**: 회사 IR·보도자료와 집계 사이트는 둘 다 회사 공시 파생이라 상호 독립이 아니다 → 🟢은 원문 직접 확인 또는 계보가 다른 두 출처를 요구한다.
- 보고서 **말미에 기계 판독용 신뢰도 요약 블록**을 포함한다(대시보드가 파싱):

      <!-- confidence-summary
      high: N
      medium: N
      low: N
      gap: N
      verdict: 높음|보통|낮음
      -->

  (아래에 사람용 요약 몇 줄: 등급별 개수 + 종합 판단 근거)
- ⚠️ verdict는 **"데이터 신뢰도"이며 "투자 매력도"가 아니다.** 두 축은 독립이며 자주 어긋난다. `[의견]` 태그는 verdict 계산 분모에서 제외한다.
