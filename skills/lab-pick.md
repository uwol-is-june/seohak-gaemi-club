# 실험실 — 이번 주 추천 종목

규칙 원본은 **`docs/LAB-SPEC.md`(v1 고정)** 다. 이 스킬은 그 6절 "픽" 단계 — **LLM 결격 검증** — 만 한다.

## 🔴 이 스킬이 절대 하지 않는 것

| 금지 | 이유 |
|---|---|
| **순위를 바꾸기** (2위가 더 좋아 보여서 고르기) | 순위는 기계가 정한다. LLM 은 **탈락만** 시킬 수 있다. `lab_record.py` 가 기계로 막는다 |
| **증거 없이 탈락시키기** ("왠지 불안") | 탈락에는 **증거 URL 필수**. 의심만 있으면 통과시키고 "이건 조심"에 적는다 |
| **목표가·철회선을 고치기** | 기계 산출값 그대로 쓴다. 보고서에 의견은 적을 수 있지만 기록값은 바꾸지 않는다 |
| **기존 시스템 판단을 읽고 따라가기** | `data/calls.jsonl`·`reports/{티커}/` 의 논제를 **검증 근거로 쓰지 않는다** — 독립성이 이 실험의 전부다 |
| **기준을 낮춰 억지로 고르기** | 상위 5개가 모두 탈락이면 **"이번 주 없음"이 정답**이다 |
| **사용자에게 묻기** | 주간 자동 실행(헤드리스)에서도 돌아야 한다. 판단이 애매하면 아래 규칙대로 기본값을 택한다 |

## 토큰 예산 ([token-budget.md](skills/token-budget.md))

- 🔴 **서브에이전트를 스폰하지 않는다** — 본체가 순서대로 직접 검증한다(TB-1). 종목 간 병렬화도 하지 않는다:
  1위가 통과하면 2위 이하는 볼 필요가 없어서, 병렬로 돌리면 대부분 버려지는 일이 된다.
- 종목당 상한: **WebSearch 4회 · WebFetch 2회**. 전체 상한: WebSearch 15회 · WebFetch 8회.
- 스크리닝 JSON(약 290KB)을 **통째로 읽지 않는다** — `lab_record.py --brief` 표만 본다.
- 정상 범위 **1~3M**. 보고서는 **Write 1회**(TB-5).

## 실행 절차

### 1단계: 이번 주 스크리닝 확보

```bash
python3 tools/lab_record.py --brief
```

- 출력 첫 줄의 스크리닝 날짜가 **오늘 기준 3일 이내**가 아니면 먼저 새로 돌린다(약 2분, 토큰 0):
  ```bash
  python3 tools/lab_screen.py
  python3 tools/lab_record.py --brief
  ```
- **"이미 기록됨"** 이 뜨면 **여기서 끝낸다** — 같은 실행일은 append-only 라 다시 기록할 수 없다(TB-7).
  "이번 주는 {날짜}에 이미 기록됐다"고만 보고한다.
- 후보가 0개면 검증 없이 3단계 "없음"으로 간다.

### 2단계: 1위부터 결격 검증 (통과하면 즉시 멈춤)

표의 순위대로 한 종목씩 아래 **5개 항목**을 확인한다. 하나라도 **증거와 함께** 해당하면 탈락 → 다음 순위.
5위까지 내려가도 모두 탈락이면 "없음".

| # | 결격 사유 | 무엇을 보나 | 탈락 기준 (증거 필수) |
|---|---|---|---|
| D1 | **회계 이상** | 재무제표 재작성(restatement) · 감사인 사임/교체 · 10-K Item 9A 중요한 취약점(material weakness) · SEC 조사 | 최근 24개월 내 해당 공시/보도가 **확인됨** |
| D2 | **대규모 희석** | 최근 12개월 유상증자 · 전환사채 · 주식 대가 대형 M&A | 희석 주식수 **+5% 이상**(YoY) 또는 그만큼의 발행 확정 공시 |
| D3 | **중대 소송·규제** | DOJ/FTC/FDA 등 진행 중 조치 · 시가총액 대비 큰 배상 리스크 · 상장폐지 위험 | 회사 공시(10-K/10-Q 우발채무·8-K) 또는 주요 언론이 **금액·범위를 특정** |
| D4 | **일회성 FCF** | 최근 FY FCF 가 운전자본 일시 해소 · 자산매각 · 세금 환급 · 보험금으로 부풀었나 | 회사가 직접 일회성 요인을 밝혔고, 그걸 빼면 **상승여력이 +15% 미만** |
| D5 | **평균회귀 불성립** | 피인수 합의(가격 상한) · 분사로 사업 축소 · 핵심 사업 구조적 쇠퇴 · 사업 모델 전환 | 아래 중 하나가 **확인됨**: ① 인수 합의(주당 가격 확정) ② 매출 40%+ 사업의 매각/분사 ③ 회사가 장기 가이던스로 구조적 축소를 공표 |

- 표의 **주의** 칸에 `분사의심` 이 있으면 **D5 를 반드시 확인**한다 — 분사 전 FCF 에 떨어져 나간 사업이 섞여
  목표가가 부풀었을 수 있다(LAB-SPEC 2절). 분사된 사업의 FCF 비중을 찾아, 빼면 상승여력이 +15% 미만이면 탈락.
- 주의 칸에 `보완:` 이 있으면 그 연도 수치가 대체 태그·EPS 역산이라는 뜻이다 — 정보로만 쓰고 탈락 사유는 아니다.

**판정 규칙 (애매할 때의 기본값)**

- 증거가 **루머·익명 소식통·의견 기사뿐**이면 → **통과**. "이건 조심"에 출처와 함께 적는다.
- 위험은 실재하지만 **탈락 기준(표의 오른쪽 칸)에 못 미치면** → **통과**. "이건 조심"에 적는다.
- 데이터를 못 구했으면(사이트 차단·검색 실패) → **통과**, 해당 항목을 `⬛ 확인 불가`로 적는다.
  못 찾았다는 이유로 탈락시키지 않는다 — 탈락은 확인된 사실로만 한다.
- 증거 우선순위: SEC 공시 원문(8-K·10-Q·10-K) > 회사 보도자료 > Yahoo Finance·CNBC 기사 > WebSearch 경유 요약(🟡).
  WSJ·Reuters·MarketWatch·Barron's 는 쓰지 않는다(CLAUDE.md 데이터 소스 — 접근 불가).

**검색 예시** (종목당 4회 안에서):
1. `"{회사명}" restatement OR "material weakness" OR "SEC investigation" 2025 2026`
2. `"{회사명}" acquisition OR "to be acquired" OR spin-off OR divestiture 2026`
3. `"{회사명}" lawsuit OR DOJ OR FTC OR recall 2026`
4. `"{회사명}" free cash flow one-time OR "working capital" {최신 FY}`
필요하면 WebFetch 로 SEC EDGAR 최근 8-K 목록 1회
(`https://www.sec.gov/cgi-bin/browse-edgar?action=getcompany&CIK={티커}&type=8-K&count=10`).

### 3단계: 보고서 작성 (Write 1회)

경로: `reports/lab/lab-pick-{YYYYMMDD}.md` — 날짜는 **스크리닝 실행일**(brief 첫 줄)이다.
> `reports/lab/` 은 티커 폴더가 아니라 대시보드 종목 목록에서 제외된다. **섹터 마커(`<!-- meta sector -->`)를 넣지 않는다**
> — 실험실 픽은 기존 시스템의 종목 분류에 섞이면 안 된다.

```markdown
# 실험실 — 이번 주 추천 {YYYY-MM-DD}

> 규칙 v1 · 스크리닝 {실행일} · 후보 {N}개 · 대조군 {티커}<br>
> 결론: **{티커} ({회사명})** 또는 **이번 주 없음**

## 결론
{한 단락: 무엇을 골랐고 왜 위 순위가 탈락했는지. "추천"이지 매수 지시가 아니다 — 실제 보유는 사용자가 정한다}

| 항목 | 값 |
|---|---|
| 추천가 (스크리닝 시점) | $ |
| 목표가 (자기 10년 중앙 FCF 수익률 회귀) | $ (+%) |
| 철회선 | $ (−15%) 또는 다음 주 후보 이탈 |
| 호라이즌 | 12개월 |

## 검증 기록
### 1위 {티커} — 통과 | 탈락
| # | 항목 | 판정 | 근거 (출처 URL) |
|---|---|---|---|
| D1 | 회계 이상 | 해당 없음 / ❌ 탈락 / ⬛ 확인 불가 | |
| D2 | 대규모 희석 | | |
| D3 | 중대 소송·규제 | | |
| D4 | 일회성 FCF | | |
| D5 | 평균회귀 불성립 | | |
(탈락 종목은 탈락 사유 1개만 확인되면 나머지 항목은 "미확인(탈락으로 중단)"으로 둔다)

> ⚠️ 회사명의 약자 마침표는 붙여 쓴다(`A.O. Smith`). `A. O. Smith` 처럼 띄우면 대시보드의 문장 줄바꿈이
> 마침표마다 줄을 끊는다(2026-10-02 첫 실행에서 발생).

## 이건 조심 (반대 근거)
- 탈락 기준에는 못 미쳤지만 실재하는 위험 2~4개 — 출처와 함께. 최소 1개는 반드시 적는다.
- "평균회귀 가정"이 이 종목에서 깨질 수 있는 시나리오 1개.

## 데이터 출처 · 한계
- 기계 순위: data/_lab/screen-{YYYYMMDD}.json (SEC XBRL · Yahoo)
- 검증 검색 {n}회 · 확인 불가 항목 목록
```

### 4단계: 판단 기록부 기록 (필수 — 보고서 직후)

```bash
# 1위 통과
python3 tools/lab_record.py --screen data/_lab/screen-{YYYYMMDD}.json --pick {티커} \
    --report reports/lab/lab-pick-{YYYYMMDD}.md

# 위 순위 탈락 후 N위 통과 — 탈락한 종목 전부를 "티커 | 사유 | 증거 URL" 로
python3 tools/lab_record.py --screen data/_lab/screen-{YYYYMMDD}.json --pick {N위 티커} \
    --report reports/lab/lab-pick-{YYYYMMDD}.md \
    --reject "{1위} | {D번호 사유 한 줄} | {URL}" "{2위} | ... | {URL}"

# 상위 5개 모두 탈락 또는 후보 0개
python3 tools/lab_record.py --screen data/_lab/screen-{YYYYMMDD}.json --none \
    --report reports/lab/lab-pick-{YYYYMMDD}.md \
    --reject "{1위} | ... | {URL}" ... "{5위} | ... | {URL}"
```

- 도구가 규칙 위반(승격 · 증거 없는 탈락 · 5위 초과 · 중복 기록)을 **오류로 거부**한다. 거부되면 메시지대로 고친다 —
  우회하지 않는다. 대조군은 도구가 자동으로 함께 기록한다.
- 같은 종목이 30일 안에 다시 뽑히면 도구가 `repeat` 로만 남긴다(새 콜 아님) — 정상이다.
- `data/calls.jsonl`(기존 판단 기록부)·`record_call.py` 는 **쓰지 않는다**.

### 5단계: 사용자 보고 (짧게)

```
이번 주 추천: {티커} ({회사명}) — $현재가 → 목표 $목표가 (+%), 철회 $철회선
위 순위 탈락: {티커}({사유}) …   |   반대 근거: {한 줄}
대시보드 '실험실' 탭에서 확인 · 받으려면 "실험실 {티커} 수락" (실제 매수는 기존처럼 매매 로그로)
```

사용자가 수락/거절을 알리면:
```bash
python3 tools/lab_record.py --decide LAB-{YYYYMMDD}-{티커}-pick accepted   # 또는 declined
```
수락은 "이 추천에 동의한다"는 기록일 뿐이다. **실제 매수는 CLAUDE.md "보유 상태의 기본값" 절차(매매 로그 → buy 콜)를
따로 거친다** — 수락만으로 보유 포지션에 올리지 않는다.
