# 아티클 → 카드뉴스 제작

`$ARGUMENTS`의 아티클을 인스타그램/스레드용 카드뉴스 PNG로 변환한다.

**지원 입력:**
- 아티클 파일 경로: `/article-cards reports/SPCX/SPCX-article-20260810.md`
- 티커: `/article-cards SPCX` → `reports/SPCX/` 에서 가장 최근 `-article-` 파일을 쓴다

> 🔴 **이 스킬은 변환기다. 새로 조사하지 않는다.**
> 카드의 모든 수치·문장은 **소재 아티클 본문에서만** 가져온다. 웹 검색·WebFetch를 쓰지 않는다.
> 아티클에 없는 숫자가 카드에 나타나면 그건 지어낸 것이다 — 카드뉴스는 수치가 이미지에 박혀
> 나가서 사후 정정이 불가능하다.
>
> 🔴 **서브에이전트를 쓰지 않는다** (`skills/token-budget.md` TB-1). 본체에서 직접 처리한다.
> 정상 소비 범위는 **1회 300K 이하**다.

## 실행 흐름

### 1단계: 소재 읽기 + 신선도 확인

아티클 전문을 읽는다. 그리고 **오늘 날짜와 대조한다**:

- 아티클이 "앞으로 확인할 일"로 적은 시점이 **이미 지났으면 그대로 카드로 만들지 않는다.**
  지난 예고를 예고로 내보내게 된다. 사용자에게 알리고 어떻게 할지 묻는다.
- 아티클 날짜가 **7일을 넘었으면** 급변동 소재로서 유효기간이 지났을 수 있다 — 짚어 준다.

### 2단계: 카드 구성 (6~10장)

**카드뉴스는 아티클의 요약이 아니라 재편집이다.** 문단을 잘라 붙이지 말고, 한 장에 하나의
논점만 남기고 나머지는 버린다. 읽는 사람은 손가락으로 넘기면서 3초씩 본다.

권장 골격 (이슈 해설형 기준):

| # | 카드 | 블록 |
|---|------|------|
| 1 | 커버 — 가장 반직관적인 한 문장 | `cover` + `lead` |
| 2 | 핵심 숫자 하나 | `stat` 또는 `versus` |
| 3 | 무슨 일이 있었나 | `timeline` |
| 4~6 | 원인 분해 — 한 장에 한 요인 | `versus`·`stat`·`points` |
| 7 | 4대가 프레임 | `quote` |
| 8 | 반증 조건 / 검증 시점 | `table` + `note` |
| 9 | 범위 고지 + 면책 | `points` + `note` |

#### 톤 — 밈틱하게, 단 어디서 멈추는지가 규칙이다

카드뉴스는 손가락으로 넘기며 3초씩 본다. 보고서 문어체로는 두 장째에서 넘겨진다.
**커버~원인 카드(1~6번)는 구어체로 친다** — "떡상", "근데 …임", "그게 하루 전에 증발했다".
짧은 문장, 반전 구조, 한 카드에 형광펜(`==…==`) 하나.

> 🔴 **7번(4대가)부터 마지막까지는 정색으로 되돌린다.**
> 반증 조건·검증 시점·면책을 밈 톤으로 쓰면 그건 밈이 아니라 **선동**이다. 독자가 웃다가
> 넘기면 안 되는 유일한 카드들이다. `CLAUDE.md`의 객관성 원칙이 여기서 우선한다.

**밈 톤이 건드리면 안 되는 것:** 수치, 단위, 날짜, 출처, 신뢰도 표기. 표현만 바꾼다 —
"약 15.8%"를 "15.8%"로 줄이는 것도 안 된다(`약`이 원문에 있으면 남긴다).

#### 색 — 한국 독자 기준 (상승 = 빨강 / 하락 = 파랑)

미국 관행과 **반대**다. 템플릿의 `--up`(#ff5f56 빨강)·`--down`(#3b9dff 파랑)이 이미 그렇게
잡혀 있으니 `dir`만 맞게 넘기면 된다.

| 쓰는 곳 | 표기 |
|---|---|
| 등락률·주가 변화 (문장 안) | `{{+15.83%\|up}}` · `{{−13.6%\|down}}` |
| `stat`·`versus`의 숫자 | `"dir": "up"` / `"dir": "down"` |
| 형광펜에 색을 얹을 때 | `==+3%\|up==` |

> 🔴 **가격·등락률이 아닌 숫자에는 색을 주지 않는다.** 공매도 비율 34%, 거래량 배수 1.6배,
> capex $18.37B 같은 값은 오른 것도 내린 것도 아니다. 여기에 빨강을 칠하면 색이 "등락"이
> 아니라 "강조"라는 뜻이 돼 버려서, 정작 등락률의 빨강/파랑이 안 읽힌다. 흰색으로 두고
> 형광펜으로 강조한다.

**필수 규칙:**
- **마지막 카드에 반드시 면책을 넣는다** — "투자 권유가 아니다"와 이 글이 다루지 **않는** 범위.
- 아티클의 **신뢰도 표기를 카드까지 끌고 온다**. `[추정]`·`🟡`·"(추정)"이 붙은 수치는
  카드에서도 백틱 태그로 표시한다 — 예: `` `[추정]` ``.
- **반증 조건을 최소 한 장 넣는다.** 결론만 9장 늘어놓으면 마케팅이 아니라 선동이다.
- 티커는 **미국 상장 티커**로 통일한다(`CLAUDE.md` 폴더 명명 규칙과 동일).

### 3단계: 카드 데이터 작성

`tools/cards/{subject}-{YYYYMMDD}.json` 으로 저장한다 (subject는 소문자 티커/주제).
예: `reports/SPCX/SPCX-article-20260810.md` → `tools/cards/spcx-20260810.json`

**스키마** (전체 예시는 `tools/cards/spcx-20260810.json` 참조):

```jsonc
{
  "source": "reports/SPCX/SPCX-article-20260810.md",  // 소재 경로 — 반드시 적는다
  "ticker": "SPCX",
  "meta": "2026.08.10",          // 러닝헤더 우측 날짜
  "brand": "서학개미클럽",
  "footDefault": "출처: SPCX-news-20260810.md",

  "caption": "게시 본문 …",       // 필수 — 아래 '게시 본문' 절 참조
  "hashtags": ["스페이스X", "SPCX", "미국주식"],
  "disclaimer": "투자 권유가 아닙니다 …",  // 생략 시 기본 문구가 들어간다

  "cards": [
    { "type": "cover", "eyebrow": "...", "title": "...", "blocks": [...], "foot": "..." },
    { "eyebrow": "01  소제목", "title": "...", "blocks": [...] }
  ]
}
```

#### 게시 본문 (`caption`) — 카드와 함께 반드시 쓴다

이미지 9장만 만들어 두면 올릴 때 결국 손으로 본문을 쓰게 되고, 그때 카드에 없는 수치가
새로 들어간다. **카드와 본문이 같은 JSON에서 나와야 어긋나지 않는다.**

- **카드의 요약이 아니라 완결된 글이다.** 이미지를 안 넘기고 본문만 읽어도 논지가 서야 한다.
- **문체는 카드보다 한 단계 차분하게.** 카드가 "떡상"이면 본문은 "15.83% 올랐습니다" 정도.
  카드는 시선을 끄는 자리, 본문은 설득하는 자리다.
- **반증 조건을 본문에도 넣는다.** 카드에서 8번을 넣었는데 본문에서 빼면 결론만 남는다.
- 단락은 빈 줄로 나눈다 — SNS는 줄바꿈 없는 덩어리를 아무도 안 읽는다.
- 해시태그는 `hashtags` 배열로 넘긴다(`#` 없이 써도 렌더러가 붙인다). 6~10개.

렌더러가 `caption` + `hashtags` + `disclaimer` + 소재 경로를 합쳐
`assets/cards/{slug}/caption.md` 로 쓴다. `caption`이 없으면 경고만 내고 이미지만 나간다 —
경고가 보이면 빠뜨린 것이다.

**블록 8종:**

| `t` | 필드 | 쓰는 곳 |
|-----|------|--------|
| `lead` | `text` | 본문 문단 |
| `points` | `items[]` | 3개 이하 불릿 |
| `stat` | `num`, `dir`(`up`/`down`), `caption` | 큰 숫자 하나 |
| `versus` | `items[{num, dir, label}]` | 두 숫자 대비 (2개만) |
| `timeline` | `rows[{date, text, hi}]` | 날짜별 전개 (4행 이하). `hi: true` = 그날이 사건 당일(날짜를 강조색으로) |
| `table` | `head[]`, `rows[][]` | 2열 3행 이하 |
| `quote` | `text`, `by` | 4대가 프레임 |
| `note` | `text` | 단서·면책 박스 |

**인라인 마크업:** `**굵게**` · `__강조색__` · `` `태그` `` · `==형광펜==` · `==텍스트|up==`
등락 형광펜 · `{{+15.8%|up}}` 등락 글자색 · `<br>` 줄바꿈.
줄바꿈은 렌더러가 문장부호에서 자동 처리하므로 손으로 넣지 않는다.

> ⚠️ **분량이 넘치면 렌더러가 알려주지 않는다** — 카드 밖으로 조용히 잘린다.
> 한 카드에 블록 3개 이하, `lead`는 2문장 이하로 유지하고, 4단계에서 **눈으로 확인**한다.

### 4단계: 렌더 + 검수

```bash
# 최초 1회만 — 의존성 설치. 반드시 서브셸 ( ) 안에서 한다
( cd tools/cards && npm install )

# 렌더는 항상 저장소 루트에서
node tools/cards/render.mjs tools/cards/{slug}.json
```

> 🔴 **`cd tools/cards` 를 서브셸로 감싸지 않으면 다음 명령이 깨진다.** 작업 디렉토리는
> 명령 사이에 유지돼서, `cd` 한 뒤 `node tools/cards/render.mjs` 를 실행하면
> `tools/cards/tools/cards/render.mjs` 를 찾다 `MODULE_NOT_FOUND` 로 죽는다
> (2026-08-12 실제 발생). 렌더 명령의 경로는 **저장소 루트 기준**이다.

산출물: `assets/cards/{slug}/{티커}-01.png` … (2160×2700, 2x) + `caption.md`

같은 JSON을 다시 렌더하면 **바이트 단위로 같은 PNG**가 나온다(검증함). 결과가 달라졌다면
JSON이나 템플릿이 바뀐 것이다. 출력 위치를 바꾸려면 `--out {디렉토리}` 를 붙인다.

🔴 **렌더 후 최소 3장은 Read로 직접 본다** — 커버 1장, 데이터가 가장 빽빽한 1장, 마지막 1장.
잘림·겹침·빈 줄이 보이면 JSON을 고쳐 다시 렌더한다. 렌더 성공은 레이아웃이 맞다는 뜻이
아니다(2026-08-12에 표 본문이 검게 렌더되는 걸 렌더 성공 상태로 놓칠 뻔했다).

### 5단계: 보고

- 산출 경로와 장수, `caption.md` 글자 수
- 카드별 한 줄 요약
- **아티클에서 의도적으로 뺀 내용** — 무엇을 버렸는지 밝힌다
- 신선도 경고(1단계에서 걸린 것)

## 트랙레코드

**이 스킬은 콜을 내지 않는다.** 카드뉴스는 기존 아티클의 표현 변경일 뿐 새 투자 판단이
아니므로 `data/calls.jsonl`에 기록하지 않는다. 카드에 아티클에 없던 판단이 새로 생겼다면
그건 이 스킬이 범위를 벗어난 것이다.
