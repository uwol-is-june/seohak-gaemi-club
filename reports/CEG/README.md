## 핵심 발견 6가지

1. **⚑ "장기계약 락인" 서사는 자산의 10~25%에만 해당한다.** 원전 22.07GW 중 DC 장기 PPA는
   **2.34GW = 10.6%** (Vistra는 59% — **6배 열위**). 2029년 원전 물량 **75% 미계약**.
   **CEG 자신도 2029 base 목표에서 AI 프리미엄을 명시적으로 제외했다.**
2. **⚑ 2026년 최대 산업 사실은 수요가 아니라 정치다.** PJM 용량가격 상한 **$325/MW-day가
   2030년까지 확정**(13개 주 주지사 **초당적** 연합, 6,700만 명, $45B 절감 공언).
   **3년 연속 상한가 청산 + 신뢰도 요건 6,831MW 미달** = 희소성이 극심한 지점에서조차 가격을 못 정한다.
3. **⚑ 이익의 40%가 Enhanced — Base EPS 기준 실질 PER은 약 40x다.** 2026 총 EPS $11.50 중
   Base는 **$6.70**뿐. Enhanced는 시장가가 기준을 초과할 때만 존재한다. 그리고 Base 가정이
   최신 forward보다 낙관적이다(ERCOT spark $21 → **$18.55, -12%**).
4. **PTC는 보조금이 아니라 현재 OTM 상태의 무료 풋옵션이다.** 원전 선단의 **0~5%만** 수취 중
   (2026년 5%, 2027년 **0%**). **폐지의 즉각 영향은 주당 $0.0~0.2**. 그러나 전력가격 붕괴 시
   **최대 주당 $4.5~5.3을 방어**한다. 강세·약세 양쪽이 대개 오해하는 구조. **2032년 만료.**
5. **경영진에는 지적할 급소가 없다.** Calpine을 자기 배수의 절반(7.9x)에 사고 **DOJ 강제 매각에서
   인수 단가 +16% 프리미엄**($1,142/kW)을 실현. Crane 예산 내·1년 조기. Meta-Clinton 딜로 IL CMC
   만료를 사전 제거. **보상 체계에 EBITDA 지표가 없고 Calpine 실적을 실제로 보상 산정에서 제외.**
   ⚠️ 단 16% 희석 대가로 organic 주당 성장 ~1%, 2026년 자사주를 $281에 매입(현재가 -6.5%).
6. **⚑ 하방 보호는 실재하지만 현재가보다 ~60% 아래에 있다.** 실질 바닥 = 2026 Base EPS $6.70 ×
   12~15x = **$80~101**. **대체원가(EV의 2.9배)는 바닥이 아니다** — Calpine이 2005년 파산했을 때도
   대체원가는 부채를 훨씬 초과했고 머천트 가스 자산은 대체원가의 20~30%에 거래됐다.
   **NDT "숨은 가치 $6.1B"도 기각** — 환급의무 $5.33B 차감 후 실질 $0.8B(시총 0.8%).
