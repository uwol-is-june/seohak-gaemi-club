# 산업 투자 리서치: 가치사슬 전체 스캔 + 4대 거장 개별 종목 분석 프레임워크

$ARGUMENTS 산업에 대한 체계적인 가치사슬 투자 리서치를 수행한다.

## 리서치 목표

하나의 투자 테마/논리 체인에서 출발하여 다음을 완수한다:
1. 투자 논리 체인의 각 단계를 검증한다
2. 완전한 가치사슬 전체 지도를 그린다
3. NYSE/NASDAQ/S&P500 전 상장기업을 스캔한다
4. 각 세부 섹터의 선두 기업에 대해 4대 거장 프레임워크 분석을 실행한다
5. 산업 수준의 포트폴리오 배분 제안을 출력한다

---

## 1단계: 투자 논리 체인 구축 및 검증

### 1.1 논리 체인 그리기
"근본 트렌드"에서 "수혜 종목"까지의 인과관계를 화살표 흐름으로 표현한다. 예시:
```
근본 트렌드 A
    → 수요 B를 창출
        → 병목/필수 수요 C를 만든다
            → 수혜 가치사슬 D
```

예시 (반도체 섹터):
```
AI 모델 파라미터 확장 경쟁
    → 고성능 GPU/HBM 수요 급증
        → 첨단 패키징·HBM 공정이 병목
            → NVDA, TSMC, SK Hynix, Micron 수혜
```

### 1.2 각 단계별 검증
논리 체인의 각 화살표에 의문을 제기하고 근거를 찾는다:

| 단계 | 핵심 가정 | 검증 방법 | 데이터 출처 |
|------|----------|----------|-----------|
| A→B | | 산업 데이터/전망 검색 | macrotrends.net, SEC 10-K |
| B→C | | 수급 분석 검색 | stockanalysis.com, WSJ |
| C→D | | 실제 계약/사례 검색 | SEC 8-K, seekingalpha.com |

### 1.3 "이미 발생한 검증 이벤트" 찾기
논리 체인을 뒷받침하는 **이미 체결·실행된 실제 비즈니스 이벤트**를 나열한다 (예측이 아닌 실제 사실). 예: 대기업 구매 계약, SEC 공시, 산업 보고서, 주요 고객사 발표 등.

## 2단계: 가치사슬 전체 지도 그리기

### 2.1 가치사슬 구조 그리기
산업을 업스트림 → 미드스트림 → 다운스트림 → 보조 섹터로 분해한다. 예시:
```
업스트림:   원자재/자원 채굴 → 소재 가공/정제
미드스트림: 핵심 장비 제조 → 시스템 통합/엔지니어링 → 신기술 R&D
다운스트림: 운영/서비스 → 최종 고객
보조:       테스트/인증 → 유지보수 서비스 → 금융 수단 (ETF/REITs)
```

미국 주요 섹터별 가치사슬 예시:
- **반도체**: EDA 소프트웨어(Synopsys/Cadence) → 웨이퍼 장비(AMAT/LRCX/KLAC) → 파운드리(TSMC/Intl Foundry) → 팹리스 설계(NVDA/AMD/QCOM) → 최종 시스템 통합
- **핀테크/결제**: 네트워크 인프라(Visa/Mastercard) → 결제 처리(FIS/Fiserv) → 소비자 앱(PayPal/Block) → 임베디드 금융(Stripe 등 비상장)
- **클라우드/AI 인프라**: 데이터센터 하드웨어(NVDA/AMD) → 하이퍼스케일러(AMZN/MSFT/GOOGL) → 플랫폼 서비스(Snowflake/Databricks) → AI 앱 레이어
- **헬스케어**: 제약 원료(specialty chem) → 임상 CRO(IQVIA/Medpace) → 대형 제약(JNJ/LLY/PFE) → 의료보험(UNH/CVS) → 의료 IT(Epic 등)
- **에너지 전환**: 원자재 채굴(리튬/희토류) → 배터리 셀(Panasonic/CATL 비상장) → EV OEM(TSLA/GM/F) → 충전 인프라(CHPT/EVGO) → 유틸리티(NEE/AES)

### 2.2 각 섹터의 "비즈니스 특성" 파악
각 섹터에 다음을 표시한다:

| 섹터 | 비즈니스 모델 | Gross Margin 범위 | 경쟁 구도 | 해자 유형 | 경기 민감도 |
|------|-------------|-----------------|----------|----------|-----------|
| | 자원판매/장비판매/서비스/구독 | | 독점/과점/완전경쟁 | 자원/라이선스/기술/규모 | 강/중/약 |

### 2.3 "병목 섹터" 표시
가치사슬에서 공급이 가장 타이트하고, 대체가 가장 어려우며, 마진이 가장 높은 섹터를 식별한다. 이런 섹터가 최적 투자 종목이 있는 곳이다.

## AI 리서치 편향 자각: 산업 리서치의 특수 함정

산업 리서치에서 AI 데이터 편향은 특유의 방식으로 증폭된다:

**산업 수준 편향**:
| 편향 유형 | 나타나는 방식 | 대응 방법 |
|----------|------------|---------|
| 성숙 산업 선호 | 전통 산업(은행/에너지/소비재) 자료가 방대해 AI 분석이 "더 확실해" 보임 | 확실성은 비즈니스 모델에서 오는 것, 리서치 보고서 수에서 오지 않음 |
| 신흥 산업 과소평가 | 신산업(AI 앱/합성생물학 등) 자료가 적어 AI 분석이 보수적으로 편향 | "현재 데이터"가 아닌 "최종 상태(endgame)" 사고로 산업 가치를 판단 |
| 대형주 선호 | 대기업 자료가 소기업보다 훨씬 많아 AI가 자연스럽게 대형주를 추천 | 소형주가 더 나은 위험/수익 비율을 제공할 수 있음. AI 분석이 짧다고 무시하지 말 것 |
| 상장 기업 편향 | 상장기업만 스캔하면 가치사슬의 핵심 비상장 플레이어를 놓침 | 비상장 기업 반드시 검색, "미래 IPO 후보"로 표시 |
| 영문 자료 편향 | AI가 영문 자료를 더 잘 처리해 아시아/유럽 경쟁자를 과소평가할 수 있음 | 외국 경쟁자의 SEC 공시(20-F)와 영문 자료를 별도 검색 |

**가치사슬 스캔의 반편향 조치**:
1. 각 섹터에서 "AI가 쉽게 찾는 기업"뿐 아니라 "비주류지만 잠재적으로 우수한 종목"을 능동적으로 검색한다
2. 정보가 부족한 소형주라도 분석 분량이 짧다는 이유로 추천도를 낮추지 않는다. 핵심 질문(비즈니스 본질, 해자, 경영진)으로 판단한다
3. 최종 보고서에서 각 기업의 "정보 충분도"(A/B/C 등급)를 표시해 독자가 AI 분석의 신뢰도를 파악하게 한다

## 3단계: 전체 상장기업 스캔

Task 도구를 사용해 백그라운드 Agent를 실행하고, 해당 산업의 모든 상장기업을 포괄적으로 검색한다.

### 검색 출처
- **주요 데이터**: macrotrends.net/stocks/charts/{TICKER}
- **재무제표**: stockanalysis.com/stocks/{ticker}/financials
- **SEC 공시**: sec.gov/cgi-bin/browse-edgar (10-K, 10-Q, 8-K)
- **스크리닝**: finviz.com/screener
- **뉴스/분석**: finance.yahoo.com, seekingalpha.com, wsj.com

### 검색 목록
- NYSE/NASDAQ/NYSE American 상장 관련 기업
- 해당 산업 ETF (Sector SPDR, iShares, Invesco 등)
- 핵심 비상장 기업 (미래 IPO 후보 가능성)
- 관련 외국 상장기업 (ADR 포함)

### 각 기업에 대해 수집할 정보
- 기업명 및 티커
- 거래소 (NYSE / NASDAQ)
- 시가총액 (대략적 규모)
- 한 문장 설명 (가치사슬에서의 위치와 역할)
- 순수 플레이 여부 (예: 순수 반도체 vs 반도체 사업부 포함 대형 복합기업)
- 가치사슬 소속 섹터

### 출력 형식
가치사슬 섹터별로 분류하고 각 섹터에 표를 작성한다.
이후 투자 확실성에 따라 계층화한다:
- **Tier 1**: 대형주, 순수 플레이, 섹터 선두주자
- **Tier 2**: 중형주, 순수 또는 높은 비중, 세부 섹터 선두
- **Tier 3**: 소형주, 개발 단계, 고위험 고탄성
- **Tier 4**: 관련 사업부가 있는 대형 복합 기업

## 4단계: 각 섹터 선두 기업 4대 거장 분석

각 가치사슬 섹터의 **Tier 1 및 Tier 2 기업**에 대해 다음 분석을 실행한다 (Tier 3/4 기업은 간략 코멘트로 충분):

### 4.1 비즈니스 본질 (단영평)
- 이 기업이 가치사슬에서 무엇을 하는지 한 문장으로 정의한다
- 매출 구조 및 성장률
- Gross Margin / Net Margin 수준 및 추세
- FCF(잉여현금흐름) 특성
- **핵심 질문**: 이것은 좋은 비즈니스인가? 왜인가?

데이터 출처:
- Gross Margin/매출 추세: macrotrends.net/stocks/charts/{TICKER}/gross-profit
- 연간 재무제표: stockanalysis.com/stocks/{ticker}/financials

### 4.2 해자 (MOAT, 버핏)
5가지 해자 유형별 점수 (★1-5):

| 해자 유형 | 강도 | 근거 |
|---------|-----|-----|
| 브랜드/가격 결정력 | | |
| 전환 비용 (Switching Cost) | | |
| 네트워크 효과 | | |
| 규모의 경제 | | |
| 기술/라이선스 장벽 | | |

**핵심 질문**: 10년 후에도 해자가 남아있는가?

### 4.3 리스크 (芒格/찰리 멍거)
- 이 기업이 가장 가능성 높은 실패 방식은 무엇인가?
- 최악의 시나리오에서 기업 가치는 얼마인가?
- 똑똑한 투자자가 이 주식을 사지 않는 이유는 무엇인가?

### 4.4 경영진 (단영평 + 버핏)
- CEO/창업자는 누구인가? 핵심 의사결정 기록은?
- 지분 비율 및 이해관계 일치 수준
- 간략 평가 (A/B/C 등급)

### 4.5 밸류에이션 스냅샷
- 현재 PER/PSR/EV/EBITDA
- 동일 섹터 경쟁사와 비교
- 간략 평가: 비쌈/적정/저렴

데이터 출처:
- 주요 지표: macrotrends.net/stocks/charts/{TICKER}/pe-ratio
- 경쟁사 비교: finviz.com/screener

### 4.6 추천도
★1-5로 표시:
- ★★★★★ = 코어 포지션 후보
- ★★★★☆ = 위성 포지션 후보
- ★★★☆☆ = 관찰 목록 (Watchlist)
- ★★☆☆☆ = 고위험 옵션 포지션
- ★☆☆☆☆ = 비추천

### 4.7 정보 충분도 등급 표시
| 등급 | 기준 |
|-----|-----|
| **A** | SEC 공시 + 복수 주요 매체 심층 분석 + 실적 발표 녹취 확인 가능 |
| **B** | 주요 재무 데이터 확인 가능하나 독립적 심층 분석 자료 제한적 |
| **C** | 기본 재무 데이터만 확인 가능. 비상장 또는 소규모 기업 |

## 5단계: 산업 수준 리스크 평가 (멍거 "체크리스트")

### 5.1 시스템적 리스크 체크리스트

| 리스크 | 확률 | 영향도 | 대응 전략 |
|------|-----|------|---------|
| 투자 논리 체인의 특정 단계가 반증됨 | | | |
| 대체 기술 출현 | | | |
| 규제/정책 블랙스완 (SEC, FTC, 반독점) | | | |
| 수요 경기순환적 하락 | | | |
| 밸류에이션 거품 붕괴 | | | |
| 거시경제 충격 (금리/달러 강세/경기침체) | | | |

### 5.2 역사적 유추
역사적으로 유사한 가치사슬 투자 테마를 찾고 최종 결과를 분석한다:
- 유추 산업은 무엇인가?
- 최종 승자는 누구였는가? (업스트림/미드스트림/다운스트림?)
- 대다수 투자자는 수익을 냈는가 손실을 봤는가?
- 현재 산업에 대한 시사점은 무엇인가?

예시 유추:
- 인터넷 버블(1995-2001): 인프라(Cisco) vs. 서비스(Amazon) 생존 구조
- 셰일 혁명(2010s): 서비스 기업(HAL/SLB) vs. E&P 기업 수익률 비교
- 스마트폰 생태계(2007-2020): 부품 공급업체 vs. OS/앱 플랫폼 승자 구조

### 5.3 편향 자기 점검
- **내러티브 편향**: 스토리가 너무 완벽하지 않은가?
- **앵커링 효과**: 최근 주가 상승에 앵커링되어 있지는 않은가?
- **군중 심리**: "모두가 사고 있기 때문에" 관심을 갖는 것은 아닌가?

## 6단계: 문명 트렌드 판단 (이록/Li Lu 프레임워크)

- 이 산업이 기반한 근본 트렌드는 "문명 수준의 패러다임 전환"인가, 아니면 "단계적 열풍"인가?
- 역사적으로 가장 유사한 기술 혁명의 유추는 무엇인가?
- 10-20년 후 이 산업의 최종 상태(endgame)는 무엇인가?
- 가치사슬에서 어떤 섹터가 "승자독식(winner-take-all)"을 실현할 가능성이 가장 높은가?
- 어떤 섹터가 파괴(disruption)될 가능성이 가장 높은가?

미국 산업별 문명 트렌드 판단 예시:
| 산업 | 트렌드 판단 | 이록 관점 핵심 |
|-----|-----------|-------------|
| AI 인프라 | 패러다임 전환 가능성 높음 | 전기화/인터넷에 비견. 다만 가치사슬 중 어디가 남을지가 핵심 |
| 전기차/배터리 | 패러다임 전환 진행 중 | 내연기관 교체는 확실. 브랜드 승자는 불확실 |
| 헬스케어 AI | 구조적 성장, 아직 패러다임 전환 미확인 | 규제·수가 리스크가 핵심 변수 |
| 핀테크 | 성숙기 진입, 일부 과열 | 결제 네트워크(Visa/MA) 해자가 생각보다 강고 |

## 7단계: 포트폴리오 배분 제안

### 7.1 추천 포트폴리오
다음 구조로 출력한다:

| 레이어 | 비중 | 종목 (티커) | 소속 섹터 | 핵심 논리 |
|------|-----|-----------|---------|---------|
| **코어 포지션** | 테마 비중의 50-60% | | | 가장 확실하고 해자가 넓음 |
| **위성 포지션** | 테마 비중의 25-35% | | | 탄성이 크고 확실성이 약간 낮음 |

## 출력 요건

1. 모든 분석에 데이터 근거를 첨부하고 출처를 표기한다
2. 핵심 데이터는 Markdown 표로 제시한다
3. 가치사슬 전체 지도는 코드 블록의 텍스트 차트로 표현한다
4. 각 섹터에서 최소 2-3개 선두 기업을 분석한다
5. NYSE/NASDAQ 전체 스캔은 가능한 한 완전하게 수행한다
6. 최종 보고서는 `reports/{산업명}-industry-{YYYYMMDD}.md` 형식으로 저장한다
7. 결론은 명확하게, 구체적인 종목·비중·가격 범위 제안을 포함한다
8. 각 분석 모듈 말미에 해당 거장의 "핵심 질문"을 배치한다
9. 모든 시가총액은 USD 기준 (B=billion, T=trillion)
