# 기업 심층 분석 시리즈: 8편으로 한 기업을 완전히 해부하기

$ARGUMENTS 에 대한 8편짜리 심층 장문 시리즈를 작성합니다. 공개 채널(블로그, 유튜브 등)에 게시하는 것을 목적으로 합니다. **이 skill의 핵심 경쟁력은 "잘 쓰는 것"이 아니라 "엄격하게 고치는 것"입니다 — 시중 재무 분석 기사의 99%는 본 skill의 팩트체크 기준을 통과하지 못합니다**.

참고 샘플: `reports/{기업명}/《{기업명} 완전 해부》/`

---

## 1. 사용 시나리오

사용자가 한 기업에 대해 "교과서 수준의 심층 연구"를 수행하고, **시리즈 장문**으로 공개 발행하고자 할 때 사용합니다. 단편 리포트와의 차이:
- 8편 합계 약 120,000자 이상, 인식 재설정부터 투자 결정 프레임워크까지 완결 구조
- 각 편이 독립적으로 읽힘 (단편 공유 가능), 하지만 전체적으로 밸류에이션/경영진/가격 판단이 일관되게 관통
- "90분을 들여 한 기업을 제대로 이해하려는" 독자를 위해 작성 — 증권사 고객용이 아님

**본 skill을 쓰지 말아야 하는 경우**: 단편 리포트, 분기 실적 코멘트, 산업 분석 — 그런 경우에는 `/investment-research`, `/earnings-review`, `/industry-research`를 사용하세요.

## 2. 시리즈 편목 템플릿 (8편)

| # | 편명 템플릿 | 핵심 질문 | 글자 수 |
|---|-----------|---------|--------|
| 01 | 당신은 X를 안다고 생각했겠지만, 사실은 모른다 | 인식 재설정: 흔한 오해 3가지 깨기 | 4,000-5,000 |
| 02 | X의 경제적 해자 — `<비즈니스 본질 한 문장>` | 해자가 얼마나 깊은지, 5년/10년 후에도 존재하는지 | 6,000-8,000 |
| 03 | X의 핵심 수익 엔진 — `<가장 수익성 높은 사업>` | 주력 사업이 무엇인지, 왜 지속 가능한지 | 6,000-8,000 |
| 04 | X의 재무제표 안에 숨어 있는 또 하나의 기업 — `<숨겨진 자산>` | 투자 포트폴리오 / 자회사 / 숨겨진 가치 | 8,000-10,000 |
| 05 | AI (또는 현재의 거대 서사) 시대, X는 승자인가 패자인가 | 시대적 변수: 사업부별 AI 영향 분석 | 8,000-10,000 |
| 06 | 버핏의 방식으로 X의 재무제표를 해부한다 | 재무 심층 분석: Gross Margin / FCF / ROE / SBC | 8,000-10,000 |
| 07 | `<경영진 핵심 발언>` — X의 경영진은 신뢰할 수 있는가 | 자본 배분 원칙 + 진정성 검증 + 후계 구도 | 8,000-10,000 |
| 08 | 얼마에 사야 하고, 어떤 신호가 오면 반드시 팔아야 하는가 (시리즈 최종화) | DCF 3시나리오 + 레드라인 리스트 + 포지션 프레임워크 | 10,000-12,000 |

목차 인덱스용으로 `00-시리즈-소개.md`를 별도 작성하되, 공개 발행하지 않습니다.

## 3. 글쓰기 스타일 가이드

### 어조

- **직접적, 날카롭게, 군더더기 없이** — 첫 문장에 바로 숫자 또는 반상식적 결론을 제시
- **가치투자 프레임** — Buffett / Munger / 段永平(단영평) / 李录(이록) 시각을 자연스럽게 녹임 (명언 나열 금지)
- **선입견 없이** — 먼저 데이터를 제시하고, 논리를 전개한 후, 마지막에 결론 도출
- **정반 양면 제시** — 핵심 판단마다 "다만 반대로 보면..." 형태의 반론 첨부
- **블로그/뉴스레터 가독성** — 제목과 첫 두 문장만 봐도 독립적으로 의미가 통해야 함 (모바일 미리보기 기준)

### 금지 표현

| 금지 표현 | 금지 이유 | 대체 표현 |
|----------|---------|---------|
| 명백히 / 반드시 / 틀림없이 | 주관적 절대화 | 데이터에 따르면 / 증거가 시사하는 바에 따르면 |
| ~라고 생각한다 / ~느낌이다 | 주관적 어투 | 삭제하거나 "이 프레임워크에 따르면"으로 대체 |
| 교과서적 / 신의 한 수 | 클릭베이트식 찬사 | 구체적 사실을 묘사 |
| 심각하게 저평가 / 극심한 불일치 | 강한 주관적 표현 | 구체적인 할인율(%) 제시 |
| 완벽한 / 흠잡을 데 없는 | 일방향 판단 | 반대 관찰 내용 추가 |

### 제목 스타일

- **대비되는 숫자** 또는 **반통념적 결론**을 훅으로 사용 ("15년간 7번 도전, 모두 실패", "연봉 $42.9M이 순이익의 0.0017%인 이유")
- 부제목은 중립적이고 내용을 개괄 ("— `<본질적 판단>`")
- **클릭베이트 표현 금지**: "작은 버핏", "미국판 X", "레전드" 등 일절 사용하지 않음
- 전문 독자에게 익숙한 용어 사용 ("Berkshire"가 "Buffett"보다, 개인 이름보다 회사명 우선)

## 4. 엄격한 팩트체크 체크리스트 (핵심 경쟁력)

### 글을 쓰기 전에 경계해야 할 "가짜 정밀함" 함정

1. **확률 가중 기댓값**: `30% × 시나리오A + 50% × 시나리오B + 20% × 시나리오C = 기대 수익률 +X%` 이런 계산은 거의 쓰레기입니다 — 확률 배분 자체가 순전히 주관적이어서 독자에게 잘못된 정밀함을 줍니다. **시나리오 + 발동 조건 + 방향성만 제시하고, 가중 기댓값은 계산하지 않습니다**.
2. **제3자 추정 MAU/시장점유율**: Sensor Tower, App Annie, Similarweb 등의 수치는 측정 방법에 따라 동시점에도 2-3배 차이가 날 수 있습니다. **가장 신뢰할 수 있는 두 곳의 수치만 anchor로 사용하고, 나머지는 정성적 묘사로 처리합니다**.
3. **과거 성장률 선형 외삽**: `2025년 +33% × 5년 복리 → 2030년 X` 는 금융 문맹 수준의 예측입니다. **시나리오 가정 + 상단/하단 범위 제시 + "예측이 아님" 명시**.
4. **공개되지 않은 지분율**: SpaceX, Stripe 같은 비상장 기업의 지분은 **공식적으로 공개된 적이 없습니다**. **범위로 제시하고, "알 수 없음"으로 표기합니다**.
5. **강한 인과 귀속**: 경쟁사의 실패 = X 때문이다. 복수의 원인을 모두 나열하고, **단일 원인 귀속은 하지 않습니다**.

### 수정 시 반드시 실행해야 할 7가지 점검

```
□ 1. 편 간 숫자 일관성: 시가총액, Non-GAAP 순이익, 핵심 지분율 (%) 전체 시리즈에서 동일
□ 2. 기준(basis) 명시: GAAP / Non-GAAP / Non-GAAP ex-SBC / FCF 각각 어느 기준을 사용했는지 전문에서 명확히
□ 3. 중복 계산 스캔: 이미 연결 대상인 자회사가 "투자 포트폴리오"에도 들어 있지 않은지, SOTP에서 이중 계산 없는지
□ 4. 비교 공정성: "주력 사업 PER (현금+포트폴리오 제거)" vs "경쟁사 PER (제거 안 함)"처럼 불공정한 비교 금지
□ 5. 확률 가중치 전면 삭제: 위 1번 참조
□ 6. 절대화 표현 전면 약화: grep "명백히|반드시|심각하게|교과서|완벽한"
□ 7. 제3자 데이터 출처 표기: 재무제표 외 모든 데이터 뒤에 "(출처: X)" 형식으로 표기
```

### 모델 편향 체크

글을 쓰기 전 **알려진 고위험 오류 유형을 먼저 나열합니다**:
- 역사적 수익률 배수: 반드시 총 투자금 기준 사용 (예: 33배, 58배가 아닌 누적 투자 기준)
- 지분율: 반드시 가장 최신 SEC 공시(13F, 10-K) 기준 사용 (예: Berkshire의 Apple 지분은 분기마다 변동)
- 특별 배당/스핀오프 회계 처리: 각 거래의 회계 처리 방식 및 인식 시점을 개별 확인
- 총 주식 수 리바운드: SBC가 연초에 집중 부여되면 주식 수가 단기 증가할 수 있음

## 5. 실행 절차

### 단계 1: 조사 (01-02편 작성 전 완료)

1. 회사의 최근 5년 연간 보고서(10-K)와 최신 분기 보고서(10-Q, 8-K) 읽기
   - Primary: macrotrends.net/stocks/charts/{TICKER}
   - Secondary: stockanalysis.com/stocks/{ticker}/financials
   - SEC 공시: sec.gov/cgi-bin/browse-edgar (10-K, 10-Q, 8-K)
2. 독립적인 셀사이드 리포트 최소 3개 읽기 (컨센서스 + 반컨센서스 찾기)
   - finance.yahoo.com, seekingalpha.com, wsj.com 등 참고
3. `/investment-team` 또는 `/investment-research`로 내부 연구 초안 먼저 생성
4. 사용자와 8편의 핵심 논점 확인 (다 쓰고 나서 방향이 틀렸음을 발견하는 사태 방지)

### 단계 2: 작성 (01 → 08 순서대로, 건너뛰기 금지)

- 각 편 완성 후 `reports/{기업명}/《{기업명} 완전 해부》/0X-XX.md` 에 저장
- 즉시 GitHub에 푸시하지 않음 — 사용자 검토 대기
- 사용자가 수정 의견을 주면 반영
- 수정 완료 후에만 `git push`

### 단계 3: 편 간 일관성 스캔 (8편 전부 작성 완료 후)

Explore agent를 병렬로 파견해 8편 전체에 대해 다음 점검 수행:
1. 동일 수치(시가총액, 순이익, 지분율 %)가 편 간에 일치하는지
2. 동일 용어(FCF, SBC, Non-GAAP)가 첫 등장 시 설명되었는지
3. 참조 관계: 02편에서 "06편 참조"라고 했을 때 실제로 대응하는지
4. 요점 요약 vs 본문의 숫자 일치 여부

### 단계 4: 발행 전 최종 점검

```bash
# 푸시 전 로컬에서 반드시 한 번 grep (개인정보 보호 규칙)
grep -r "linxuan\|/Users/\|<사용자 개인식별 정보>" reports/ | head
```

이상 없음을 확인한 후에만 `git pull --rebase && git commit && git push`.

## 6. 수정 의견 처리 절차

사용자가 수정 의견을 줄 때 다음 순서로 처리합니다:

### 1. 먼저 사실 확인 (바로 수정하지 말 것)

사용자가 "X 데이터가 틀렸다"고 하면, 먼저 Bash/Read로 원본 데이터를 교차 검증합니다:
- ai-berkshire 프로젝트 내 같은 기업의 earnings/재무 보고서 확인
- SEC 공시 원문, macrotrends.net, stockanalysis.com 확인
- "사용자가 제시한 데이터 vs 내가 조회한 데이터 vs 내가 기존에 사용한 데이터" 3자 비교 제시

### 2. 수정 등급 판단

| 등급 | 유형 | 처리 방법 |
|------|------|---------|
| 🔥 하드 에러 | 숫자 오류, 인과 오류, 기준 오류 | 반드시 수정, 망설임 없이 |
| ⚠️ 주관화 | 강한 주관 표현, 절대화, 클릭베이트 비유 | 약화 또는 삭제 |
| 🔬 세분화 | 출처 표기, 기준 세분화 | 우선순위 낮음, 가독성과 균형 |
| ❓ 신뢰 불가 | 제3자 추정치 차이 큼 | **고치는 것보다 삭제가 더 안전** (사용자 명시 지시에 따름) |

### 3. 수정 후 연동 점검

한 곳을 수정하기 전에 "이 숫자/개념을 인용하는 다른 곳이 어디인지" 먼저 생각합니다. 예:
- 시가총액 변경 → 전체 시리즈의 PER / 주력 사업 PER / 할인율 / FCF Yield 연동 수정
- 지분율 (%) 변경 → TOP 10 순위 + 역사적 지분 테이블 + 매도 리스트 연동 수정
- 용어 기준 변경 → 최초 정의 + 이후 인용 + 요점 요약 연동 수정

### 4. 푸시 후 즉시 보고

```
푸시 완료 (commit hash).
[N]건 수정 요약 [표 형식]:
- 수정한 내용
- 연동 수정한 내용
- 아직 수정하지 않은 내용

다음 지시를 기다립니다.
```

## 7. 본 skill이 하지 않는 것

- **독자를 대신해 투자 결정을 내리지 않습니다** — 모든 편의 말미에 "본 내용은 투자 권유가 아닙니다"
- **주가를 예측하지 않습니다** — "시나리오 + 발동 조건"만 제시
- **"기대 연환산 수익률" 가중값을 계산하지 않습니다** — 주관적 확률 배분은 독자를 오도합니다
- **"X 유명 투자자도 보유 중"이라고 쓰지 않습니다** — 타인의 포지션으로 자신의 판단을 정당화하는 것은 가치투자에 반합니다
- **8편 전부 강제로 쓰지 않습니다** — 특정 편이 독립적인 내용으로 채워지지 않을 경우(예: 경영진이 특별히 분석할 게 없는 경우), 다른 편에 합치거나 편수를 줄입니다

## 8. 준수 및 개인정보 보호

- 모든 공개 보고서는 **공개 정보만 사용** (10-K/10-Q/8-K, SEC 공시, 셀사이드 리포트, 공신력 있는 제3자 기관)
  - macrotrends.net, stockanalysis.com, finviz.com, finance.yahoo.com, seekingalpha.com, wsj.com
  - NYSE/NASDAQ/SEC 공시 원문
- **사용자의 개인 정보 일절 사용 금지** (개인 닉네임, 내부 메신저 내용, 비공개 보유 포지션)
- 푸시 전 grep으로 `linxuan` / `/Users/` / 사용자 개인식별 정보 등 개인정보 필드 반드시 스캔
- 공개 서명 방식은 사용자의 다중 신원 전략에 따르며, 혼용하지 않음

## 한 줄 요약

**《X 완전 해부 시리즈》의 핵심 역량은 "잘 쓰는 것"이 아니라 "엄격하게 고치는 것"입니다** —
재무 장문 기사의 89%가 가짜 정밀 수치, 주관적 확률 가중 기댓값, 절대화 표현 때문에 무너집니다. 본 skill은 그 함정들을 전부 표시하고, 쓰기 전에 피하고, 쓴 후에 깨끗이 걷어내기 위해 존재합니다.
