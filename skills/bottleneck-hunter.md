# 공급망 병목 헌터: AI 기반 글로벌 산업 사슬 병목 차익거래

$ARGUMENTS 메가트렌드에 대해 공급망 병목 스캔 및 차익거래 기회를 발굴한다.

## 핵심 철학

"AI가 어떤 주식을 추천하는가"를 묻지 말고, "이 트렌드가 계속 확장된다면 어느 고리가 먼저 부족해지는가"를 물어라.

전통적인 투자 리서치는 선도 기업과 이미 알려진 섹터에 집중한다. 이 시스템은 반대로 접근한다: **물리적 공급망의 목구멍 위치에서 출발해, 아무도 주목하지 않지만 일단 공급이 끊기면 산업 전체가 멈춰야 하는 기업을 찾는다.**

초과 수익의 원천: Layer 1 병목(GPU, HBM, 전력)은 이미 충분히 가격에 반영됐다. 진정한 알파는 **Layer 2, Layer 3**에 있다 — 광 모듈, 레이저 다이오드, InP 기판, SOI 웨이퍼, 에피택시 장비, 웨이퍼 레벨 테스트, IC 캐리어 기판, 특수 유리섬유 등이다.

## 1단계: 메가트렌드 확인

### 1.1 트렌드 선별 기준

작은 유행에서 허상을 찾지 않는다. 아래 조건을 **모두** 충족하는 메가트렌드만 추적한다:

| 기준 | 요건 | 검증 방법 |
|------|------|---------|
| 지속성 | 최소 3~5년의 확실한 성장 | 업계 전망 보고서, 설비투자(capex) 계획 검색 |
| 물리성 | 실제 하드웨어/소재/장비 건설이 필요 | "소프트웨어 업그레이드"와 "물리적 증설" 구분 |
| 규모성 | 전 세계 capex > $500억(50B)/년 | 주요 플레이어의 capex 가이던스 검색 |
| 가속성 | 수요 증가 속도 > 공급 증설 속도 | 수요 성장률 vs 생산능력 확장 계획 비교 |

### 1.2 현재 추적 중인 메가트렌드 목록

매 실행 시 업데이트한다. 초기 목록:

1. **AI 인프라 구축** — 데이터센터, GPU 클러스터, 네트워크 인터커넥트, 전력
2. **에너지 전환** — 원전 재가동, 전력망 업그레이드, 에너지 저장
3. **국방 현대화** — 서방 국방비 상승 사이클, 공급망 재편
4. **반도체 재산업화** — 미국·유럽·일본 보조금 공장 건설, 장비/소재 병목
5. **우주 경제** — 위성 인터넷, 발사 빈도 급증

사용자가 특정 트렌드(예: "AI 인프라")를 지정한 경우, 해당 트렌드에만 집중한다.

### 1.3 트렌드 검증 출력

```
트렌드명:
핵심 드라이버: (한 문장)
발생한 검증 이벤트 (최소 3개):
  1. [날짜] [이벤트] [출처]
  2.
  3.
Capex 규모: 전 세계 약 $XX B/년, 증가율 YY%
수급 불균형 판단: 수요 증가 속도 > 공급 증설 속도? 예/아니오/불확실
트렌드 확인: ✅ 추적 가능 / ❌ 증거 불충분, 추적 보류
```

## 2단계: 공급망 물리적 분해

### 2.1 레이어별 분해 프레임워크

**개념 수준에 머물지 말고, 물리적 실체까지 분해한다.**

```
Layer 0 (최종 수요): 최종 제품/서비스
    │
Layer 1 (핵심 부품): 시장이 충분히 주목한 핵심 하드웨어
    │                 ⬆ 가격 충분히 반영, 알파 제한적
    │─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
    │                 ⬇ 주목도 낮음, 알파 집중 구간
    │
Layer 2 (서브 부품/소재): 핵심 부품을 지지하는 부품과 소재
    │
Layer 3 (업스트림 장비/원자재): 서브 부품 제조에 필요한 장비와 원자재
    │
Layer 4 (기반 인프라): 전력, 냉각, 토지, 인력, 인증
```

### 2.2 AI 인프라를 예시로 한 분해 템플릿

```
Layer 0: AI 모델 훈련/추론 서비스
Layer 1: GPU/가속기, HBM 메모리, 서버, 데이터센터
Layer 2 (집중 스캔 구간):
  ├─ 네트워크 인터커넥트: 광 모듈, 광섬유, 스위치 칩, 동축 케이블
  ├─ 광통신 핵심: 레이저 다이오드(EML/VCSEL/CW), 변조기, 광검출기
  ├─ 반도체 소재: InP 기판, GaAs 기판, SOI 웨이퍼, SiC 기판
  ├─ 첨단 패키징: CoWoS 캐리어, HBM TSV, ABF 기판재
  ├─ PCB/캐리어: 고주파 고속 PCB, IC 캐리어, 특수 유리섬유
  ├─ 테스트: 웨이퍼 레벨 테스트(Probe Card), 번인 테스트, ATE
  ├─ 방열/냉각: 액냉 시스템, CDU, 침지식 냉각액
  └─ 전력 연결: 버스덕트, UPS, 배전반, 변압기
Layer 3:
  ├─ 에피택시 장비: MOCVD, MBE
  ├─ 리소그래피/식각: 특수 파장 리소그래피, InP 식각
  ├─ 원자재: 고순도 금속(인듐, 갈륨, 게르마늄), 특수 가스, 스퍼터링 타겟
  └─ 인증/표준: MSA 표준, Telcordia 인증
Layer 4:
  ├─ 전력: 원전, 천연가스 발전, 송변전
  ├─ 냉각수/방열 인프라
  └─ 데이터센터 부지/허가
```

## 3단계: 병목 식별 — "목구멍" 찾기

### 3.1 병목 판정 6가지 기준

Layer 2~3의 각 고리에 대해 하나씩 평가한다:

| # | 기준 | 질문 | 점수 |
|---|------|------|------|
| 1 | **공급 집중도** | 전 세계 공급업체가 3개 이하인가? | 🔴 2개 이하 / 🟡 3~5개 / 🟢 5개 초과 |
| 2 | **증설 주기** | 신규 생산능력 추가에 얼마나 걸리는가? | 🔴 2년 초과 / 🟡 1~2년 / 🟢 1년 미만 |
| 3 | **대체 난이도** | 다른 기술/소재로 대체 가능한가? | 🔴 대체 불가 / 🟡 부분 대체 / 🟢 쉽게 대체 |
| 4 | **가동률** | 현재 설비 가동률은? | 🔴 90% 초과 / 🟡 70~90% / 🟢 70% 미만 |
| 5 | **수요 증가율** | 하류 수요 증가율은? | 🔴 연 50% 초과 / 🟡 20~50% / 🟢 20% 미만 |
| 6 | **고객 검증 주기** | 신규 공급업체 진입 검증에 얼마나 걸리는가? | 🔴 1년 초과 / 🟡 6~12개월 / 🟢 6개월 미만 |

**병목 등급:**
- 🔴🔴🔴 4개 이상 → **S급 병목** (단일 장애 포인트, 최우선순위)
- 🔴🔴 3개 → **A급 병목** (심각한 제약)
- 🔴 1~2개 → **B급 병목** (압박은 있으나 관리 가능)
- 🔴 없음 → 병목 아님, 건너뜀

```

  1. [고리명] — [원인 한 문장] — 공급업체: [기업 목록]
  2.

A급 병목 (심각한 제약):
  1.
  2.

B급 병목 (압박 있음):
  1.
  2.

최근 변화 (이전 스캔 대비):
  - [신규/상향/하향/해제] [고리명] — [원인]
```

## 4단계: 기업 선별 — 병목에서 투자 대상으로

### 4.1 각 S급/A급 병목에서 관련 상장 기업 전체 파악

검색 방법:
- WebSearch "{병목 고리} supplier listed company NYSE NASDAQ"
- WebSearch "{병목 고리} manufacturer stock US"
- WebSearch "{병목 제품} market share company"

### 4.2 1차 필터링 기준 (빠른 선별)

| 기준 | 요건 | 이유 |
|------|------|------|
| 상장 여부 | NYSE/NASDAQ 상장 기업 (미국 증시 우선) | 거래 가능성 |
| 병목 사업 비중 | 병목 고리에서 30% 이상의 매출 | 순수성 |
| 시가총액 | 우선 $100B 미만 | 대형주는 이미 충분히 가격 반영 |
| 유동성 | 일평균 거래대금 > $1M | 진출입 가능성 |

### 4.2.1 밸류에이션 확인 (반드시 실행, 생략 불가)

**병목이 실재한다고 해서 투자 기회는 아니다.** 각 기업에 대해 PS, PE를 계산해 보고서에 반드시 표시해야 한다. 아래 복합 조건으로 밸류에이션 과잉 여부를 판단한다:

#### 밸류에이션 적신호 (아래 중 하나라도 해당 → 신호 강도 최대 ★★, "⚠️ 밸류에이션 과잉" 표시)

1. **시가총액 > TAM의 20%**: 이미 성장 기대가 과도하게 내재화됨
2. **PS > 30x이면서 매출 성장률 < 100%**: 고밸류에이션이나 성장률이 이를 뒷받침하지 못함. 성장률>100% 기업은 PS 적신호 면제이나, "⚠️ 고밸류에이션, 높은 성장률 지속 검증 필요" 표시 의무
3. **시가총액 > 5년 낙관적 매출 예측의 10배**: 가장 낙관적인 시나리오가 전부 실현되어도 현재 가격이 지나치게 높음
4. **증자 후 60일 내 주가 두 배**: 감정 주도 특성이 뚜렷, 신호 강도 한 단계 하향

#### 밸류에이션 황신호 (추가 설명 없으면 등급 하향)

1. **적자 + PS > 15x**: ★★★ 진입 허용하나 수익성 경로와 시간표 반드시 명시
2. **PS가 동업종 수익 기업의 5배 이상**: 프리미엄 근거 설명 필수 (시장점유율, 성장률 차이, 해자 차이)
3. **PER > 80x**: PEG 계산 및 성장률이 뒷받침하는지 명시 필요

#### 밸류에이션 청신호 (가점 항목)

- PS < 10x이면서 매출 성장 중 → 신호 강도 한 단계 상향 가능
- PER < 30x이면서 MOAT 보유 → "밸류에이션 안전마진 존재" 표시

#### 밸류에이션 합리성 검증 (필수 실행)

각 투자 대상에 대해 다음 질문에 답한다: "현재 시가총액으로 매수해 가장 낙관적인 시나리오가 전부 실현된다고 가정하면, 10년 후 25x PER로 매도 시 연간 수익률은 얼마인가?" 연간 수익률 <10% → "현재 가격에 안전마진 없음" 표시.

**주의**: 밸류에이션 확인의 목적은 "PS 100배 적자 기업 추천"이라는 명백한 오류를 방지하는 것이지, 고밸류에이션 초기 기업을 전부 배제하는 것이 아니다. 핵심은 성장률, TAM, 경쟁 구도가 현재 밸류에이션을 뒷받침할 수 있는지 구체적으로 분석하는 것이다.

### 4.3 심층 선별 기준

1차 필터를 통과한 기업 각각에 대해 평가한다:

```
## {기업명} ({티커})

**병목 포지셔닝**:
- 공급망 내 구체적 위치
- 시장점유율: 전 세계 X위, XX%
- 고객 명단 (알려진 것)

**생산능력 및 증설**:
- 현재 생산능력 / 가동률
- 증설 계획 / 일정
- 증설 소요 자금 vs 보유 현금

**재무 스냅샷**:
- 시가총액 / 매출 / 순이익 / 성장률
- 병목 사업 매출 비중
- GPM(매출총이익률) 추세 (병목이 심할수록 GPM 상승해야 함)

**리스크 체크리스트**:
- [ ] 대체 기술 리스크: 우회 가능한가?
- [ ] 희석 리스크: 대규모 증자/전환사채 있는가?
- [ ] 지정학 리스크: 민감 지역 소재 또는 수출 규제 대상인가?
- [ ] 경영진 리스크: 불량 이력이 있는가?
- [ ] 고객 집중 리스크: 단일 고객에 과도하게 의존하는가?
- [ ] 밸류에이션 과잉: 현재 밸류에이션이 3년치 성장을 이미 반영했는가?

**병목 지속성 판단**:
- 이 병목은 언제 해소될 것인가?
- 해소 후 이 기업에 남는 것은 무엇인가?
- 일회성인가, 지속적인가?
```

## 5단계: 교차 검증 — 한 가지 스토리만 듣지 않는다

### 5.1 정방향 검증

| 검증 항목 | 질문 | 검색 방법 |
|--------|------|---------|
| 고객 검증 | 주요 고객이 이미 계약/도입했는가? | 기업 공시, 고객 실적 발표에서 언급 검색 |
| 매출 검증 | 병목이 이미 매출 성장에 반영됐는가? | 최근 2~3분기 실적 발표 검색 |
| 가격 검증 | 제품 가격이 오르고 있는가? | 업계 가격 동향, 애널리스트 보고서 검색 |
| 생산능력 검증 | 생산능력이 실제로 빡빡한가? | 납기 데이터, 고객 불만 검색 |
| 자본 검증 | 증설을 위한 capex가 있는가? | 기업 capex 가이던스 검색 |

### 5.2 역방향 검증 (멍거식 반증)

| 역방향 질문 | 의미 |
|---------|------|
| 현명한 투자자가 이 주식을 사지 않는 이유는? | 알려진 베어리시 논거 발굴 |
| 이 병목을 우회할 수 있는가? 대안 경로는? | 기술 경로 리스크 |
| 미국/아시아 경쟁사가 빠르게 생산능력을 복제할 수 있는가? | 공급 충격 리스크 |
| 최종 수요가 50% 감소하면 이 기업은 어떻게 되는가? | 하방 민감도 |
| 경영진이 과거에 고점에서 증자로 희석한 적이 있는가? | 경영진 신뢰도 |
| 현재 밸류에이션이 내포하는 성장 가정은 무엇인가? | 밸류에이션 합리성 |

### 5.3 신호 교차 검증

- 동일 병목의 여러 기업이 모두 상승하고 있는가? (업종 검증)
- 하류 고객이 실적 발표에서 공급 부족을 언급했는가? (고객 검증)
- 업계 협회/리서치 기관에 관련 데이터가 있는가? (제3자 검증)

## 시간별 스캔 모드 (스케줄 태스크용)

매 시간 실행, "새로운 정보가 있을 때만 보고서 생성" 방식을 따른다:

### 스캔 절차 (매 시간)

1. **뉴스 스캔**: 지난 1~2시간의 공급망 관련 뉴스 검색
   - 키워드: supply chain bottleneck, shortage, capacity constraint, allocation, lead time, sole source, chip shortage, component shortage, price increase
   - 커버리지: 영어 소스 중심 (finance.yahoo.com, wsj.com, seekingalpha.com, Reuters, Bloomberg)
2. **시장 신호**: 추적 중인 기업의 주가 변화 확인 (특히 5% 초과 이상 변동)
3. **실적/공시**: 병목 관련 기업의 실적 발표 또는 중요 공시 여부 확인
4. **밸류에이션 기회**: 관찰 목록 기업이 시장 하락 등으로 매수 구간에 진입했는지 확인
5. **보고서 생성 여부 결정**:
   - 새로운 병목 신호, 명확한 투자 대상, 중요한 상태 변화 → **보고서 생성**
   - 새로운 발견 없음 → **보고서 미생성**, 로그에 "이번 스캔 새 신호 없음"만 기록

## 핵심 원칙 (최우선순위)

1. **AI에게 주식 추천을 시키지 말고, 공급망을 분해하게 하라** — 질문이 답변보다 중요하다
2. **물리적 실체 우선** — 실제 물리적 제품/소재/장비가 필요한 고리만 주목한다
3. **Layer 2, Layer 3** — 이미 충분히 가격에 반영된 선도 기업을 쫓지 않는다
4. **교차 검증** — 모든 결론에 최소 2개의 독립적 출처가 있어야 한다
5. **불확실성에 솔직하게** — 데이터를 찾을 수 없으면 "데이터 부족"이라 쓰고 추측으로 채우지 않는다
6. **병목에는 유효기간이 있다** — 모든 병목은 결국 해소된다. 핵심은 시간 창을 판단하는 것이다
7. **소형주 = 좋은 기회가 아니다** — 소형주도 나쁜 기업일 수 있다. 반드시 재무 품질 관문을 통과해야 한다
8. **병목이 실재한다 ≠ 투자 기회** — 기업이 가장 빡빡한 병목 위에 앉아 있어도, PS>30x이거나 여전히 적자라면 현재 가격은 매수 시점이 아니다. **밸류에이션은 하드 기준이며, 병목 순수성, 신호 강도, 내러티브 매력으로 덮어쓸 수 없다.** 오른 병목주를 놓치는 것이 PS 100배 적자 기업을 매수하는 것보다 낫다
9. **CLAUDE.md 객관성 원칙 준수** — 강세를 전제하지 않는다. 데이터 먼저, 결론은 나중에
