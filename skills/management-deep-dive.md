# 경영진 심층 연구: 주식을 산다는 것은 사람을 사는 것이다

$ARGUMENTS 에 대해 경영진 심층 연구를 수행한다.

**지원 입력 형식**: `회사명` 또는 `인물명 회사명`, 예시: `Apple`, `Jensen Huang NVIDIA`, `Tim Cook Apple`

> "주식을 산다는 것은 사람을 사는 것이다. 믿을 수 있는 사람을 찾아라, 그리고 장기 보유하라." — 단융핑(Duan Yongping)
>
> "경영진을 평가할 때는 아무도 보지 않을 때 그들이 무엇을 하는지를 보라." — Warren Buffett

## 설계 철학

대부분의 투자 분석은 경영진 평가를 표면적인 수준에서 멈춘다: 이력서, 지분율, 보수. 하지만 Buffett은 경영진과 식사하며 대화하는 데 많은 시간을 쏟고, Li Lu는 투자의 본질은 사람에 대한 투자라고 말하며, 단융핑(Duan Yongping)은 주식을 산다는 것은 곧 사람을 사는 것이라고 말한다.

이 Skill은 `/investment-research` 5단계 경영진 평가의 **심화 버전**이다. 표준 투자 리서치에서 경영진 점수가 불확실하거나 (★★★ 이하), 또는 경영진이 핵심 투자 논거일 때 이 Skill로 심층 연구를 수행한다.

AI가 경영진과 직접 대화할 수는 없지만, 공개 정보를 통해 다음을 수행할 수 있다:
- **경영진의 말과 행동 일치 여부 추적** (약속 vs. 이행)
- **모든 중요 자본 배분 결정의 수익률 분석**
- **어려운 시기의 결정을 통해 품성 추론**
- **직원/고객/공급업체 피드백을 통한 측면 검증**

## 실행 절차

### 1단계: 핵심 경영진 파악 및 병렬 데이터 수집 시작

WebSearch를 사용해 다음 핵심 인물을 확인한다:

| 역할 | 성명 | 재임 기간 | 배경 | 지분/스톡옵션 |
|------|------|-----------|------|--------------|
| CEO | | | | |
| CFO | | | | |
| 창업자 (현직이 아닌 경우) | | | | |
| 실질 의사결정권자 (CEO와 다른 경우) | | | | |
| 기타 핵심 임원 | | | | |

**주의**: "실제 의사결정자"와 "직함상 이름"을 구분하라. 일부 회사는 창업자가 공식 직함을 내려놓았어도 여전히 핵심 영향력을 행사한다 (예: Elon Musk의 Tesla 이사회 퇴임 후에도 지속적 영향력).

핵심 인물 확인 후, Task 도구를 활용해 여러 백그라운드 Agent를 **병렬**로 실행해 다음 데이터를 수집한다:
1. Agent 1: CEO 공개 발언 및 예측 기록 (주주서한, 실적 컨퍼런스콜, 인터뷰, SNS)
2. Agent 2: 자본 배분 결정 기록 (M&A, 자사주 매입, 배당, 신사업 투자)
3. Agent 3: 지배구조 및 보수 구조 (주식 구조, 특수관계인 거래, 임원 보수)
4. Agent 4: 측면 검증 정보 (직원 평가, 고객 피드백, 업계 평판)

**주요 데이터 소스**:
- SEC 공시 (Proxy Statement DEF 14A, 10-K, 8-K): sec.gov/cgi-bin/browse-edgar
- 실적 컨퍼런스콜 transcript: seekingalpha.com, wsj.com
- 임원 보수 및 지배구조: macrotrends.net, stockanalysis.com/stocks/{ticker}/financials
- 직원 평가: glassdoor.com
- 뉴스 및 인터뷰: finance.yahoo.com, wsj.com, seekingalpha.com

### 2단계: CEO 역량 평가

#### 2.1 전략적 통찰력

CEO의 최근 5년 공개 발언 (주주서한, 실적 컨퍼런스콜, 인터뷰, SNS)을 검색하여 다음 사항에 대한 판단을 추출한다:

| 시기 | CEO의 판단/예측 | 실제 결과 | 정확도 |
|------|----------------|-----------|:------:|
| | "We believe the X market will..." | X 시장 실제 결과... | ✅/❌ |
| | "Our focus for the next 3 years will be..." | 실제 실행 결과... | ✅/❌ |

**핵심 질문**:
- CEO가 시장보다 앞선 정확한 판단을 내린 적이 있는가?
- CEO가 모두가 낙관적일 때 냉정함을 유지한 적이 있는가?
- CEO의 산업 트렌드 이해는 시장 추종인가, 독립적 사고인가?

#### 2.2 실행 능력

| 항목 | 평가 | 근거 |
|------|------|------|
| 전략 → 실행 | 말한 것을 실제로 이행했는가? | |
| 조직 역량 | 인재를 유치하고 유지할 수 있는가? | |
| 위기 대응 | 어려운 상황에서 어떻게 대응했는가? | |
| 수정 속도 | 실수 후 방향 수정이 빠른가? | |

### 3단계: 성실성 평가 (가장 중요)

**Buffett**: "우리는 세 가지 품성을 찾는다: 성실함, 지성, 에너지. 첫 번째가 없다면 나머지 둘이 당신을 죽일 것이다."

#### 3.1 약속 vs. 이행 추적

최근 3년간의 실적 컨퍼런스콜, 주주서한, 공개 인터뷰에서 경영진이 한 **구체적인 약속**을 추출한다:

| # | 시기 | 약속 내용 | 약속 장소 | 이행 여부 | 평가 |
|---|------|----------|----------|----------|------|
| 1 | | "We will achieve profitability in X segment by 2025" | 2024 실적 컨퍼런스콜 | | ✅/⚠️/❌ |
| 2 | | "We plan to buy back $X billion" | 2024 주주서한 | | ✅/⚠️/❌ |

**이행률 기준**:

| 약속 이행률 | 평가 |
|:----------:|------|
| >80% | 우수 — 말한 대로 행동함 |
| 60–80% | 합격 — 대방향은 맞지만 실행에 편차 있음 |
| 40–60% | 우려 — 과도한 약속, 부족한 이행 |
| <40% | 심각한 문제 — 신뢰 불가 |

#### 3.2 어려운 시기의 대응

회사 역사상 주요 위기/어려움 (주가 급락, 실적 미스, 규제 충격, 경쟁 심화)을 검색하고 경영진의 대응을 분석한다:

| 위기 사건 | 시기 | 경영진 반응 | 사후 평가 |
|---------|------|-----------|----------|

**주목할 점**:
- 적극적으로 소통했는가, 아니면 회피했는가?
- 내부 요인으로 귀인했는가, 아니면 외부로 책임을 전가했는가?
- 어렵지만 올바른 결정을 내렸는가, 아니면 단기적으로 시장을 달래는 선택을 했는가?

#### 3.3 이해관계자에 대한 태도

| 이해관계자 | 경영진 태도 | 근거 | 평가 |
|-----------|-----------|------|------|
| 주주 | 존중/무시/이용 | | |
| 직원 | 배려/착취/무관심 | | |
| 고객/사용자 | 고객 중심/단기 착취 | | |
| 공급업체 | 공정한 협력/극단적 압박 | | |
| 규제/사회 | 준법 협력/회색지대 활용 | | |

**Li Lu**: "이해관계자에 대한 태도가 기업의 장기 생명력을 결정한다. 단기 착취는 효율을 높일 수 있지만, 장기적으로는 생태계를 훼손한다."

### 4단계: 자본 배분 능력

이것은 Buffett이 경영진에게 가장 중요하게 보는 능력이다 — **벌어들인 $1을 경영진이 얼마로 만들 수 있는가?**

#### 4.1 자본 배분 결정 기록

최근 5년간 회사의 주요 자본 배분 결정을 검색하여 항목별로 평가한다.

**M&A 기록**:

| 시기 | 인수 대상 | 금액 | 전략적 논리 | 사후 수익률 | 점수(1–5) |
|------|----------|------|-----------|-----------|:---------:|

**자사주 매입 기록**:

`tools/financial_rigor.py verify-valuation`을 사용해 매입 당시 및 현재의 PER 등 밸류에이션 지표를 검증한다.

| 시기 | 매입 금액 | 평균 매입가 | 당시 PER | 사후 평가 | 점수(1–5) |
|------|----------|-----------|:--------:|---------|:---------:|

**배당 기록**:

| 연도 | 배당 금액 | 배당 성향 | 동기간 FCF | 지속 가능성 |
|------|----------|:--------:|----------|:----------:|

**신사업 투자**:

| 시기 | 투자 분야 | 누적 투입액 | 현재 상태 | 수익률 평가 | 점수(1–5) |
|------|----------|-----------|---------|-----------|:---------:|

#### 4.2 자본 배분 점수표

| 항목 | 점수(1–5) | 설명 |
|------|:---------:|------|
| M&A 규율 | | 합리적인 가격에 인수했는가? 통합은 어떠했는가? |
| 자사주 매입 타이밍 | | 저평가 시 매입, 고평가 시 중단했는가? |
| 배당 합리성 | | 배당 성향이 FCF와 매칭되는가? |
| 신사업 투자 | | 성공률은? 손절 규율은? |
| 현금 관리 | | 현금 보유가 적정한가? 과도하게 쌓아두지 않는가? |
| **종합 점수** | | |

**Buffett 기준**: 이상적인 경영진은 좋은 기회가 있을 때 과감히 투자하고, 기회가 없을 때는 적극적으로 자사주 매입/배당을 실시하며, 절대로 비싼 가격에 M&A를 하지 않는다.

#### 단융핑(Duan Yongping)의 "사람 투자" 기준

> 다음 세 가지 질문에 답하라:
> 1. **이 사람은 성실한가?** (정직하고, 주주를 착취하지 않는가)
> 2. **이 사람은 능력이 있는가?** (전략적 통찰력 + 실행력 + 자본 배분)
> 3. **이 사람에게 10년간 내 돈을 맡길 수 있는가?**
>
> 세 가지 모두 "예" = ★★★★★ (5점)
> 앞의 두 가지가 "예" = ★★★★ (4점)
> 첫 번째만 "예" = ★★★ (3점)
> 첫 번째가 "아니오" = ★ (1점, 투자 불가)

## 핵심 원칙

- **성실성은 거부권 항목이다** — 능력은 배울 수 있지만, 품성 문제는 고칠 수 없다
- **말이 아닌 행동을 보라** — 경영진이 무슨 말을 하는지가 아니라, 무엇을 했는지가 중요하다
- **어려울 때 진실이 드러난다** — 순풍에는 누구나 좋은 CEO다, 역풍에서 진면목이 보인다
- **자본 배분이 최종 시험이다** — 돈 버는 것은 쉽다, 번 돈을 잘 배분하는 것이 어렵다
- **경영진에게 빠지지 마라** — 객관성을 유지하라, 당신이 존경하는 사람도 큰 실수를 저지를 수 있다
