# 산업 퍼널 스크리닝: 전체 시장에서 최종 3종목까지의 가치투자 정선 프로세스

$ARGUMENTS 산업/테마에 대해 퍼널 방식의 가치투자 스크리닝을 실행한다. 전체 시장 스캔에서 시작해 단계별로 압축하여 최종 3개 종목을 선정한다.

## 적용 시나리오

어떤 산업이나 투자 방향(예: "AI 인프라", "바이오테크", "전기차", "클라우드 컴퓨팅")을 제시했을 때:
1. 중요한 종목을 빠뜨리지 않도록 전체 시장을 커버한다 (NYSE/NASDAQ 전체 + 관련 ETF 구성 종목)
2. 통일된 기준으로 "스토리 주식"과 품질 미달 기업을 걸러낸다
3. 진짜 깊이 연구할 가치가 있는 상위 3종목에 집중력을 모은다
4. 각 단계에서 명확한 통과/탈락 기준을 유지하여 복기와 추적이 가능하다

`industry-research`와의 차이:
- `industry-research`: 산업 체인 구조와 전체 그림, 세그먼트 분석에 초점
- `industry-funnel`: 개별 종목 선별 퍼널에 초점, 전체 시장에서 단계별로 3종목까지 압축

두 스킬은 상호 보완적이다: 먼저 `industry-research`로 산업 구조를 파악하고, 이후 `industry-funnel`로 최적 종목을 정선한다.

## ⓪ 사전 점검: 데이터 소스 접근 확인

```bash
python3 tools/site_preflight.py industry-funnel
```

퍼널 스크리닝은 특정 티커 없이 사이트 접근성만 확인한다. 차단된 소스가 있으면 스크립트가 대체 소스를 출력한다. **차단 여부와 관계없이 스크리닝을 계속 진행한다.**

**⓪ 결과 처리 (필수)**

1. **보고서 상단 "데이터 접근성" 절에 결과를 기록한다** — 무엇이 막혔고 무엇으로 대체했는지.
2. **차단된 소스에서 얻은 수치는 신뢰도를 한 단계 낮춘다**(🟢→🟡). 403은 직접 열기만 막힌
   것이라 `WebSearch(allowed_domains=['해당도메인'])`로 우회 가능하나 원문 확인은 아니다.
3. 🔴 **검색 경유는 연도별 시계열 표를 주지 않는다**(실측: 10년 ROE 질의 4회 재시도에도 값
   0건). 2단계 지표 스크리닝의 시계열은 **stockanalysis.com 또는 SEC 원문**에서 가져온다.

## ⓪-2 선행 보고서 데이터 기준일 확인

`reports/{산업명}-industry-{YYYYMMDD}.md` (즉 `/industry-research` 결과물)가 존재하면 먼저 읽고 "데이터 기준일"을 확인한다.

- 기준일이 **3개월 이내** → 가치사슬 구도, TAM 등 해당 데이터를 그대로 재사용 가능
- 기준일이 **3개월 초과** → 해당 항목은 "데이터 노후화" 표시를 달고, 이번 퍼널 스크리닝에서 최신 수치로 재검색하여 갱신한다
- 선행 보고서가 없으면 별도 표시 없이 진행하되, 이번 퍼널 보고서에도 동일하게 데이터 기준일을 표기한다 (아래 출력 요구사항 참조)

## 퍼널 구조 전체 개요

```
1단계: 전체 시장 스캔     30-60개   (거래대금 + 수익률 + 시가총액 상위 30개의 합집합)
       ↓ 가치투자 5개 핵심 지표
2단계: 1차 스크리닝        ≤ 10개   (5개 지표 전부 통과 + MOAT ★★★ 이상)
       ↓ 정밀 분석
3단계: 정밀 분석           ≤ 10개   (각 종목당 300-500자 구조화 분석)
       ↓ 최종 선정
4단계: 4대 투자 대가 심층 분석  3개  (각 종목당 800-1200자, 버핏·멍거·단융핑·리루 시각)
       ↓
출력: 투자 추천 + 매매 신호 + 포지션 제안
```

각 단계에서 "탈락된 종목"은 반드시 탈락 이유를 기록해야 한다. 블랙박스 방식은 금지한다.

> **토큰 예산 ([token-budget.md](token-budget.md))** — 퍼널은 **위로 갈수록 얕게, 아래로 갈수록
> 깊게** 파는 구조다. 이 원칙이 깨지면(30~60개 종목을 전부 깊이 조사) 비용이 폭발한다.
>
> | 단계 | 종목 수 | 종목당 조사 상한 |
> |---|---|---|
> | 1단계 스캔 | 30~60 | **개별 조회 금지** — 스크리너/목록 페이지에서 일괄로 받는다 |
> | 2단계 1차 스크리닝 | ≤10 | WebSearch 1회 + WebFetch 1회 (한 페이지에 5개 지표가 대부분 있다) |
> | 3단계 정밀 분석 | ≤10 | WebSearch 2회 · WebFetch 2회 |
> | 4단계 4대가 심층 | 3 | WebSearch 6회 · WebFetch 5회 |
>
> - Agent를 띄운다면 **깊이는 1단계**, 동시 실행 8개까지, 하위 Agent 스폰 금지(TB-1).
> - 보고서는 **Write 1회**로 저장한다(TB-5). 못 구한 값은 `⬛`.
> - ⚠️ 이 스킬 1회 실행의 정상 범위는 **5~12M 토큰**이다.

## 1단계: 전체 시장 스캔 진입점

### 1.1 활성 종목 정의 (세 가지 카테고리 합집합)

**A 카테고리 - 거래 활성도**:
- 최근 30일 일평균 거래대금 기준 산업 내 상위권 (NYSE/NASDAQ 각 상위 30개)

**B 카테고리 - 수익률 순위**:
- 최근 30일 수익률 상위 20개
- 최근 90일 수익률 상위 20개
- 두 리스트의 합집합

**C 카테고리 - 시가총액 기준**:
- 산업 내 시가총액 상위 30개 (등락 무관)

최종 스캔 풀 = A ∪ B ∪ C, 예상 30-60개.

### 1.2 반드시 스캔해야 할 시장

| 시장 | 권장 데이터 소스 |
|------|----------------|
| NYSE/NASDAQ 대형주 | finviz.com/screener (섹터 필터), S&P 500 구성 종목 |
| 성장주 & 중형주 | finviz.com/screener, Russell 2000 ETF 상위 보유 종목 |
| 관련 ETF 구성 종목 | 섹터 ETF 상위 10개 보유 종목 (예: XLK, QQQ, SOXX) |
| 국제 상장 종목 | 미국 거래소에 ADR 형태로 상장된 해외 기업 (반도체·전자 특히 주의) |
| 비상장 기업 | "미래 IPO 후보" 별도 항목으로 정리, 최신 밸류에이션과 예상 IPO 시기 기재 |

**finviz 무료(비-Elite) 스크리닝 제한 보강**: finviz 무료 계정은 일부 세부 필터가 제한되어, 거래대금·시총 상위에 들지 않는 중소형 니치 종목이 1단계 스캔에서 처음부터 누락될 수 있다. 이를 보강하기 위해 다음을 추가로 수행한다.
- **SEC EDGAR SIC 코드 전체 스캔 (핵심 보강)**: `sec.gov/cgi-bin/browse-edgar?action=getcompany&SIC={코드}&type=10-K&dateb=&owner=include&count=300` 으로 해당 산업의 SIC 코드에 등록된 **전체** 상장사를 조회한다. finviz와 달리 거래대금·시총으로 거르지 않고 등록된 모든 기업을 보여주므로, Elite 제한과 무관하게 니치·소형주 누락을 구조적으로 줄인다. SIC 코드를 모르면 먼저 WebSearch로 "{산업명} SIC code" 또는 대표 기업의 EDGAR 프로필에서 SIC 코드를 확인한다. (주의: 다수 외국 민간 발행사(ADR)는 10-K 대신 20-F를 제출하므로 `type=20-F`로 추가 조회해야 하며, 그래도 일부 ADR 누락은 남을 수 있다)
- 다양한 섹터 themed ETF(예: SOXX, SMH, ARKK 등 산업에 맞는 ETF)를 폭넓게 합집합에 포함
- stockanalysis.com 스크리너로 finviz와 다른 필터 기준으로 교차 스캔
- Yahoo Finance Screener로 보조 교차검증
- WebSearch로 "저평가 + 소형주 + 산업명" 등 정성적 키워드 검색을 병행해 정량 필터가 놓친 종목 보충
- SEC EDGAR 13F 공시(저명 가치투자 펀드)를 참고해 후보군에 강제 포함할 종목 확인

위 보강을 거쳐도 (특히 20-F 미조회 시) 잔여 누락 가능성은 5.4(정보 충분도 자가 평가)에 명시적으로 기재한다.

### 1.3 출력 형식

| 기업명 | 티커 | 거래소 | 시가총액 | 핵심 사업 한 줄 요약 | 해당 산업 매출 비중 | 입선 카테고리 (A/B/C) |
|--------|------|--------|---------|-------------------|-----------------|-------------------|

**핵심 자가 점검**:
- 해당 산업 매출 비중 < 30%인 "간접 관련주"는 주의 표시를 달고 "비순수 종목"으로 표기
- 소형주라고 해서 대형주 선호 편향으로 빠뜨리지 말 것
- ETF 구성 종목과 finviz 스크리너 결과를 반드시 교차 확인할 것

## 2단계: 가치투자 5개 핵심 지표 1차 스크리닝 → ≤ 10개

1단계의 30-60개 기업에 5개 핵심 지표를 순서대로 적용한다.

### 2.1 5개 핵심 지표

| # | 지표 | 통과 기준 | 완화 조건 | 데이터 소스 |
|---|------|---------|---------|-----------|
| 1 | PER 밸류에이션 | 합리적 수준 (역사적 구간·동종업계 비교 기준) | 고성장주는 PEG < 1.5까지 허용 | macrotrends.net, stockanalysis.com |
| 2 | ROE | > 15% 또는 최근 3년 개선 추세 | 자본집약적 산업은 완화 가능 | stockanalysis.com/stocks/{ticker}/financials |
| 3 | 영업 현금흐름 | 양(+)이고 순이익 대비 > 70% | — | SEC 10-K/10-Q, stockanalysis.com |
| 4 | 부채비율 (D/E) | < 60% (또는 업종 표준 이내) | 유틸리티·인프라는 70%까지 허용 | stockanalysis.com, macrotrends.net |
| 5 | MOAT 퀵 평가 | ★★★ 이상 | — | 정성적 판단 |

**MOAT 5가지 유형**:
- 브랜드 / 가격결정력
- 전환 비용 / 고객 고착도
- 네트워크 효과
- 규모의 경제
- 기술 / 특허 / 라이선스 / 규제 장벽

### 2.2 출력 형식

| 기업 | PER | ROE | FCF/순이익 | D/E | MOAT | 종합 | 통과/탈락 | 탈락 이유 |
|------|-----|-----|-----------|-----|------|------|---------|---------|

**보류 규칙**:
- 5개 전부 통과 → 바로 보류
- 4개 통과 + 1개 근접 → 보류하되 주의 표시
- 4개 미만 통과 → 탈락, 이유 명기

**목표**: ≤ 10개 보류. 보류 수가 과도할 경우 (> 12개), MOAT 기준을 ★★★★로 높여 재스크리닝.

## 3단계: 정밀 분석 (≤ 10개, 각 종목당 300-500자)

1차 스크리닝을 통과한 종목들에 대해 구조화된 분석을 수행한다.

### 3.1 각 기업 분석 템플릿

```

**재무 품질**:
- 매출 성장률 / 이익 성장률 / 매출총이익률 / ROE / FCF
- 핵심 변화 (최근 1-2년 중 가장 중요한 재무적 전환점)

**MOAT 깊이**:
- 주요 MOAT 유형 + 구체적 근거
- 5년 후에도 MOAT가 유지될지 간단한 판단

**주요 리스크 (상위 3개)**:
1.
2.
3.

**밸류에이션 퀵 평가**:
- 현재 PER/PS/EV/EBITDA + 역사적 구간 내 위치
- 동종업계 비교
- 한 줄 결론: 비싸다 / 적정 / 저렴하다

**최종 3개 후보 진입 여부**: 예 / 아니오 (이유)
```

### 3.2 최종 3개 선정 기준

점수 순위로 상위 3개를 고르는 것이 아니라, "포트폴리오 상호 보완성"을 기준으로 선정한다:
- 최소 1개: "고확실성·저변동성" (버핏 유형)
- 최소 1개: "중간 확실성·중간 변동성" (성장주 유형)
- 선택 1개: "고변동성·고위험" (옵션형)

특정 서브섹터에서 충분히 좋은 종목 3개를 찾지 못할 경우, 억지로 채우지 말고 "최종 2개 + 관찰 1개"로 기재한다.

## 4단계: 4대 투자 대가 심층 분석 (3개 종목, 각 800-1200자)

최종 선정 3개 종목에 대해 4대 투자 대가 시각의 심층 분석을 실행한다.

### 4.1 단융핑(Duan Yongping) 시각: 사업의 본질

- 이 회사가 하는 사업을 한 문장으로 정의한다
- 이것이 좋은 사업인가? 왜 그런가?
- 이 회사의 "본분"은 무엇인가? 경영진이 이탈하고 있지는 않은가?
- 비즈니스 모델의 "지속성"은 어디에서 오는가?

### 4.2 워런 버핏 시각: MOAT 깊이

- 5가지 MOAT 유형별 점수 (★1-5), 구체적 근거와 함께 기재
- 10년 후에도 MOAT가 유지될 것인가?
- 현재 매수 시 "안전마진"은 어디에 있는가?

| MOAT 유형 | 강도 | 구체적 근거 |
|----------|------|-----------|
| 브랜드 / 가격결정력 | | |
| 전환 비용 | | |
| 네트워크 효과 | | |
| 규모의 경제 | | |
| 기술 / 특허 / 라이선스 장벽 | | |

### 4.3 찰리 멍거 시각: 리스크와 실패 패턴

- 이 회사는 어떻게 실패할 가능성이 가장 높은가? (상위 3가지 실패 경로)
- 최악의 시나리오에서 이 회사는 얼마짜리인가? (간소화된 밸류에이션)
- 왜 똑똑한 투자자들이 이 주식을 사지 않는가? (역방향 논증)
- 윤리적·컴플라이언스·경영진 리스크가 있는가?

### 4.4 리루(Li Lu) 시각: 문명적 트렌드 포지셔닝

- 이 회사가 속한 섹터는 "문명적 패러다임 전환"인가, 아니면 "사이클적 붐"인가?
- 역사상 가장 유사한 기술 혁명의 비유는 무엇인가?
- 10-20년 후 이 회사의 최종 형태는 어떤 모습인가?
- 승자독식 구조가 형성될 것인가?

### 4.5 종합 추천도

```
추천도: ★★★★☆
포지션 유형: 코어 / 위성 / 옵션형 / 관찰
매수 구간 제안: 현재가 / N% 조정 후 / 인내심을 갖고 대기
권장 비중: 해당 테마 포지션의 X%
핵심 모니터링 지표: (이 종목의 투자 논리가 뒤집힐 신호는 무엇인가)
```

## 5단계: 종합 출력

보고서 마지막에 통합 정리:

### 5.1 최종 3개 종목 조합표

| 기업 | 유형 | 추천도 | 권장 비중 | 핵심 논리 | 핵심 리스크 |
|------|------|-------|---------|---------|-----------|
| A | 코어 | ★★★★★ | 50-60% | | |
| B | 위성 | ★★★★☆ | 25-35% | | |
| C | 옵션형 | ★★★☆☆ | 5-15% | | |

### 5.2 산업 ETF 대안

개별 종목 선택을 원하지 않는 경우, 관련 ETF 1-3개를 제시한다 (예: XLK, QQQ, SOXX, XLV 등 섹터 ETF).

### 5.3 산업 전체 위치 판단

- 산업 PER/PBR 역사적 백분위
- 자금 흐름 (ETF 순유입/유출, 애널리스트 커버리지 밀도, 기관 포지션 변화)
- 전체적으로 "초기 / 확장 / 성숙 / 쇠퇴" 중 어느 단계에 있는가

### 5.4 정보 충분도 자가 평가 (필수 기입)

| 항목 | 등급 | 설명 |
|-----|------|-----|
| 기업 재무 데이터 완전성 | A/B/C | |
| 밸류에이션 데이터 최신성 | A/B/C | |
| 산업 구도 판단 | A/B/C | |
| 경영진 정보 | A/B/C | |

A = 데이터 충분하고 신뢰 가능; B = 일부 누락이 있으나 주요 결론에 영향 없음; C = 누락 상당, 결론은 주의 필요.

### 5.5 업데이트 필요 데이터 포인트

명확하게 기재: 어떤 데이터가 추정치인지, 어떤 데이터를 향후 검증해야 하는지, 어느 분기 실적발표를 중점 추적해야 하는지.

### 5.6 자료 출처 목록

모든 데이터·결론의 출처 링크를 분류하여 나열한다 (SEC 공시, 재무 데이터 사이트, 뉴스, 산업 리포트).

**권장 데이터 소스**:
- 재무 데이터: macrotrends.net/stocks/charts/{TICKER}, stockanalysis.com/stocks/{ticker}/financials
- SEC 공시: sec.gov/cgi-bin/browse-edgar (10-K, 10-Q, 8-K)
- 스크리닝: finviz.com/screener
- 뉴스·분석: finance.yahoo.com, cnbc.com, seekingalpha.com(WebSearch 경유)

## AI 연구 편향 자각 (중요)

퍼널 스크리닝 과정에서 AI가 빠지기 쉬운 함정:

| 편향 | 표현 방식 | 대응 방법 |
|------|---------|---------|
| 대형주 선호 | 시가총액이 크고 자료가 많은 기업이 분석 분량도 길어서 "더 좋아 보임" | 핵심 지표와 MOAT 점수 기준으로 평가, 보고서 분량으로 순위 매기지 말 것 |
| 영어 자료 편향 | 미국 대형주는 자료가 풍부하여 신흥 성장주나 소형주가 과소평가될 수 있음 | finviz와 ETF 구성 종목 리스트로 시스템적으로 스캔 |
| 스토리 편향 | 높은 수익률 + 미디어 관심 = "AI/테마 관련주"가 더 좋아 보임 | "실제 해당 산업 매출 비중" vs "테마 스토리 비중" 구분, 실제 사업 수치 확인 |
| 현재 편향 | 현재 재무가 좋은 기업이 입선되기 쉬워, 전환기 블랙호스를 놓칠 수 있음 | 2단계 스크리닝에서 "추세 개선"을 완화 조건으로 허용 |
| 상장 기업 편향 | 상장사만 보다가 해당 섹터 최고의 플레이어를 놓칠 수 있음 | "미래 IPO 후보" 항목 필수 기재, 밸류에이션과 예상 타임라인 포함 |

## 출력 요구사항

1. **보고서 위치**: `reports/{산업명}-funnel-{YYYYMMDD}.md` (산업 보고서는 reports/ 루트 디렉토리에 저장)
2. **언어**: 한국어 (기술적 금융 용어는 영어 병기 가능: PER, EPS, ROE, FCF, EBITDA, MOAT 등)
3. **스타일**: 직접적·예리하게·군더더기 없이
4. **데이터**: 모든 데이터에 출처 명기; 추정치는 "추정"으로 표기
5. **입장 선입견 없음**: 데이터 제시 → 논리 추론 → 결론 도출 순서 엄수
6. **양면 제시**: 각 핵심 판단에는 반대 논거 필수 첨부
7. **각 단계 탈락 기록**: 탈락된 기업도 이름과 이유를 남길 것
8. **데이터 기준일 표기**: 보고서 맨 위에 "데이터 기준일: YYYY-MM-DD"를 표기하고, ⓪-2 단계에서 노후화로 판정된 항목은 "(갱신됨, 원본 기준일 YYYY-MM)"으로 별도 표시한다
9. **섹터 마커(필수, 대시보드 파싱 계약)**: H1 제목 **바로 다음 줄**에 최종 선정 종목을 기계 판독 마커로 남긴다.

   ```markdown
   # {산업명} 퍼널 스크리닝 — 전체 시장 → 최종 3종목
   <!-- funnel sector: Defense | finalists: NOC, GD, PLTR -->
   ```

   - `sector` 값은 **파일명의 섹터 토큰과 정확히 같은 표기**를 쓴다(`Defense-funnel-20260730.md` → `Defense`, `GLP-1-Obesity-funnel-20260723.md` → `GLP-1-Obesity`). 표기가 어긋나면 대시보드에서 같은 섹터가 둘로 갈린다.
   - `finalists` 는 5단계 최종 조합표의 종목 티커만 쉼표로 나열한다(관찰·대기 종목과 현금 행은 제외, 굵게·괄호 없이 순수 티커).
   - 이 마커가 **'티커 → 섹터' 자동 배정의 근거**다(`tools/sync_sector_map.py` → 대시보드 종목별 보고서 탭의 분야·섹터 위계). 마커가 없으면 후속 `/investment-team` 보고서를 써도 그 종목은 '미분류'로 남는다.

## 데이터 검증 (출판 전 절차)

보고서 작성 후, 아래 검증을 수행하고 통과 시에만 발행한다:

```bash
# Step 1 — 검증 목록 추출 (15% 무작위 샘플링)
python3 tools/report_audit.py extract \
  --report <보고서 파일 경로>

# Step 2 — 목록의 각 항목을 신뢰 가능한 출처에서 수치 확인 (skills/financial-data.md 참조)

# Step 3 — 통과/반려 판정 출력
python3 tools/report_audit.py verdict \
  --results '<작성된 JSON>' \
  --report <보고서 파일명>
```

**[통과]** 전부 통과 → 보고서 발행 가능; **[반려]** 미통과 항목 있음 → 수정 후 재심사.

## 데이터 신뢰도 표기 (필수)

본 보고서는 **[data-confidence.md](data-confidence.md) 표준**을 적용한다:

- 핵심 수치·판단 옆에 **신뢰도 등급 + 유형 태그**를 단다 — 🟢높음(2+독립출처 교차검증 또는 SEC 원문 직접 확인) / 🟡보통(단일출처·경미편차·해석여지) / 🔴낮음(추정·미확정주장·구데이터) / ⬛데이터부족(공백 유지) + `[사실]`/`[추정]`/`[주장]`/`[의견]`.
- **출처 독립성 주의**: 회사 IR·보도자료와 집계 사이트는 둘 다 회사 공시 파생이라 상호 독립이 아니다 → 🟢은 원문 직접 확인 또는 계보가 다른 두 출처를 요구한다.
- 보고서 **말미에 기계 판독용 신뢰도 요약 블록**을 포함한다(대시보드가 파싱):

      <!-- confidence-summary
      high: N
      medium: N
      low: N
      gap: N
      verdict: 높음|보통|낮음
      -->

  (아래에 사람용 요약 몇 줄: 등급별 개수 + 종합 판단 근거)
- ⚠️ verdict는 **"데이터 신뢰도"이며 "투자 매력도"가 아니다.** 두 축은 독립이며 자주 어긋난다. `[의견]` 태그는 verdict 계산 분모에서 제외한다.
