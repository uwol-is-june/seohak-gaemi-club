# 대시보드 디자인 기준 — 토스증권 레퍼런스 (다크)

> 🔴 **이 문서가 UI/UX 단일 소스다.** `docs/DESIGN-x.ai.md`는 2026-09-23부로
> 폐기됐다(아카이브 목적으로만 남긴다). 그 문서의 원칙 — "볼드 금지 · 그림자 없음 ·
> 시맨틱 팔레트 없음 · 대문자 모노 eyebrow" — 은 **지금 코드와 정면으로 어긋난다.**
>
> 🔴 **토큰 값의 정본은 `dashboard/app/globals.css` 의 `@theme` 블록이다.**
> 이 문서는 그 값을 설명하고 근거를 남기는 자리다. 값이 갈리면 코드가 맞다.

---

## 0. 출처 구분 — 무엇이 확인된 값이고 무엇이 파생인가

토스증권이 공개한 스펙은 **라이트 테마까지**다. 이 대시보드는 다크 전용이라
나머지는 파생했고, 파생한 값은 WCAG 2.1 상대휘도 공식으로 대비를 직접 측정했다.

| 구분 | 내용 |
|---|---|
| **공개 확인됨** | primary `#3182F6` · grey 700 `#4E5968` · radius 7/8/12/16px · spacing 4/8/12/14/16px · 타입스케일 13·15·16·18px(weight 600~700) · Toss Product Sans(비공개 서체) |
| **공개 안 됨 → 파생** | 다크 서페이스·텍스트 계조 · 등락 색 hex · 판정 색 · 분류 색 |
| **대체** | 서체 — Toss Product Sans는 배포되지 않아 **Noto Sans KR**로 대체 |

> 토스 기술 블로그는 다크가 **별도 명도 기준**을 쓴다고만 밝힌다. 실제로 확인됐다:
> `#3182F6`을 다크 카드 위에 그대로 올리면 **4.46:1**로 본문 기준(4.5)에 미달한다.
> 그래서 텍스트용 파랑은 `#4593FC`(5.39:1)로 따로 둔다.

## 1. 두 개의 색 축 — 절대 섞지 않는다

이 대시보드에서 가장 자주 틀리는 지점이다.

| 축 | 토큰 | 뜻 |
|---|---|---|
| **등락** (가격 방향) | `up` `down` | 주가가 올랐나 내렸나 |
| **판정** (맞았나) | `success` `danger` `warn` | 콜이 적중했나, 조건이 충족됐나 |
| **분류** (무엇인가) | `cat-1` ~ `cat-4` | 보고서 종류처럼 좋고 나쁨이 없는 구분 |

섞으면 **"빗나감"이 "상승"으로 읽힌다.** 같은 초록이 한 화면에서 "통과"와
"보고서 종류"를 동시에 뜻하면 색이 아무것도 말하지 않게 된다.

### 🔴 등락은 한국 관례다 — 상승 빨강 / 하락 파랑

미국·유럽과 **정반대**다. 한국·중국·일본은 빨강을 복으로 보고, 토스증권을 포함한
국내 증권앱이 전부 이 관례를 따른다. 미국식(초록 상승)을 쓰면 한국 사용자가
손익을 반대로 읽는다.

여기서 이 앱에만 해당하는 규칙이 하나 나온다 — **매수자에게 하락은 기회다.**
그래서 진입 구간·래더 차수·"1차까지 N%"를 전부 하락 파랑으로 묶는다.
파랑이 짙어질수록 살 때가 가까워진다는 규칙 하나만 남는다.

## 2. 색 토큰 (괄호 = 카드 `#191F28` 위 실측 대비)

### 서페이스 — 4단

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `canvas` | `#14181F` | 페이지 배경 |
| `canvas-card` | `#191F28` | 카드 fill |
| `canvas-soft` | `#232A35` | hover · 인풋 · **카드 안의 블록** |
| `canvas-mid` | `#2E3742` | raised · 강조 블록 |

🔴 **서페이스 단차가 위계를 진다. 보더는 장식이다.**
이전 시스템은 "그림자 없음 · 헤어라인이 모든 elevation"이었는데, 그 헤어라인이
**1.26:1**이라 실제로는 아무 구조도 못 지고 있었다. 카드에는 보더를 두지 않는다.

🔴 **카드 안의 블록은 반드시 한 단 위로.** 부모와 같은 배경을 쓰면 단차가 사라진다
(실제로 발생했다 — HoldingsBanner KPI 타일 3곳).

### 텍스트

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `ink` | `#F2F4F6` (15.02:1) | 기본 |
| `body` | `#B0B8C1` (8.26:1) | 보조 본문 |
| `mute` | `#8B95A1` (5.45:1) | 캡션 · 라벨 |
| `faint` | `#6B7684` (3.59:1) | 🔴 **UI 전용 — 본문 금지** |

### 등락 · 판정 · 분류

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `up` | `#FF5A67` (5.45:1) | 상승 |
| `down` | `#4593FC` (5.39:1) | 하락 · **진입 기회** |
| `success` | `#15C47E` (7.28:1) | 적중 · 조건 충족 · 통과 |
| `danger` | `#FF5A67` (5.45:1) | 빗나감 · 탈락 · 오류 |
| `warn` | `#FFB020` (9.06:1) | 진행중 · 조건 미충족 · **추격금지** |
| `cat-1`~`cat-4` | teal/violet/pink/slate | 보고서 종류 등 분류 |

> `danger`와 `up`은 값이 같다. 토큰 이름을 분리해 둔 건 나중에 갈라질 수 있게
> 하려는 것이고, 지금은 라벨 텍스트가 둘을 구분한다(칩에는 항상 글자가 있다).
>
> **추격금지선은 `danger`가 아니라 `warn`이다.** 손실이 아니라 가드레일이다.
> 같은 이유로 "밴드 도달"은 `success`다.

### 액션

| 토큰 | 값 | 규칙 |
|---|---|---|
| `primary` | `#3182F6` | 🔴 **fill 전용** — 카드 위 4.46:1이라 본문 텍스트 금지 |
| `primary-press` | `#1B64DA` | 버튼 fill (흰 글자 5.41:1) |
| `border-control` | `#6B7684` | 입력 · 선택 경계 (3.01:1, WCAG 1.4.11) |

## 3. 색으로만 말하지 않는다

🔴 손익·등락은 **색 + 부호(+/−/±) + 도형(▲/▼/─)** 세 겹을 항상 함께 낸다.
적록색약(남성 약 8%)과 흑백 출력에서도 뜻이 남아야 한다.

이 규칙은 문서가 아니라 **`components/primitives/Delta.tsx` 가 강제한다.**
호출부가 실수할 수 없도록 컴포넌트가 세 겹을 내장한다. 새 손익 표시는 반드시
`<Delta>` 를 쓴다.

판정 칩(`StatusChip`)도 **항상 라벨 텍스트를 갖는다.** 색은 보조이고 글자가 주다.

## 4. 타이포그래피

| | |
|---|---|
| 서체 | **Noto Sans KR** (Toss Product Sans 대체) + Geist Mono(수치·티커) |
| 본문 | 15px |
| 제목 | `h1~h4` **weight 700**, letter-spacing −0.02em |
| 보고서 본문 | 15px / line-height 1.72 |
| 섹션 라벨(`.eyebrow`) | 12px / 700 / 한글 |

🔴 **`font-variant-numeric: tabular-nums` 를 `body` 에 건다.** 금융 대시보드의
숫자는 열에서 자리를 지켜야 한다. 비례폭이면 행마다 소수점이 어긋나 세로로
훑어 비교할 수 없다.

🔴 **영문 대문자 eyebrow는 쓰지 않는다.** 이전 시스템의 시그니처였다. 영문 라벨
위에 한글 제목을 또 얹으면 같은 말을 두 번 한다 — 굵은 한글 제목 하나로 끝낸다.
영문 대문자는 브랜드 워드마크에만 남긴다.

## 5. 모양 · 간격

| | |
|---|---|
| radius | 카드 `rounded-2xl`(16px) · 내부 블록 `rounded-xl`(12px) · 칩 `rounded-full` |
| spacing | 4 / 8 / 12 / 16 / 24px |
| 터치 타깃 | 최소 44px (`min-h-11`) — 아이콘 전용도 동일 |
| 포커스 링 | `outline: 2px solid var(--color-primary)`, offset 2px |

**선택 상태의 반전(흰 pill)은 필터 칩에만.** 사이드바 현재 위치는 한 단 밝은
배경 + 굵은 글자로 말한다. 반전은 화면당 하나뿐인 primary 액션의 어휘다.

아이콘은 **인라인 스트로크 SVG**(`currentColor`)를 쓴다. 이모지 금지 — 폰트
의존이고 OS마다 다르게 그려지며 토큰으로 제어할 수 없다.

## 7. 규칙을 지키게 하는 장치

```bash
python3 tools/check_design_tokens.py          # 검사
python3 tools/check_design_tokens.py --list   # 위반 전체
```

주석에만 적힌 규칙은 다음 편집에서 다시 샌다. 검사기가 막는 것:

- `primary`를 텍스트 색으로 / `faint`를 본문 색으로
- Tailwind 기본 팔레트(`text-emerald-300` 등) 직접 사용
- 순백 `#fff` 직접 지정 / hex 하드코딩

> 실제로 이 검사기가 **직접 만든 프리미티브의 AA 미달 1건**과
> **`lib/` 전체가 정리에서 빠져 있던 25건**을 잡아냈다.
> 검사 범위는 `components/` · `app/` · `lib/` 셋 다여야 한다.
