  - **폭**: `xl:col-span-2`(충돌 카드만 2열 차지) 제거 → 모든 카드 1열 고정.
  - **논제 배치**: 충돌 시 `sm:grid-cols-2 xl:grid-cols-3` 로 눕히던 것을 **세로 스택**으로
    통일. 래더의 가격 축이 종목마다 1/1·1/2·1/3 폭으로 그려져 눈으로 비교가 안 됐다.
    `showAll`/'다른 논제 n건 보기'도 제거 — 살아있는 논제는 **전부** 같은 규격으로 보인다.
  - **접힌 줄**: 요약을 **2슬롯 고정**(매수가 / 진입·목표까지). 예전엔 둘 다 없으면 줄이
    통째로 사라졌다. 미보유는 `미보유`, 산출 불가는 `⬛ 미산출`. 두 번째 슬롯의 라벨은
    대표 논제의 방향을 따른다(hold→진입까지 · buy/keep→목표까지 · avoid→없음) —
    같은 숫자가 방향에 따라 정반대를 뜻하기 때문이다.
  - **논제 건수 칩**을 항상 표기(`논제 1건` / `논제 2건 · 충돌`). 1건일 때만 칩이 사라져
    머리 줄 구성이 카드마다 달랐다. 중복이던 `보유` 칩은 매수가 슬롯이 대신한다.
  - **숫자 표 3×3 고정**: 기존 6칸(시점가·시점대비·경과 / SPY·초과수익·기회비용) 위에
    **티어 · 호라이즌 · 체결확률** 줄을 추가했다. 셋 다 예전엔 '있는 콜만' 칩으로 붙던
    것이라 논제마다 머리 줄 길이가 달랐다. `Stat` 의 보조 줄은 값이 없어도 nbsp 로
    자리를 지켜 행 높이를 맞춘다. 결측 칸의 `title` 에 **산출 명령**을 넣었다
    (`tools/quality_tier.py` · `tools/fill_probability.py`) — 결측만 지적하고 방법을
    안 알려주면 빈칸은 안 채워진다.
  - 래더가 없는 논제에 `진입 래더 ⬛ 미산출` 고지 + `record_call.py --tranche` 예시 툴팁.
  - 부수: `FillProbability` 컴포넌트는 표 칸으로 흡수해 삭제, `fmtPrice` 의 무의미한
    삼항(`v < 100 ? 2 : 2`) 정리.

  집행할 진입이 없어 래더 결측을 지적하지 않는다(안 가르면 보유 종목 ADBE 에 "집행할 수
  없다"는 헛경고가 붙는다). 화면이 이제 이걸 드러낸다 — 원장을 채우는 것은 별도 작업이다.
